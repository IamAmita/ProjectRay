# ストーリー

天宮前日譚のAI_Novel版の本文と、話ごとのプロットを置く。

## 構成

```
ストーリー/
├── プロット/     話ごとの構成メモ
│   └── 全体プロット.md   全4章・19節の構成（2026-11-15）
└── 原稿/         本文
```

全体プロットのうち、設定で決まっていない所に仮に置いたものは【仮置き】の印と、末尾の「仮置きの一覧」で分かる。設定（`../../../settings/`）には書き戻さない。

## 参照

- 世界設定・人物設定の正本は `../../../settings/`。作品の設定は `../../../settings/stories/天宮前日譚.md`。
- 作者の原稿は `../../../story/manuscript/前日譚/`。
