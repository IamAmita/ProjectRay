# 考察

> **本フォルダの位置づけ（2026-11-08作成）：**
> 作品世界の設定についての**考察・点検の記録**を置く。確定前の検討の過程や、設定の矛盾・疑問点を調べた結果であり、作品世界の架空の要素を含む。
> 確定した設定の正本は `../settings/`。現実世界の調査資料は `../notes/`（架空の要素を含めない原則がある。`../notes/README.md`）。
> 2026-11-08、`notes/考察/` にあった記録を、`notes/` の原則と食い違うためここへ移した。

## 置くもの

| 種類 | 例 |
|------|----|
| 設定の点検の記録 | `豊葦島の設定点検・2026-10-30.md`、`魔法設定の点検・2026-11-08.md` |
| 検討の過程の記録（確定前のもの） | `豊葦の歴史考察/` |

- 点検で見つかった項目の対処状況は、各記録の中に追記する。未確定のまま残る項目は `../settings/未確定事項一覧.md` に載せる。
- 検討の結果が決まったら、確定内容は `../settings/` の各ファイルに書く。ここには経緯だけが残る。
