# 視覚受容の仕組み

調査日: 2026-09-10

> **本ファイルの位置づけ:**
> ヒトの眼が光を受容し、視覚として処理する仕組みをまとめた現実世界の調査資料。
> 作品世界の設定・架空の要素は含まない。創作への適用は `settings/` 配下で扱う。
> 以下は主として桿体・錐体による像の形成に関する基本機構を整理したもので、視覚系の全機能を網羅するものではない。

## 概要

視覚は、光を集める光学系、光を神経信号へ変換する受容器、信号を処理する網膜・脳の働きによって成立する。

```text
物体が発した光・反射した光
  → 角膜と水晶体によって網膜に結像
  → 視細胞の視物質が光子を吸収
  → 分子の構造変化と細胞内の信号伝達
  → 視細胞の膜電位・神経伝達物質の放出量が変化
  → 網膜内の神経回路で処理
  → 視神経を経て脳へ
  → 明るさ・色・形などの知覚
```

「刺激を検知すること」「刺激の位置を区別すること」「その意味を認識すること」は、それぞれ異なる段階に属する。[1][2][3]

## 1. 光を集め、位置の情報を保つ

可視光は電磁波の一部であり、物質との吸収・放出では光子を単位としてエネルギーが受け渡される。

眼では角膜と水晶体が光を屈折させ、網膜に像を結ぶ。瞳孔は光の入口で、虹彩が開口の大きさを調節する。[1]

| 部位 | 主な役割 |
|------|----------|
| 角膜 | 入射光を屈折させ、結像に寄与する |
| 瞳孔・虹彩 | 光の入口と、その開口の調節 |
| 水晶体 | 角膜とともに、網膜上に焦点を合わせる |
| 網膜 | 光を受容し、神経信号への変換と初期処理を行う |
| 視神経 | 網膜から脳へ信号を伝える |

結像によって、視野内の異なる位置から来た光が網膜上の対応する位置に振り分けられる。受容器が光に反応するだけでなく、この空間的な対応があることで形を見分けられる。

## 2. 視細胞と視物質

像を見る働きでは、主に次の二種類の視細胞が関わる。[4]

| 視細胞 | 主な性質 |
|--------|----------|
| 桿体（かんたい） | 弱い光に敏感で、暗い環境での視覚を支える |
| 錐体（すいたい） | 明るい環境で、色や細部の知覚を支える |

視細胞には、光を吸収する「視物質」がある。視物質は、タンパク質の**オプシン**と、ビタミンA由来の光吸収分子である**レチナール**からなる。桿体の視物質は**ロドプシン**と呼ばれる。[2]

レチナールが光子を吸収すると、11-cis型からall-trans型へ構造が変化する。この変化がオプシンの構造変化を引き起こし、細胞内の信号伝達を開始させる。[2]

## 3. 光受容から電気信号への変換

桿体の代表的な光受容過程は、次のように整理できる。[2]

1. 光子の吸収によってロドプシンが活性化する。
2. トランスデューシンというGタンパク質が活性化する。
3. ホスホジエステラーゼ（PDE）が活性化し、cGMPを分解する。
4. cGMPの減少により、cGMP依存性の陽イオンチャネルが閉じる。
5. 視細胞への陽イオン流入が減り、膜電位がより負になる（過分極）。
6. 次の細胞への神経伝達物質の放出量が減少する。

したがって、光が当たると単純に視細胞の電気的な活動が増す、という仕組みではない。放出量の減少も情報として利用される。

光は細胞内反応を開始させる刺激であり、吸収した光のエネルギーがそのまま視神経を流れるわけではない。光子の吸収をきっかけとした反応には増幅がある。ヒキガエルの桿体を用いた実験では、単一光子の吸収に対応する電流応答が測定されている。これはヒトについて直接実験した結果とは区別する。[5]

## 4. 色と像の知覚

ヒトの色覚には、感度の高い波長帯が異なる三種類の錐体が関わる。それぞれ短波長・中波長・長波長側への感度により、S・M・L錐体と呼ばれる。[3][6]

各錐体は一定の幅を持つ波長域に反応する。一つの錐体が特定の一色だけを検出するのではなく、複数の錐体の反応の比較と、その後の神経処理によって色が知覚される。[3][6]

網膜は単なる受光面ではなく、神経回路による処理も担う。その出力が視神経を経て脳へ伝わり、さらに処理されることで、見えている像や色の知覚につながる。[1][3]

## 5. 誤解しやすい点

| 誤解 | 整理 |
|------|------|
| 眼は物体そのものを直接受け取る | 眼に到達した光を受け取り、そこから物体についての情報を得る |
| 光がそのまま電流になって脳まで流れる | 光による分子の変化が細胞内反応を起こし、神経信号へ変換される |
| 光が当たると視細胞が発火する | 桿体・錐体では主に段階的な膜電位変化で応答し、光に対して過分極する |
| 三種類の錐体は赤・緑・青だけに反応する | 感度の分布は幅を持ち、互いに重なる。反応の比較が色覚に関わる |
| 受容器さえあれば、対象の形や位置も分かる | 刺激の検出に加え、空間情報を保つ仕組みと神経処理が必要 |
| 網膜はカメラの受光面と同じ働きだけをする | 網膜自体に信号を処理する神経回路がある |

## 6. 知見の範囲

- 光学的な結像、視物質の光吸収、桿体の信号伝達経路、三種類の錐体による色覚の基礎は、確立した知見として扱える。
- 分子から知覚までの説明は複数の階層をまたぐ。光受容の分子機構が分かることと、主観的な視覚体験の全容が解明されていることは同義ではない。
- 動物実験の具体的な感度・応答特性を、そのままヒトの数値として扱わない。
