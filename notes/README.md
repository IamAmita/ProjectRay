# notes

## 本フォルダの原則

> **`notes/` 配下には、架空の要素を一切含めない。**
> 記載するのは現実世界における事実・科学的知見・調査結果のみとする。
> 作品世界の設定、魔法の仕様、キャラクター、地名などの創作物は書かない。

理由は、現実と創作の境界を曖昧にしないため。
調査資料に創作の都合が混ざると、後から「どこまでが事実か」を判別できなくなり、
設定の根拠として使えなくなる。

## 創作への適用をどこに書くか

現実の知見を作品世界へどう反映するかの検討・決定は、`notes/` ではなく以下で行う。

| 置き場所 | 内容 |
|---------|------|
| `settings/` | 確定した作品世界の設定 |
| 各作品フォルダの `設定/` | 個別作品に閉じた設定・検討中の案 |

`notes/` の資料は、それらから参照される**一次資料**として扱う。

## 構成

```
notes/
├── research/       現実世界の調査資料（科学・制度・歴史など）
├── chat_history/   AIとの相談ログ
└── *.md            作業計画等
```

### 記載の作法

- 冒頭に `調査日` と、現実資料である旨の位置づけを明記する。
- 末尾に `参考資料` として出典を残す。可能な限り一次資料・公的機関・査読済み論文を用いる。
- 確定した事実と、研究途上・議論のある事項を区別して書く。
- 一般に流布している誤解がある分野では、`誤解しやすい点` の節を設けて整理する。
