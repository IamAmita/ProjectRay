時系列を作成していきたい。
何から始めればよいだろうか。




まずは**「出来事の順番」ではなく、「時系列で管理したい情報の種類」を決める**ところから始めるのがいいと思う。

今回の前日譚は、すでに発端がかなり固まってる。
**2025年3月24日早朝、京都市内で魔法暴発事故が起き、凍結空間の中心で鬼灯蓮華が保護され、京都府警魔道課が初動対応する**ところまでは確定している。
だから、時系列作成は「ゼロから年表を作る」というより、**確定済みの事件を中心に、前後を埋めていく作業**になる。

## まず作るべき時系列は3つ

いきなり全体年表を作るより、分けた方がいい。

### 1. 事件時系列

これは一番重要。

「2025年3月24日早朝の暴発事故」を中心に、
その前に何があり、当日に何が起き、その後どう処理されたかを並べる。

例：

| 時期            | 出来事            |  確定度 | メモ           |
| ------------- | -------------- | ---: | ------------ |
| 数年前           | 蓮華の両親が死亡       |   確定 | 孤児化          |
| 不明            | 蓮華が行方不明になる     | 確定寄り | 失踪期間の調査対象    |
| 不明            | 組織に利用・実験・搾取される |  未確定 | 黒幕・真相と関係     |
| 2025年3月24日 早朝 | 魔法暴発事故         |   確定 | 凍結空間、男性2名、蓮華 |
| 同日朝           | 京都府警魔道課が保護     |   確定 | 伏見・喜多の捜査開始   |
| 同日以降          | 二条署の魔術師保護室へ    |   確定 | 冒頭シーン        |
| その後           | 京蓮学院大学病院へ      | 確定寄り | 医療担当         |
| その後           | 公安・魔道協会が介入     |   予定 | 管轄争い・圧力      |
| 終盤            | 蓮華が死を選ぶ        |  最有力 | 結末候補C        |

最初はこの程度でいい。
細かい時刻まで入れるのは後でいい。

---

### 2. 蓮華の心理時系列

この作品の核心は、単に「蓮華が死ぬ」ことではなく、
**なぜ蓮華が“自分は生きるべきではない”と信じ込むのか**だと思う。

だから事件年表とは別に、蓮華の内面の変化を作るべき。

| 段階       | 蓮華の状態             | 重要な変化               |
| -------- | ----------------- | ------------------- |
| 保護直後     | 無声、衰弱、記憶混濁        | 自分の状況を理解していない       |
| 入院初期     | 安全を与えられる          | でも安心しきれない           |
| 捜査進行     | 自分が事件の中心だと知る      | 罪悪感が芽生える            |
| 組織・周囲の圧力 | 自分の存在が争点になる       | 「自分が迷惑をかけている」と考える   |
| 天宮との交流   | 助けようとされる          | 救われたい気持ちも生まれる       |
| 真相理解     | 自分の価値・危険性・利用価値を知る | 生きている限り誰かを巻き込むと思い込む |
| 終盤       | 死を選ぶ              | 天宮でも止められない          |

ここを作ると、物語の転〜結がかなり安定する。

特に決めるべきなのは、
**蓮華が死を意識し始めるタイミング**。

これは未確定事項にも入っているので、最優先で詰める価値がある。

---

### 3. 天宮梓音の価値観時系列

この前日譚の役割は、天宮梓音のノブレス・オブリージュ観の形成だよね。
だから、天宮の変化も独立して時系列化した方がいい。

| 段階     | 天宮の認識            | 変化             |
| ------ | ---------------- | -------------- |
| 事件前    | 上に立つ者は助ける義務がある   | 教育として知っている     |
| 事件を知る  | 蓮華を救うべき対象と見る     | 正義感・義務感で動く     |
| 蓮華と関わる | 個人として助けたいと思う     | 義務から感情へ        |
| 現実を知る  | 家柄・権力でも救えない領域がある | 理想が崩れる         |
| 終盤     | 蓮華を止められない        | 初めて敗北する        |
| 事件後    | 全員は救えないと受け入れる    | 現実主義へ          |
| 本編時点   | それでも義務を捨てない      | ノブレス・オブリージュの完成 |

ここで大事なのは、天宮を単に「挫折した少女」にしないこと。
彼女は挫折して終わるのではなく、
**“救えない人間がいる”と知ったうえで、それでも上に立つ者の義務を選ぶ**。

これが本編の天宮に繋がる。

## 次に決めるべきこと

一番先に決めるべきは、**物語期間**。

つまり、前日譚全体がどのくらいの期間の話なのか。

候補は3つある。

### 案A：数日間の物語

かなり濃密。
刑事事件・保護・天宮との接触・結末まで一気に進む。

メリットは緊迫感が強いこと。
デメリットは、天宮と蓮華の関係が深まるにはやや短いこと。

### 案B：2〜3週間の物語

一番扱いやすいと思う。

蓮華の検査、警察の捜査、天宮との交流、組織の介入、心理の悪化を自然に描ける。
個人的には、この案が一番合っている。

### 案C：1〜3ヶ月の物語

社会構造や組織対立をじっくり描ける。
ただし、蓮華が長期間保護されているのに救えない理由をかなり強く作る必要がある。

この作品なら、まずは
**2025年3月24日から4月中旬ごろまでの約3週間**
を仮置きするとよさそう。

## 章立てに繋げるなら

時系列を作る目的は、最終的には章立てにすることだと思う。
なので、最初から章構造を意識しておくといい。

### 第一章：凍結事故

伏見・喜多の視点。
蓮華の保護。
読者に「これはただの事故ではない」と思わせる。

### 第二章：保護された少年

二条署、京蓮病院。
蓮華の異常な身体状況。
未登録魔術師の腎臓移植など、事件の闇が見え始める。

### 第三章：天宮梓音

天宮が事件を知る。
御三家令嬢として、あるいは個人として蓮華に関わる。

### 第四章：救えない理由

公安、魔道協会、黒幕組織、家柄、魔術師管理制度。
蓮華をめぐって社会構造が露出する。

### 第五章：蓮華の結論

蓮華が「自分は生きるべきではない」と思い込む。
天宮はそれを否定するが、届かない。

### 終章：ノブレス・オブリージュ

天宮は敗北する。
でも義務を捨てない。
ここで本編の天宮に繋がる。

## 結論

最初にやるべきことは、これ。

**1. 2025年3月24日を中心点にする。**
**2. 物語期間を仮に3週間と置く。**
**3. 「事件」「蓮華の心理」「天宮の価値観」の3本の時系列を分けて作る。**
**4. その後で、各日付を章に変換する。**

いきなり「全出来事」を並べようとすると詰まる。
まずは、

> 事件はどう進んだか
> 蓮華はいつ死を選ぶに至ったか
> 天宮はいつ現実を知ったか

この3つだけを並べればいい。




物語の期間は1週間にしたいな。梓音が高校1年生から2年生に上がる直前の出来事。
⇒本編主人公が高等部に進学する直前の出来事で、時期的につなげたい。
まずは、事実重視で不自然な点がないように、出来事の整理を行いたい。




いいと思う。
**1週間**に絞るなら、むしろこの前日譚のテーマにはかなり合う。

理由は、蓮華の死を「長期的に救えなかった」ではなく、
**保護された瞬間から、すでに社会・身体・心理・制度の全てが詰んでいた**
という形にできるから。

ただし、1週間にする場合は注意点がある。
出来事を詰め込みすぎると「警察・病院・公安・魔道協会・天宮家・黒幕組織が全員いきなり動きすぎ」に見える。
なので、まずは**事実として自然に起きる順番**を整理した方がいい。

# 1週間構成で一番自然な流れ

## 1日目：3月24日 月曜日

### 暴発事故・蓮華保護

ここはすでに固まっている。

起きる出来事はこの順番が自然。

1. 早朝、京都市内で異常な魔力反応・凍結現象が発生
2. 通報、または魔道警察の検知網により京都府警魔道課が出動
3. 現場で凍結空間を確認
4. 男性2名が立ったまま停止している
5. 中心に鬼灯蓮華がいる
6. 蓮華を保護
7. 現場保存、遺体搬送、魔力残滓の採取
8. 蓮華は二条署の魔術師保護室へ
9. 伏見・喜多が初期確認

ここでは、蓮華に深い事情聴取はできない。
理由は自然に作れる。

* 衰弱している
* 外傷が多い
* 精神的ショックが大きい
* 発声できない
* 当夜の記憶がない
* 未成年
* 被害者か加害者かも不明

だから1日目は、
**「保護」「現場確認」「異常性の提示」**
までで十分。

### 不自然にしないポイント

この時点で公安や天宮家が即座に現場入りすると、少し早すぎる。
1日目に動くのは、基本的に京都府警魔道課と医療関係者だけでいい。

ただし、公安は裏で情報を受け取っていてもいい。
表立って出るのはまだ早い。

---

## 2日目：3月25日 火曜日

### 医療検査・蓮華の異常性判明

この日から京蓮学院大学病院に移すのが自然。

理由は、

* 二条署の保護室では医療対応に限界がある
* 蓮華が重度の衰弱状態
* 魔術師としての精密検査が必要
* 未登録魔術師の疑いがある
* 腎臓移植など身体的異常が疑われる

この日に判明してよいこと。

| 判明事項        | 自然度  |
| ----------- | ---- |
| 栄養失調・外傷・古傷  | 高い   |
| 魔力過負荷の痕跡    | 高い   |
| 複数回の拘束・処置痕  | 高い   |
| 腎臓移植の痕跡     | 高い   |
| 未登録魔術師であること | 高い   |
| 蓮華の能力の全容    | まだ早い |
| 黒幕組織の正体     | まだ早い |

2日目の中心は、
**蓮華は単なる事故関係者ではなく、長期間搾取されていた可能性が高い**
と警察・病院側が認識すること。

### 天宮梓音との接点

この日に梓音が事件を「知る」くらいなら自然。

ただし、蓮華と直接会うのはまだ早くてもいい。

梓音が事件を知るルートは複数ある。

* 天宮家に公安・警察筋から情報が入る
* 京蓮学院関係者から情報が入る
* 御三家案件として魔道社会内で噂になる
* 凍結魔法の異常性が天宮家の関心を引く
* 蓮華の家系、鬼灯家が古い祭司筋で、天宮家と接点がある

一番自然なのは、
**天宮家が「未登録の希少魔術師が保護された」として情報を受け取る**
流れ。

---

## 3日目：3月26日 水曜日

### 事件性の確定・蓮華の身柄をめぐる問題化

この日には、事故ではなく事件だと固まってくる。

自然に進む捜査はこう。

1. 死亡した男性2名の身元確認
2. 彼らが一般人ではなく、何らかの組織関係者だと判明
3. 蓮華の失踪届、戸籍、親族関係を確認
4. 数年前から所在不明だったことが判明
5. 蓮華の体に医療行為・魔術処置の痕跡がある
6. 暴発は偶発事故ではなく、追い詰められた結果の可能性が高まる

ここで初めて、公安が表に出る理由ができる。

公安が関心を持つ理由は、既存メモ通り
**国際人身売買・国家安全保障**
で自然。

### 魔道協会もここから動く

魔道協会は、

* 未登録魔術師
* 危険能力持ち
* 管理外の希少個体
* 既存制度の失態
* 魔術師管理権限

という理由で介入したがる。

でもこの時点では、まだ「身柄を渡せ」と強く言うより、
**照会・協議・調査参加の要求**
くらいが自然。

---

## 4日目：3月27日 木曜日

### 天宮梓音の本格介入

1週間構成なら、梓音の本格登場は4日目あたりがよさそう。

理由は、1〜3日目で事件の異常性が明らかになり、
天宮家が動く根拠が揃うから。

梓音が関わる理由は、慎重に作った方がいい。

単に「かわいそうだから会いに来た」だと、御三家令嬢としては少し軽い。
自然にするなら、以下のどれか。

## 案1：天宮家が後見候補になる

蓮華が古い祭司筋・鬼灯家の血を引く孤児で、
通常の保護制度に乗せるには危険すぎる。

そこで、天宮家が一時後見、あるいは保護観察の候補に上がる。

この場合、梓音が会う理由が強い。

## 案2：蓮華の能力が天宮家案件になる

蓮華の能力が、降霊術・錯視・凍結など複数にまたがっている。
特に降霊術や神聖性のある祭司筋は、天宮家の管轄・関心領域と近い。

だから天宮家が確認に来る。

## 案3：梓音が父や家の代理として同行する

正式な権限者は天宮家当主や家の大人。
梓音は高1だが、次代教育の一環として同行する。

この形が一番自然。

梓音がいきなり単独で警察・病院に乗り込むより、
**天宮家の大人に連れられて来る**
方が自然。

そのうえで、蓮華と個人的に関わってしまう。

---

## 5日目：3月28日 金曜日

### 圧力の集中・蓮華が自分の立場を知る

この日が物語の「転」に向いている。

起きる出来事はこう。

| 勢力      | 動き                |
| ------- | ----------------- |
| 京都府警魔道課 | 蓮華を被害者として守ろうとする   |
| 公安      | 身柄移管を検討する         |

この時点では、蓮華は「謎の少年」。

## 第2段階：再会

翌日、また会う。

ここで梓音は、蓮華がたまたま居合わせた子供ではなく、

例えば、

* 看護師が妙に慎重
* 私服警官らしき人物がいる

* 蓮華が名前を呼ばれない
* 蓮華が「保護対象」と呼ばれる
* 病院職員が梓音を見ると会話を止める

梓音は御三家令嬢だから、普通の高校生より察しがいい。
ここで「何かある」と気づく。

でも、天宮家が公式に関わっていない以上、強引に情報を取るのは避けた方がいい。

## 第3段階：教授から断片的に聞く

ここが重要。

梓音が大学に通っている理由が「教授に話を聞くため」なら、
蓮華の情報を知るルートは教授にすると自然。

ただし、教授が守秘義務を破って全部話すのは不自然。

だから、教授が話せるのは断片だけ。

例えば、

> 「あの子については、君が関わるべきではない」
> 「警察案件だ」
> 「保護されている。少なくとも、今は」
> 「あの子は被害者だ。だが、ただの被害者ではない」
> 「天宮の名で動くなら、話は別だ。だが、君個人が近づくには危うすぎる」

このくらいなら自然。

教授は全部は言わない。
しかし、隠そうとするからこそ梓音は気づく。

## 第4段階：梓音が個人として蓮華に会いに行く

ここで梓音の性格が出る。

天宮家としてではなく、

だから会う場所は中庭のままがいい。

梓音は蓮華の散歩時間を狙って会う。

この時点でも、梓音は事件の全容を知らない。

知っているのは、

* 蓮華が保護児童である
* 警察案件である
* かなり酷い目に遭っている
* 周囲が蓮華を危険視している
* 蓮華自身が何かを恐れている

くらい。

これで十分。

## 第5段階：蓮華が少しだけ反応する

なら、梓音との関係は会話よりも行動で作るのがいい。

たとえば、

* 蓮華が握りしめている
* 梓音が「また明日」と言う
* 蓮華が初めて少しだけ反応する

1週間しかないので、急激に仲良くなりすぎると不自然。
でも、蓮華のような子供にとっては、**毎日同じ人が来て、同じように声をかける**だけでも大きい。

と気づく。

これは蓮華の結末にも直結する。

# 天宮家を公式に関わらせない場合の利点

これはかなり大きい。

天宮家が公式に関わっていないなら、梓音は御三家の権力を十分には使えない。

これが自然。

梓音が救えない理由が、単なる脚本都合ではなくなる。

## 2. 「天宮家」ではなく「梓音」の敗北になる

もし天宮家が正式に関与して蓮華を救えなかった場合、
それは天宮家の政治的敗北になる。

描きたいのは、
**梓音が初めて、自分の善意と責任感の限界を知ること**。

だから、天宮家を公式に関わらせない方がいい。

これは梓音個人の敗北になる。

本編時点の梓音が強いノブレス・オブリージュ観を持っているなら、
この事件は「家として処理した案件」ではなく、

である方が強い。

天宮家の公式記録にはほとんど残らない。
でも梓音の中には残る。

これが本編で効いてくる。

# 不自然になりそうな点と対策

## 不自然点1：保護対象の蓮華が、なぜ梓音と何度も会えるのか

これは対策が必要。

完全に自由に会えると不自然。
でも中庭での散歩なら自然にできる。

対策：

* 蓮華の散歩は医師の指示
* 梓音はたまたま同じ時間に大学へ来ている
* 最初は偶然
* 2回目以降は梓音が少し時間を合わせる
* 付き添いはいるが、梓音が危険人物ではないため黙認される
* 梓音が天宮姓なので、病院側も強く排除しにくい

ここで「天宮家は公式関与していないが、天宮姓の圧はある」というバランスが使える。

---

## 不自然点2：教授がどこまで話していいのか

教授が事件の詳細を話しすぎると不自然。

対策：

教授はあくまで一般論として話す。

例えば、

* 未登録魔術師の保護制度
* 魔法暴発後の処置
* 魔術師の身体検査
* 魔力臓器移植の危険性
* 魔道協会と警察の管轄問題

これらを講義の延長として話す。

梓音はそれを蓮華の状況に当てはめて察する。

教授が直接、

> あの子はこういう事件の被害者だ

と全部説明する必要はない。

むしろ、梓音が察した方が優秀さが出る。

---

## 不自然点3：梓音が事件解決に関われない

天宮家が非公式なら、事件の中核に入れない。
でも、それでいい。

梓音の役割は事件解決ではなく、蓮華との関係。

つまり、物語の二重構造にするといい。

| パート    | 主担当   | 内容             |
| ------ | ----- | -------------- |
| 事件捜査   | 伏見・喜多 | 事故、組織、公安、協会、真相 |
| 蓮華との交流 | 梓音    | 中庭、会話、罪悪感、救済失敗 |

この2本が並行して進む。

梓音は事件の全部を知らない。
伏見・喜多は蓮華の心の全部を知らない。

だから誰も全体を掴めない。
その隙間で蓮華が死を選ぶ。

これはかなり強い構造になる。

でも蓮華は、その手を取れなかった。

この形が一番強い。




蓮華が大学病院に移って、その日から散歩できるのは不自然ではないだろうか。




不自然寄りだと思う。

特に蓮華は、

* 事件直後
* 衰弱
* 外傷多数
* 無声
* 魔法暴発の中心人物
* 未成年の保護対象
* 警察案件
* 身体検査が必要

なので、**大学病院へ移った当日から屋外散歩**は早すぎる。

自然にするならこう。

## 一番自然な流れ

| 日付   | 状態    | 行動                      |
| ---- | ----- | ----------------------- |
| 3/24 | 事件当日  | 二条署保護室 → 応急処置 → 京蓮病院へ搬送 |
| 3/25 | 入院1日目 | 検査、安静、事情確認。散歩なし         |
| 3/26 | 入院2日目 | 病棟内の歩行確認。廊下を少し歩く程度      |
| 3/27 | 入院3日目 | 医師・看護師付き添いで中庭に短時間出る     |
| 3/28 | 入院4日目 | 中庭散歩が数分だけ許可される          |
| 3/29 | 入院5日目 | 梓音と再会・少し会話              |
| 3/30 | 入院6日目 | 破局                      |

だから、**梓音との初対面は3月27日か28日**が自然。

## もっと自然にしたいなら

最初の出会いを「中庭」ではなく、**病棟の廊下・渡り廊下・リハビリ室前**にするといい。

たとえば、

> 蓮華は検査後、看護師に付き添われて病棟内を数分歩いていた。
> 梓音は教授の研究室へ向かう途中、大学病院棟へつながる渡り廊下で、その少年を見かける。

これなら**入院翌日でもギリギリ自然**。

でも屋外の中庭での散歩は、やっぱり入院2〜3日目以降がいい。

## おすすめ

梓音との出会いをこう変えるのが一番いい。

| 日付   | 出会い                |
| ---- | ------------------ |
| 3/25 | 梓音は病院内で蓮華を一瞬見かけるだけ |
| 3/26 | 渡り廊下で初めて目が合う       |
| 3/27 | 中庭で初めて声をかける        |
| 3/28 | 再会。蓮華が少し反応する       |

これなら、1週間内でも無理が少ない。




それが一番自然だと思う。

**3月27日、入院3日目。初めて大学の庭園に出る。そこで蓮華の方から梓音に話しかける。**
この流れなら、無理が少ない。

整理するとこう。

| 日付   | 出来事           |
| ---- | ------------- |
| 3/24 | 暴発事故、保護、京蓮病院へ |
| 3/25 | 検査・安静。散歩なし    |
| 3/26 | 病棟内歩行、廊下程度    |
| 3/27 | 初めて庭園へ。梓音と出会う |

蓮華から話しかける理由も自然にできる。

蓮華は基本的には怯えていて無口。
でも、梓音を見て、

> 綺麗な人だな。
> 怖くなさそう。
> この人なら、怒らないかもしれない。

と思う。

この場合、最初の言葉は重くしない方がいい。

たとえば、

> 「……お姉さん、ここの人ですか」

とか、

> 「……お姉さん、学生さんですか」

くらいが自然。

「綺麗ですね」と直接言わせると、9歳の蓮華には少し作為的かもしれない。
でも、少しズレた素直さとして言わせるならあり。

> 「……お姉さん、きれいですね」

これに梓音が少し驚いて、

> 「え？」

蓮華が慌てて、

> 「ご、ごめんなさい……」

と縮こまる。

この流れはかなり蓮華らしい。

## おすすめの初対面

蓮華は庭園の花を見ている。
梓音は教授に会いに来た帰り、庭園を通る。
蓮華は梓音を見て、花と同じように「綺麗」と感じる。

そこで小さく言う。

> 「……お姉さん、花みたいですね」

これがかなりいいと思う。

蓮華の個性が花と結びついているから、初対面の言葉にも意味が出る。
梓音も「容姿を褒められた」だけでなく、「この子は変わった感性を持っている」と感じられる。

そして蓮華がすぐ謝る。

> 「……ごめんなさい。変なこと、言いました」

梓音はそこで、普通の子供らしさと異常な怯え方の両方を見る。

この出会い方なら、蓮華から話しかけても不自然じゃない。




ここまでの時系列を簡潔かつ端的に整理して。




現時点で確定・仮確定している内容だけを整理するとこうなる。

# 前提

* 時期は2025年3月下旬。
* 梓音は高校1年生の春休み中。
* 数日後に高校2年生へ進級予定。
* 本編主人公が高等部へ進学する直前の出来事。
* 物語期間は約1週間。

# 3月24日（月）

## 魔法暴発事故

* 京都市内で魔法暴発事故が発生。
* 凍結空間の中心で鬼灯蓮華が発見される。
* 男性2名が死亡。
* 京都府警魔道課（伏見・喜多）が出動。
* 蓮華を保護。
* 京蓮学院大学病院へ搬送。

## 蓮華の状態

* 9歳。
* 重度の衰弱。
* 全身に傷跡。
* 無声状態。
* 当夜の記憶を失っている。

---

# 3月25日（火）

## 医療検査

* 京蓮学院大学病院で精密検査。
* 安静状態。
* 散歩や外出はなし。

## 捜査

* 京都府警魔道課が捜査開始。
* 死亡男性2名の身元確認。
* 蓮華の失踪期間や経歴の調査開始。

---

# 3月26日（水）

## 回復段階

* 病棟内での歩行訓練開始。
* 廊下を歩ける程度まで回復。

## 捜査進展

* 事故ではなく事件の可能性が強まる。
* 公安や魔道協会が関心を持ち始める。

---

# 3月27日（木）

## 初めての庭園散歩

* 医師の許可を得て大学病院の庭園へ。
* 付き添いあり。
* 蓮華にとって初めての屋外散歩。

## 梓音との出会い

* 梓音は京蓮学院大学の教授に学びに来ている。
* 帰りに大学庭園を訪れる。
* 偶然、蓮華と遭遇。

### 出会いの形

* 梓音は蓮華の事情を知らない。
* 蓮華の方から話しかける。

理由：

> 「綺麗なお姉さんだな」

と思ったため。

蓮華は警戒よりも先に興味を抱く。

---

# 梓音側

## 立場

* 天宮家は事件に公式介入しない。
* 梓音も天宮家の代表として行動しない。
* あくまで個人として蓮華と関わる。

## 大学へ通う理由

* 京蓮学院大学の教授から学ぶため。
* 事件を調べるためではない。
* 蓮華との出会いは完全な偶然。

---

# 現時点での関係性

### 蓮華 → 梓音

* 第一印象は「綺麗なお姉さん」。
* 自分から話しかける。
* まだ恋愛感情ではなく純粋な憧れや安心感。

### 梓音 → 蓮華

* 最初は事情を知らない。
* 痩せた不思議な少年という認識。
* この出会いをきっかけに少しずつ気にかけるようになる。
