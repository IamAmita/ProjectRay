# 1946年2月・御三家の境遇・検討事項

**作成日：** 2026-09-09  
**状態：** 検討開始。ユーザーから、初動を考える前提として御三家の境遇を検討する必要があるとの指摘を受けて作成。

> 各家の1946年の当主、戦時中の活動、占領下の処遇は未確定。
> 以下は既存設定の確認、史実上の検討材料、創作上の選択肢を区別して記す。個々の家を戦犯・公職追放・財閥解体などの対象と決定するものではない。

## 1. 初動案との関係

[発見直後の初動案](1946年2月・発見直後の初動案.md)では、神原家が専門家を早く派遣し、他二家の正式代表は後から加わる可能性を置いた。しかし、その行動には次の前提が必要になる。

- 政府が連絡できる代表者がいる。
- 調査へ参加できる立場の専門家がいる。
- 船・資材・旅費を調達できる。
- 日本政府と占領当局が、その人物・組織の参加を認める。

したがって、家の性格だけで初動を決めず、**戦前・戦中の国家との関係→敗戦時の損失と処遇→1946年2月に実際に動かせる人・物・権限**の順で考える。

## 2. 既存設定から確認できること

| 項目 | 既存の記述 | 1946年への適用上の留保 |
|---|---|---|
| 神原家 | 主拠点を持たず、豊葦の主拠点化を目指す | 主拠点がないことは、住居・資産・企業・人脈が一切ないことを意味しない |
| 天宮家 | 京都に主拠点。豊葦では儀礼・神域性を重視 | 戦時中に国家神道・宮中・公的機関とどう関係していたかは未確定 |
| 龍崎家 | 白河に主拠点。豊葦では防衛・危険管理を重視 | 陸海軍への所属、軍需事業、家独自の組織の有無は未確定 |
| 御三家の優位 | 魔法の才能に加え、教育・秘術・人脈・資産が強さを支える | 1946年に誰が生存し、どの教育・継承基盤が残ったかは未確定 |
| 大戦と魔法 | 魔術師が戦局へ強く影響し、戦後に秘匿されていた魔術師の調査が進む | 日本の御三家が具体的にどの戦場・機関で活動したかは未確定 |
| IMA | 1947年設立 | 1946年2月の境遇を、設立後の制度だけで説明しない |

## 3. 史実上、分けて確認する必要がある制度

### 3-1. 人物の公職追放と、団体の解体

1946年1月4日、SCAPIN-548による団体の解散等と、SCAPIN-550による公職からの排除が指示された。[S1・S2]

公職追放、戦争犯罪に関する捜査・拘束、復員・武装解除、団体解散は同一の処遇ではない。元軍人や当主というだけで、すべての制約が同時にかかるとはしない。人物の職歴・行動と、関与団体の性格を確認する。

SCAPIN-548は軍事的・準軍事的訓練を行う団体等も対象としている。魔法の教育機関や家の警備組織を設定するなら、その活動が民間の教育・安全管理なのか、軍事組織の維持なのかが論点になる。[S2]

**時点の注意：** 指令の発出、国内の実施措置、個人への処分を同じ日付と扱わない。2月11日時点で特定人物の追放・拘束が済んでいるとする場合は、別途根拠・経緯が必要。

### 3-2. 宗教・祭祀と国家の関係

1945年12月15日のSCAPIN-448（神道指令）は、国家神道への公的支援や国家との結びつき等を廃する一方、私的・自発的な信仰や支援を一律に禁止したものではない。[S3]

天宮家を祭祀に関わる家とする場合、次の区別が必要になる。

- 家や民間の宗教・祭祀として続けられること。
- 公費、官職、国家儀礼との関係を失う可能性がある部分。
- 魔法上の実務と宗教儀礼の境界。

祭祀に関わることだけで国家神道の中枢だったと決めず、戦前の実際の立場から考える。

### 3-3. 資産と、利用可能な資金

2月17日の預金封鎖は発見日の後に起きるため、2月11日の初期状態と、その後の制約を分ける。[S4]

土地・会社・証券・預金・船・倉庫・資料・工具などを区別し、所有者と処分・利用権限も確認する。財閥解体についても、御三家全体を一括判定せず、企業群の構造・支配関係と実施時期を検討する。[S5]

## 4. 各家について埋めるべき項目

| 項目 | 確認すること | 初動への影響 |
|---|---|---|
| 国家との戦前・戦中の関係 | 軍・官庁の指揮系統に入ったか。契約・協力関係か。独自組織を保ったか | 政府から照会される理由、占領当局の警戒 |
| 戦時中の活動 | 戦闘、研究、教育、治療、軍需、祭祀など。役割は家全体と個人で分ける | 戦後の評価、資料の所在、活動制限 |
| 当主と代表者 | 年齢、所在、健康、生死、復員状況、代理人、決裁権 | 誰が報告を受け、派遣を決められるか |
| 人員の損失と継承 | 戦死・負傷・未復員、資料散逸、後継者の経験 | 調査へ出せる専門家と、家に残すべき人員 |
| 資産 | 国内外の資産、空襲被害、企業、現物、預金、負債 | 実際の調達力・継続費用 |
| 公的地位 | 官職、家格・爵位の有無、国家からの役務・収入 | 敗戦後に失った権威や収入 |
| 占領当局との接点 | 既に把握・調査されているか。協力実績はあるか | 許可を得やすい人物・出せない人物 |
| 他二家との関係 | 戦時協力、対立、損失への責任、情報共有 | 単独で動くか、共同名義が必要か |
| 一般社会の評価 | 保護者、特権層、戦争協力者など、誰がどう見ているか | 地元協力、政府が起用する際の負担 |
| 1946年の優先課題 | 家の存続、復員者支援、研究再開、資産維持、名誉回復など | 豊葦の調査に資源を割く理由 |

## 5. 国家との関係を考える選択肢

> どれも未採用。三家共通とも限らず、同じ家でも部門・人物によって組み合わせがありうる。

| 案 | 戦時中の構造 | 敗戦後に生じうる境遇 |
|---|---|---|
| 国家機構へ深く組み込まれていた | 当主・一族・門下が軍や官庁の職務を担う | 公的な指揮権・収入・所属を失い、家の活動を組み直す必要がある |
| 民間の組織を保って国家へ協力した | 家の教育・研究・事業基盤を保ち、人員・技術を提供する | 基盤が残る可能性はあるが、契約喪失や活動内容の審査に直面する |
| 国家と一定の距離を保ち限定協力した | 必要な場面だけ協力し、秘術・人員を独自管理する | 制度上の損失が比較的小さくても、秘匿能力や動向を警戒されうる |

「国家から独立していたから戦後も自由」「国家に協力したから全員拘束」と単純化しない。

## 6. 三家の差を作るための仮説

> 以下は検討の糸口。既存の役割から考えられる例であり、境遇を確定するものではない。

| 家 | 検討できる仮説 | 決める前に必要なこと |
|---|---|---|
| 神原家 | 主拠点は持たないが、人材・研究・企業のつながりが分散して残り、代理人が早く動ける。豊葦は新しい活動基盤の候補となる | 戦前の収入源、戦争への関与、当主と代理人の権限。後の成功のために初期条件を優遇しすぎない |
| 天宮家 | 伝承・教育・祭祀の基盤は残る一方、公的な役割や支援の再編が課題となっている | 国家儀礼・神社・公費との具体的関係。京都を拠点とすることだけで被害や存続を断定しない |
| 龍崎家 | 危険対応に熟練した人材がいても、復員・組織再編・代表者の処遇が派遣を難しくする | 実際に軍に所属していたのか、誰が未復員・活動制限下なのか。防衛重視というだけで軍歴を確定しない |

魔法能力が残ること、組織を指揮できること、政治的発言力があること、資金を支出できることは別々に扱う。

## 7. 推奨する検討順

1. **戦前・戦中、御三家は国家とどのような関係だったか。** まず共通の制度を置き、その中で各家の違いを考える。
2. **1945年の敗戦時に、各家の誰と何が残ったか。** 当主・代理人・専門家、資産、資料、教育基盤。
3. **1946年2月11日、その人と組織は何をできるか。** 職務・活動制約・資金・移動・決裁。
4. その結果を初動案へ戻し、政府の照会先、神原家の初回参加、他二家の到着時期を検証する。

既存の「神原家が初回に参加」を必ず正当化するために、他家の拘束・損失を先に決めない。境遇から行動を導き、整合しない場合は初動案を見直す。
