# 1946年の前提条件・調査結果

**調査日：** 2026-09-09  
**記録日：** 2026-09-09  
**目的：** 豊葦の歴史を1946年からシミュレーションするため、当時の政治・行政・経済・交通の条件を整理する。

> **本ファイルの位置づけ：**
> 会話で調査した史実と、その調査から導いた考察用の仮定を保存する。
> 第1〜4節は史実・史料上の注意点、第5〜7節は創作への適用案・未調査事項として区別する。
> 創作への適用案は確定設定ではない。実在の指令が、架空の豊葦島の帰属や調査許可を実際に定めていたという意味ではない。

### 1-1. 伊豆諸島の一時的な行政分離

SCAPIN-677の第3項は、伊豆諸島などを、その指令において定義する日本の範囲から除外している。第1項は、その範囲外で日本政府が行政権を行使することを停止するよう指示している。[S3]

第2項には、範囲外の官吏・住民との日本政府による通信についても制約がある。ただし、許可された海運・通信・気象業務の通常運用などの例外がある。**あらゆる通信が全面的に途絶した、とまではこの指令から言えない。** 発見報告の具体的な伝達経路は別途検証する必要がある。[S3]

SCAPIN-841は、1946年3月22日に伊豆諸島と孀婦岩以北の南方諸島を対象範囲へ戻し、連合国軍最高司令官の権限に服する形で日本政府の行政権再開を指示している。[S4]

**両指令は最終的な領土帰属を決めたものではない。** それぞれに、ポツダム宣言第8項に関する最終的な島嶼の処分を示すものではない旨がある。「行政権からの除外」「米国領への変更」「無主地化」を混同しない。[S3・S4]

### 1-2. 当時の組織・自治体名

- **海上保安庁は1948年発足。** 1946年の登場機関として置かない。水路部は当時、運輸省に属する。[S6]
- **海軍省は1945年12月に廃止済み。** 旧海軍関係者・旧資料・復員関係機関が存在することと、海軍が現役組織として活動することは分ける。[S2]
- 八丈支庁は1926年に設置されている。[S11]
- **現在の八丈町の成立は1955年4月1日。** 1946年の窓口を一括して「八丈町役場」と呼ばず、当時の村役場・八丈支庁のどちらが対応するかを特定する。[S12]

## 2. 資金・人員・生活基盤

### 2-1. 預金封鎖と調査費

1946年2月17日に金融緊急措置令が公布・施行された。旧銀行券を金融機関へ預け入れさせ、既存の預金とともに封鎖し、生活費・事業費などに限って新銀行券による払い出しを認める措置が取られた。[S7・S8]

このため、考察では次の三つを分ける必要がある。

1. 保有資産の総額。
2. 手元にある船・倉庫・工具・食料などの現物。
3. 調査事業のために実際に支出できる資金。

「資産家なら巨額の調査費を即時に自由支出できる」とも、「預金封鎖で一切の事業支出ができない」とも置かない。特定の調査への払い出しや予算措置の具体的な手続は未調査。

### 2-2. 財閥解体

1946年には、企業の所有・経営の民主化と財閥解体を進める持株会社整理委員会が設置された。[S9]

有力な家系というだけで、特定の企業群が自動的に解体対象になるわけではない。会社の所有構造、同族支配、事業内容、戦時中の関与などを設定したうえで、当時の制度との関係を調べる必要がある。

### 2-3. 食料と人口移動

終戦後は引揚げ・復員に伴う人口の受け入れが課題となり、1946年には農家人口調査、1947年には食糧管理や農地改革等に対応する臨時農業センサスが実施された。[S13]

ここからの**推論**として、新しい土地の農業利用・就業先への期待は考えられる。ただし、それだけで遠隔地への大量移住が可能になるわけではない。移住者の輸送、最初の収穫までの食料、住宅、医療、農具・種苗などの供給を別々に考える。

1946年の八丈島における食料・燃料の配給量、利用可能な船、余剰人員の規模は、今回の調査では確認していない。

## 3. 移動・調査・小笠原の条件

### 3-1. 航空調査

SCAPIN-301は、1945年末までの民間航空組織の解体や、同年末以降の日本側の航空機の購入・所有・所持・運航等の禁止を指示している。[S5]

1946年初頭の日本側調査団が、独自に航空機を調達して自由に飛ぶ前提は採用しにくい。航空偵察や空中写真が必要なら、占領当局側の実施・協力、または個別の許可の可能性を検討する。具体的な航空部隊や飛行場は未特定。

### 3-2. 海上調査

運輸省水路部を海図照合・測量の実務主体候補にできる。[S6]

ただし、このことは「任意の船がいつでも調達できる」「任意の海域へ許可なしで航行できる」ことの根拠にはならない。利用する船の種類・所属・出港地が決まった段階で、占領下の海運統制、航行可能区域、燃料調達、現地の港湾状況を追加調査する。

### 3-3. 小笠原は別の経緯を持つ

小笠原諸島は戦後、米国の占領下に置かれ、日本への返還は1968年6月26日である。[S14・S15]

この史実を採用する場合、1946年から小笠原を日本政府・東京都が自由に開発・行政再編できる地域として扱わない。伊豆諸島の1946年3月の行政権再開と、小笠原の1968年の返還を区別する。

## 4. 誤解しやすい点

| 誤って置きやすい前提 | 調査上の扱い |

| 伊豆諸島が一時分離されたので、米国領または無主地になった | SCAPIN-677・841は行政権の範囲に関する指令。最終的な領土帰属の決定とは別 |
| 2月11日の発見報告は通常どおり届いたはず | 当時の通信制約と例外、現地の設備・運用を確認する必要がある |
| 最初の発見者・上陸者が土地全体を所有できる | 発見、調査許可、行政帰属、所有権、開発権を分けて検討する |
| 1946年の調査隊に海上保安庁や現役の海軍省が参加する | 当時の実在組織へ置き換える |
| 八丈島の窓口は八丈町役場である | 八丈町成立は1955年。当時の村役場・八丈支庁を検討する |
| 私有の飛行機で自由に測量できる | 民間航空への占領政策を踏まえ、占領当局側の関与を検討する |
| 大資産家なら資金調達に制約がない | 預金封鎖、企業支配の改革、現物資産を区別する |

## 5. 歴史シミュレーションへ適用する前提案

> **以下は創作上の仮定。史実・確定設定とは区別する。**

### 5-1. 史実との差異の置き方

- 魔法の存在と大戦での利用は作品の既存設定を維持する。
- 一方、1945年の日本の敗戦、1946年の占領体制、内閣・行政機構・経済措置は、まず史実に合わせて開始する。
- 戦前の御三家の軍事的関与、戦後の監督・処遇は未確定として残す。
- 連合国側にも魔法の知識・専門家がいるものとする案。日本側だけが魔法を理解する状況にはしない。
- 既存設定ではIMAの設立は1947年。1946年の許認可主体として、設立後のIMAや条約体制を先取りしない。

### 5-2. 1946年2月11日の発見

- 既存設定の発見日と、八丈島南部の漁師による目撃を出発点とする。
- 豊葦島はその日に隆起した島ではなく、以前から存在した土地への視認・接近が可能になったとする。
- 霧が晴れた理由、再び接近不能になる可能性は、当事者には分からない。
- 島の正確な面積、飲料水の安全性、耕作適性、火山活動、長期滞在の影響は未調査として開始する。
- 虹命樹は観察対象であり、経済価値・軍事的利用可能性が初日から判明しているとはしない。
- 八丈島から樹冠が見える条件は、別途、距離・標高・観測位置を確認する。

### 5-3. 行政上の扱い

- 日本政府は旧海軍の記録と現地報告を整理し、占領当局へ調査を申し出る案。
- 豊葦島は実在のSCAPINに記載された島ではないため、位置と対象区域の解釈を確認する個別のやり取りを創作する。
- 恒久的な行政帰属を決める前に、短時間の調査だけ認められる案を置く。
- 東京都への編入や、国の直接管理を初期条件として自動確定しない。

### 5-4. 第一次上陸を維持する場合の案

既存設定の「2月中旬、政府・神原家中心の約10人が短時間上陸」を維持する場合は、次の補足案を使える。

> 発見情報を占領当局へ速報し、恒久的な帰属判断とは切り離して、予備調査に限った許可を得る。調査記録の提出、持ち帰り試料の申告、恒久施設を建設しないことなどを条件とする。

これは史実上の許可が確認されたという意味ではない。連絡・許可に必要な日数や、占領当局側担当者の参加の有無は未確定。

### 5-5. 調査隊と補給

- 日本側の初動は船を基本とする。
- 食料・燃料・医薬品は持ち込み。現地の水・植物を直ちに補給源へ数えない。
- 船員・機関士・医療担当など、調査以外の維持要員も必要とする。
- 港湾・道路・住居が未整備の土地として、上陸地点と天候に活動を左右される。
- 魔法は作業補助や局所的な危険回避に使えても、大量輸送・食料・燃料を無制限に代替できないという仮定で始める。
- 神原家の初動の優位は、無制限の現金ではなく、既に確保している現物資産・人員・人脈・伝承知識に置く。

## 6. 当事者の動機・関係の初期案

> 各当事者の行動は、この動機からシミュレーションする。行動の結果はまだ決めない。

| 当事者 | 得たいものの案 | 警戒するものの案 |
|---|---|---|
| 占領当局 | 未知の魔法現象、旧日本軍との関係の把握 | 秘匿兵器・研究施設・武装集団 |
| 日本政府 | 調査への継続的関与、行政上の足場 | 日本側を排除した管理、事故の責任 |
| 東京都・現地行政 | 住民と航行の安全、報告・連絡体制の維持 | 責任・費用だけが増えること、指揮系統の混乱 |
| 神原家 | 調査の主導権、将来の拠点 | 他家や占領当局による独占 |
| 天宮家 | 聖地の確認、祭祀への関与 | 調査・開発による破壊 |
| 龍崎家 | 危険管理への関与 | 危険を過小評価した無秩序な上陸 |
| 地元住民 | 航行の安全、漁業、運搬等の収入 | 漁場への立入制限、補給物資の圧迫 |

神原家は「監督を受けながらも、現場では必要とされる協力者」から始める案。後の都市支配・政治力が1946年時点で完成しているとはしない。

八丈島・小笠原を将来の豊葦県に含めるというユーザー確認は到達条件として維持する。ただし、1946年の当事者が最初からその将来を構想・合意しているとは置かない。

## 7. 次に確認・選択する事項

| 論点 | 必要な確認・選択 |
|---|---|
| 発見地点 | 八丈島のどの村・どの海岸から目撃したか。樹冠が見える距離・標高か |
| 通信経路 | 漁師→村役場・八丈支庁→東京→占領当局の実際の手段と所要時間 |
| 豊葦島の位置 | 正確な緯度経度と、伊豆・南方諸島の行政範囲との関係 |
| 日本側の窓口 | 関係省庁、東京都、占領当局との連絡機関の担当をどこまで具体化するか |
| 船と補給 | 出港地・船種・所属・乗員数・燃料・航行許可・退避先 |
| 旧海軍記録 | 記録の保管先、生き残った担当者、誰が照合できるか |
| 御三家の戦後処遇 | 戦争への関与、監督、資産・会社の所有構造、使用可能な人員 |
| 占領当局の関与 | 許可だけか、同行・独自調査を行うか。担当部門や軍の具体化は追加調査が必要 |
| 魔法による差異 | 航行・通信・建設・補給のどこを変え、どの制約を残すか |
| 情報公開 | 島の存在、調査成果、軍事的評価のそれぞれを誰まで共有するか |
