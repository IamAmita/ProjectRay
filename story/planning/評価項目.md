# 評価項目

## キャラクター
1. 読者にとってキャラクターは魅力的か
2. 掛け合いが魅力的に書けているか
3. 共感したくなる主人公か
4. 適切なキャラの配置・書き分けができているか

## ストーリー
1. 物語の方向性がはっきりしているか
2. 読者を楽しませるストーリーをつくれているか
3. 読者の予想を上回ろうとしているか
4. 題材、キャラクター、設定が物語に活かされているか

## 世界観・アイデア
1. 読者の興味・関心を引きつけられる題材か
2. 新規性のあるアイデアか
3. 世界観や設定に矛盾は無いか
4. 作品世界にリアリティがあるか

## 構成力
1. 物語の導入からおもしろいか
2. 起承転結のメリハリがあるか
3. テンポよく読み進められるか
4. 終盤がしっかりと盛り上がっているか

## 文章力
1. 読みやすく、書きこなれた文章か
2. 文体は魅力的か
3. 用字用語に誤りがなく適切か
4. 過不足ない状況描写ができているか
