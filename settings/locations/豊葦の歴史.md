### 第II期：調査と開発の始まり（1952〜1975）

**骨組み（2026-10-30採用。「決定記録」）：**

| 時期 | 出来事 | 神原家の動き |
|---|---|---|
| 1950年代 | 資金が戻る。主権回復後、神原系の企業が集まり直し、神原グループの原型ができる | 神原家が豊葦に金を出せるようになる |
| 1950〜60年代 | 研究者が集まる。豊葦島と虹命山は重要な調査対象であり、研究者が集まるのは自然な流れ（作者） | 国の研究機関を東京の外へ移す構想（1961年の官庁移転の閣議決定、1963年の筑波研究学園都市の閣議了解）にも乗る |
| 1960年代 | **保護ではなく開発へ。** 重要な土地を、中心部を除いて保護ではなく開発に持っていく。ここを神原家が無理矢理に押し切る（作者） | 国有地の払い下げで神原系の開発会社が土地を得て、港（藤港）を築く。押し切る具体的な流れは検討中 |
| 1960年代後半 | 港の整備と合わせて、藤港の沖の浅瀬を埋め立てた小さな飛行場が開港する（2026-11-01採用。「決定記録」） | 神原系の企業が港と一体で造る。管理は東京都 |
| 1960年代 | 天宮家への手当て。虹命山の一帯を国立公園として開発から外す（既存の虹命山国立公園） | 祭祀の場は守られるが、それ以外は神原家が開発する |
| 1960年代〜 | 家族で住む人が増え、町村が置かれる。1975年に約4万人 | 町村の名前と時期は `豊葦県成立史.md` 論点F |

**保護ではなく開発へ（2026-10-30採用。「決定記録」）：**

普通なら、島全体を守る方向に話が進む（現実の類例：南硫黄島は1975年に島全体が原生自然環境保全地域に指定され、1983年に全域が立入制限地区となった）。保護を求めるのは、保護派の研究者（手つかずの島そのものが研究対象）、文部省（天然記念物。1950年の文化財保護法）、厚生省（当時の国立公園の所管。1957年の自然公園法）、天宮家（神域）。神原家は次の五段階で押し切る。

| 段階 | 時期 | 神原家の手段 |
|---|---|---|
| ① 線引きの根拠を握る | 1950年代 | 調査団の記録を握る神原家が、総合調査の報告で「学術上かけがえがないのは虹命山の中心部」とまとめる。保護すべき範囲を、最初から中心部に絞った形で示す（知恵） |
| ② 研究者を割る | 1950年代〜 | 資金の戻った神原家が、研究所の拡張に要る港・電力・宿舎・病院を整え、研究費も出す。研究を続けたい研究者ほど神原家の整備に頼り、島全体の保護を訴える研究者は少数派になる（金） |
| ③ 「住まなければ守れない」 | 1950〜60年代 | 火山とカルデラの海域を観測し続けるには、人が住み、港と道路が要る、と主張する。既存の年表の「都市開発・防災研究の中核化」をこの名目として読む |
| ④ 先に造る | 1960年代 | 研究の付帯設備として港と宿舎を造り、そこから町へ広げる。払い下げは後から形を整える |
| ⑤ 線を引く（決着） | 1960年代 | 人脈で厚生省・文部省に入り込み、国立公園の特別保護地区（開発を最も厳しく制限する区域）を虹命山の中心部に絞らせる。天宮家には祭祀の場が守られることで手を打たせる。島の残りは開発に回る（人脈） |

**決めること：**
- ~~保護ではなく開発に持っていく流れ~~ → 2026-10-30採用（上表）。
- ~~国立公園の指定年~~ → 2026-10-30採用：1960年代半ば（例：1965年。正確な年は後で決めてよい）。特別保護地区の正確な範囲は未定。
- ~~町村が置かれた時期と名前~~ → 2026-10-30採用：1960年代前半に豊葦村、1960年代末に豊葦町、1970年代後半に豊葦市（「決定記録」）。町村に属さない島に新しく町村を置く法的な手順は未確認。

### 第III期：研究・観光都市（1975〜1989）

**骨組み（2026-10-30採用。「決定記録」）：**

| 時期 | 出来事 | 神原家の動き |
|---|---|---|
| 1970年代後半 | 豊葦市になる。研究所の拡張と高等教育機関化が進む。研究者・学生とその家族が増える | 研究に要る町の整備を、引き続き神原系の企業が担う |
| 1980年代 | 観光都市として、温泉や保養地の開発が進む（のちの南陽区・桃海区の原型）。1987年6月にリゾート法（総合保養地域整備法。民間の力で保養地を整える法律）が施行される | 民間経済を重んじる神原家の流儀と合う。神原系の企業が開発を担う |
| 1980年代 | 藤港の空港の滑走路を延ばし、ジェット機が飛べるようになる（2026-11-01採用） | 神原系の企業が人工島を広げる |
| 1987〜89年 | 国の地方分散の流れ（1987年の四全総、1988年の国の機関移転の閣議決定）に乗じて、県の設置を押し切る | 上と下から挟む（下記） |

**住民と神原家：** 1989年の約15万人の多くは、研究所・開発事業・観光・神原系の企業で働く人とその家族。雇い主の多くが神原家につながる企業城下町の時代で、神原家への反発は表に出にくい。**第III期は神原家の黄金期**。古くからの二系統（神原財閥の人材と八丈島の人々）は続いている。

**県の設置の押し切り方（上と下から挟む）：**
- **上から：** 国政の人脈を使い、「国の機関を移す受け皿には、400km離れた都庁が支庁で治める形では足りない」として、県を設ける法律を通させる。
- **下から：** 豊葦市の議会と住民に、東京都からの分離を求めさせる。企業城下町なので、神原家は「住民の声」を作れる。
- **東京都：** 区域と財源（神原系の企業からの税収）を失うこと、戦後に例のない県の新設であることから反対するが、国策と「地元の声」に挟まれて押し切られる。

**含み（未決定）：** 八丈島は、この押し切りの中で、ほとんど声を聞かれないまま同時に編入されたことになりうる。八丈島の人々の「見つけたのは自分たちだ」という思いに、もう一つ不満が重なる可能性がある。

**決めること：** 県の設置を押し切った神原家の人物と、国政側の協力者。

**第III期は以上で一区切り（2026-10-30）。**

### 第IV期：県の急成長（1989〜2010）

**骨組み（2026-10-30採用。「決定記録」）：**

| 時期 | 出来事 |
|---|---|
| 1989年4月 | 県の設置。初代知事は中央省庁出身の官僚。神原家は直接担がないが、有権者の多くが神原家につながる企業で働いていたため、神原家に好意的な候補として当選する（`豊葦県成立史.md` 論点G） |
| 1990年代前半 | 国の研究機関の移転が始まる。魔術師とその家族の移住が本格的になる（論点D①）。大学部の前身ができる |
| 1990年代半ば（例：1996年） | 豊葦県特別自治法が成立する。国会で可決され、住民投票で賛成多数を得る（1952年以来、約40年ぶりの憲法第95条の住民投票。論点C）。神原家は天宮家・龍崎家を共同名義に引き込む。1995年の地方分権推進法（5月成立、7月施行）の流れに乗る |
| 1990年代 | 県の港湾計画で堅洲島の開発が始まる。両端の入り江（海峡に面した内海側）に漁港と産業用の港を築き、造船所・化学工場・風力発電を置く。働く人が近くに住む（2026-11-01、工場と漁業の町として改め） |
| 1990年代〜2000年代 | 藤港の空港の人工島を広げ、国際線も受け入れる（2026-11-01採用） |
| 1990年代後半〜2000年代 | 人口が急に増え、1年に約3万人以上ずつ増える（2000年に約50万人）。中等部・高等部が整う |
| 2000年代前半 | 堅洲市が置かれる。新しい住民の多い町で、反神原勢力の地盤になりやすい |
| 2008年ごろ | 豊葦市が政令指定都市の目安（約70万人）を超える |
| 2010年前後（例：2010年4月） | 豊葦市が政令指定都市になり、九つの区が置かれる（`豊葦県成立史.md` 論点I） |
| 2010年 | 約85万人（2026-10-30、2026年を約120万人とした作者決定に合わせて約70万人から変更） |

**住民の変化：** 第III期の住民の多くは神原家につながる企業で働いていた。第IV期に来る新しい住民の多くは、国の研究機関・大学・自分の仕事のために来た人で、**神原家に雇われていない**。神原家の力が「雇い主として」は届かない住民が多数派になっていく。

**反神原勢力（2026-10-30採用。「決定記録」）：** 神原家の考え方（市場の自由・共栄の施策）への反対ではなく、**80年にわたって押し切られてきたことそのものへの反発**。無理矢理に押し切る歴史が、自らの反対勢力を生む。

| 誰が | 何に反発するか | 歴史の中の根 |
|---|---|---|
| 新しい住民（研究者・魔術師の家族） | 島の暮らしと県政が、一つの家の企業に縛られていること。施策の中身ではなく、依存の構造への反発（2026-10-30改め。当初は「選挙で選んでいない家が県政を裏で決めている」決め方への反発としていた） | 島の経済が神原系の企業に依存し、神原家に好意的な知事が続く（`豊葦県成立史.md` 論点G）。県の設置では「住民の声」を作った（第III期） |
| かつての保護派の研究者 | 創設期の総合調査の報告が、開発のために保護の範囲を絞って書かれていたこと | 第II期の①（線引きの根拠を握る） |
| 八丈島の人々 | 見つけたのは自分たちなのに、声を聞かれないまま県に組み込まれたこと | 第I期の最初の住民、第III期の含み |
| 自然保護・神秘保護を掲げる強硬な勢力 | 開発そのもの。虹命山の周りの開発を止め、自然と神秘を守るよう強く求める | 第II期の「保護ではなく開発へ」 |

- **天宮家（作者決定）：** 天宮家自身は、神域の保護について強硬な姿勢をとっていない。自然保護・神秘保護を理由に強硬な姿勢をとる勢力が、天宮家を担ぎ上げようとしている。
- **表に出るきっかけ：** 2000年代、創設期の総合調査の報告がどう書かれたかが明るみに出る。経路は、情報公開の広がり（国の情報公開法は2001年4月施行）か、少数派に追いやられた保護派の研究者が残していた記録。
- **掲げるもの：** 「島のことは島の住民が決める」「残された自然と神域を守る」。人口が急増して開発の圧力が続く中で、虹命山の周りをさらに開発するか守るかが争点になる。
- **選挙：** 2000年代後半、神原家に好意的な候補が知事選挙で一度だけ負ける。

**反神原の知事と、神原家の奪還（2026-10-30採用。「決定記録」）：**
- 知事選挙は1989年から4年ごと（1993・1997・2001・2005・2009・2013・2017・2021・2025年）と置く。
- **2009年：** 神原家に好意的な候補が負け、反神原の知事が生まれる。国政で政権交代が起きた年で、既存の力への反発が全国で強まっていた。
- **2013年：** 反神原の知事は1期で終わり、神原家に好意的な知事に戻る。理由は二つの組み合わせ。
  - **寄り合いのほころび：** 反神原勢力は、新しい住民・保護派の研究者・八丈島の人々・強硬な保護勢力の寄り合い。強硬な保護勢力が開発の停止を求める一方、人口は年に2〜3万人ずつ増え続けており、開発を止めると住宅が足りなくなり家賃が上がる。暮らしに困る新しい住民が離れる。
  - **民間経済の引き：** 神原系の企業が新しい投資を控え、県の景気が冷える。違法なことはしない。**真相は自然な経営判断**（反神原の県政が開発を止めたため、先行きを見て控えた）だが、反神原勢力は「意図した締め付けだった」と信じている。本編では、どちらが本当なのか島の人々には分からない（2026-10-30採用）。
- **その後：** 反神原勢力は県議会の野党などとして残る。2026年の島には、「神原家に好意的な県政に戻ったが、一度は負けた」という緊張が続いている。
- **島の経済（2026-10-30作者決定）：** あらゆる分野で、元をたどれば神原系のグループにたどり着く（`豊葦県.md`「神原系の浸透」）。

### 2026-10-30：1946年2月の神原家の状況（案A）

- **決定：** 案Aを採用（AIの推奨を作者が採用）。**神原家の財閥は財閥解体の最初の対象となり、財産を自由に動かせない。ただし、魔道の人材と知識、各地の企業や人とのつながりは帳簿に載らないため残る。** 1946年の神原家は、豊葦に大きな金は出せず、人と知恵と人脈で割り込む。
- **史実：**
  - 1945年11月6日、SCAPIN-244が三井・安田・住友・三菱の本社の解体計画を承認し、財閥家族の財産の移動を禁じた。作中では、明治期以来の日本一の財閥である神原家の本社もこの最初の対象に入る。
  - 1946年2月17日、預金封鎖（発見の6日後）。
  - 1946年4月20日、持株会社整理委員会令により、解体を進める機関ができた。最終的に、解体対象の持株会社は83社、財閥家族として指定されたのは56名。
  - 出典：SCAPIN-244（https://jahis.law.nagoya-u.ac.jp/scapindb/docs/scapin-244 ）、アジア歴史資料センター「持株会社整理委員会」（https://jacar.go.jp/english/glossary_en/term1/0110-0010-0050-0010-0020.html ）。
- **理由：**
  - 2026-09-09の検討メモの仮説「主拠点は持たないが、人材・研究・企業のつながりが分散して残り、代理人が早く動ける」と合う。同メモの「初期条件を優遇しすぎない」とも合う。
  - 金が使えないからこそ、人脈と交渉で無理矢理に押し込む。富と交渉の家（`../organizations/御三家.md`）らしい介入の仕方になる。
  - 財閥という家の土台を失った直後に桃源郷が現れる。「神原の悲願」が最も切実になる。
  - 史実でも、旧財閥の企業は1950年代に企業集団として集まり直した。現代の神原グループ（財閥の名残）もこの流れで説明できる。

### 2026-11-01：堅洲市を約6万人の町とする

- **決定：** AIの推奨を作者が採用。**堅洲市は約6万人**とし、**漁業・造船・風力発電を柱に、台地の牧畜・農業、観測施設、危険物を扱う化学工場を加えた町**とする。減らした約18万人は豊葦市に移し、豊葦市は約113万人（県全体の約120万人は変えない）。
- **理由（AIの評価）：** 楽園の方針がなければ、工業も豊葦島に置ける（蒼海区は工業区画）。堅洲島に人が住む理由は、豊葦島ではできないこと、または堅洲島のほうが向いていることに絞られる。漁業（両端の入り江から外海の漁場へ）、造船（長い海岸線と深い内海）、風力発電（外側の台地は一年の大半で西・南西の風が素直に吹く）は自然さが高い。牧畜・観測は中程度。化学工場は豊葦島の中でも離して置けるので決め手にならない。この役割なら数万人が自然で、24万人を支える理由は足りない。
- **豊葦市：** 約113万人でも、島の密度は約940人/km²で、沖縄本島（約1,060人/km²）より空いている。九つの区とも合う。政令指定都市への移行（2010年前後）は、豊葦市が約70万人を超える時期が少し早まるが、そのままでよい。
- **港：** 堅洲島の両端の、北西・南東の海峡に面した内海側の入り江に置く（同日の検討による）。

### 2026-11-01：発見前の異常は今どうなっているか（未確定事項一覧 3-9①②）

- **作者の確認：** 虹命樹の電磁代謝層は、反転二重螺旋構造で電磁場を体内で相殺している（`虹命樹.md`）。AIが先に出した「虹命樹の電磁代謝が外に働いて方位や計器を狂わせていた」という案は、この設定と食い違うため取り下げた。
- **決定：** AIの推奨を作者が採用。発見前の異常を三種類に分ける。
  - **霧そのもの：** 虹命樹の大量の蒸散（1日15,000〜40,000トン）と山の高温雲霧環境による物理的な霧として、今も虹命山の周りに残る（原稿の「普段は霧に覆われている」）。
  - **魔法の作用**（島が見えない、方位感覚・距離感覚の狂い、船が進路をずらされる。「魔法の霧」の本体）：**1946年に無くなった。** 消えるまでに数週間〜数か月の短い期間があってもよい。
  - **計器の狂い：** 方位計のずれは、火山島の岩石（磁鉄鉱を含む玄武岩・安山岩）による自然の現象として今も残る。一般の海図の「磁気異常・航行注意」はこの意味でも正しい。1946年2月中旬の第一次上陸の「方位計の異常・無線通信不良」も、この自然の現象と当時の無線機の性能で説明できる。
- **理由（AIの評価）：** 「突如として霧が晴れた」という出来事と合う。虹命樹は電磁場を外に漏らさないので、作用を残すには別の仕組みが要る。空港・港・モノレールのある都市が80年かけて育ったことと両立する。
- **作者の言葉：** 「豊葦島はもともと、魔法の霧によって隠れていた秘島である」（2026-06-30。`../../notes/chat_history/2026/06/30/舞台設定.md`）。同日にAIが挙げた霧が晴れた理由の候補（戦争の影響、虹命樹の周期、古代の結界の限界、意図的な解除、敗戦が条件）は、作者の採用の記録がない。
- **未定（作中の謎として後で決める）：** 魔法の霧の原因（何が島を隠していたのか、なぜ1946年2月11日に止まったのか）。

### 2026-11-01：世界遺産「虹命山と虹命樹」（未確定事項一覧 3-9⑤）

- **決定：** AIの推奨を作者が採用。旧記述「豊葦県：自然文化複合遺産」を、名前「虹命山と虹命樹」の自然と文化の複合遺産に改めた。現実の日本に複合遺産はないため、日本で唯一の複合遺産になる。
- **自然の価値：** 虹命樹、固有の生態系、カルデラと再生ドーム、今も動く地盤。
