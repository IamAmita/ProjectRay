# 魔道庁

> **本ファイルの位置づけ:**
> 日本の国の魔道行政を担う官庁と、その成立の経緯を管理する。作品世界の設定であり、確定事項・未確定事項を区別する。
>
> **作成日：** 2026-10-10

---

## 基本情報（2026-10-10確定）

| 項目 | 内容 |
|------|------|
| 名称 | 魔道庁 |
| 位置づけ | **内閣府の外局**（現実の金融庁などと同じ格） |
| 発足 | 1948年1月、魔法省の廃止（1947年12月31日）と同時（2026-10-19確定） |
| 所属の変遷 | 総理庁の外局（1948年〜）→ 総理府の外局（1949年〜）→ 内閣府の外局（2001年〜）。現実の中央省庁の再編に従う（2026-10-19確定） |
| 前身 | 魔法省（1871年〜1947年。`魔法省.md`） |

## 役割（2026-10-10確定）

- 魔道行政の企画・立案
- 特別指定魔道士の事務（内閣総理大臣による指定の補佐。`../world/魔法体系.md`「特別指定魔道士」）
- IMAへの報告（国際魔道条約第3条・第4条の締約国義務。`国際魔道協会.md`）
- **JMAの監督**（JMAは特殊法人。2026-10-10確定。`日本魔道協会.md`）
- **IMAとの窓口**：国内の機関（警察・JMAなど）がIMAへ照会・協力要請するときは、魔道庁を通す（2026-10-21確定）
- **（発足からJMA設立まで）魔術師の登録・測定を暫定的に直接行った**（2026-10-19確定。下記「成立の経緯」）

内閣府の外局とすることで、医療・教育・安全保障にまたがる魔法を一つの省に縛らずに扱える。総理による特別指定とも直結する。

IMAへの報告を魔道庁が担うため、**JMAが正確なデータを集め、魔道庁が何を報告するかを決める**という構図になる。国家による秘匿・過少指定（`国際魔道協会.md` 第4条）が起きうるのはこの段階である。

**天宮前日譚での隠蔽（2026-10-21確定）：** 魔道庁は、体面と外交上の配慮から、鬼灯蓮華の件を伏せる。蓮華の登録を「保護・捜査中」を理由に先延ばしし、2025年春に資金源の調査がIMAに突き当たっても照会を上げない。明確な指示ではなく、幹部の方向づけと周囲の忖度による。IMA医療保健委員会の委員とは示し合わせていない（`../stories/天宮前日譚.md`「日本の側の能動的な隠蔽」）。

## 成立の経緯（2026-10-10確定）

| 時期 | 出来事 |
|------|--------|
| 1871年（廃藩置県の直後） | **魔法省**が置かれる。目的は魔術師の把握・管理（2026-10-19確定、`魔法省.md`）。地方に管轄局を持ち、関西管轄局には治安維持部があった（`京都府警.md`） |
| 1947年12月31日 | **魔法省が廃止される。** 現実の内務省と同じ日。占領当局が魔法を扱う強大な官庁を危険視した（日付は2026-10-19確定） |
| 解体後 | 機能が分割される。登録・測定は国から距離を置いた**協会（JMA）**へ、政策と監督は**魔道庁**へ、治安は**警察の魔道部門**へ、教育（管轄局の養成機関）は**文部省**へ（教育は2026-10-19確定、`魔法省.md`） |
| 1948年1月 | **魔道庁が発足する**（総理庁の外局）。JMAが設立されるまで、登録・測定を暫定的に直接行う |
| 1951年ごろ | 日本が占領当局の了承を得て国際魔道条約に加盟し、JMAが設立される。登録・測定はJMAへ移る（`日本魔道協会.md`、`国際魔道協会.md`） |

**空白期間の意味（2026-10-19）：** 魔法省の廃止からJMAの設立までの約3年間、魔術師の名簿は占領下の魔道庁が持っていた。占領当局がこの名簿をどう使ったかは、軍が抱えていた「名簿の外の魔術師」（`魔法省.md`「戦時の軍との関係」）の戦後の扱いにつながる（未確定）。

「省」ではなく「庁」であるのは、産業革命以降の魔法の価値の低下（`../world/魔法の分類.md`「成立史」）と、戦後の魔法への恐怖（IMA設立と同じ原点）が重なった結果である。

## 関連する組織

| 組織 | 役割 |
|------|------|
| JMA（日本魔道協会） | 登録・測定・資格・統計。IMA条約の国内実施機関（`日本魔道協会.md`） |
| 警察（都道府県警の魔道課、警視庁公安部魔道課） | 刑事事件と治安（`魔道警察.md`） |
| 都道府県の魔道部門 | 地方の魔道行政。豊葦県には魔道局がある（`../locations/豊葦県.md`）。他県の体制は未定 |

## 未確定事項

- 魔法省の解体に至る占領当局の判断の詳細（日付は1947年12月31日と2026-10-19確定）
- 空白期間（1948年〜1951年ごろ）に、占領当局が魔道庁の名簿をどう使ったか。名簿の外の魔術師をどう扱ったか
- 魔道庁の内部組織、長官、職員規模。天宮前日譚で方向づけをした幹部の役職・人物像
- 魔道庁によるJMA監督の具体的な範囲（役員人事・予算・業務計画など）
- 都道府県の魔道行政の体制（豊葦県の魔道局と他県の違い）
