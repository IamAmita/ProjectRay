# 舞苑学院

## 概説
- 国立魔道学院の一つ
- 中等部・高等部は全寮制
- 外出は自由、帰省の際は申請が必要

## 定員

| 部 | 定員 |
|----|------|
| 保育部 | 50名 |
| 初等部 | 200名 |
| 中等部 | 400名 |
| 高等部 | 600名 |
| 大学部 | 5,000名 |
| 大学院 | 年度ごとに変動 |

---

## 保育部〜高等部

### 部活動

- 運動部：野球　ソフトボール　サッカー　テニス　バスケ　バレー　バドミントン　卓球　陸上　水泳　柔道　剣道　弓道
- 文化部：吹奏楽　合唱　美術　書道　技術　科学
- 同好会：薙刀　新聞　放送

### 黄蝶寮
- 由来：オハイアリイの日本名「黄胡蝶」
- 花言葉：「自分らしく生きる」「輝く個性」
