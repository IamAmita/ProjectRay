# 舞苑学院

## 概説
- 国立魔道学院の一つ
- 中等部・高等部は全寮制
- 外出は自由、帰省の際は申請が必要

## 定員

| 部 | 定員 |
|----|------|
| 保育部 | 50名 |
| 初等部 | 200名 |
| 中等部 | 400名 |
| 高等部 | 600名 |
| 大学部 | 5,000名 |
| 大学院 | 年度ごとに変動 |

### 黄蝶寮
- 由来：オハイアリイの日本名「黄胡蝶」
- 花言葉：「自分らしく生きる」「輝く個性」
- 高等部生全体の寮
- 内部は男子棟・女子棟・共用棟に分かれる
- 共用棟設備：食堂・談話室・自習室・訓練室・医務室・監督官室
- 外出は自由、帰省・島外移動には申請が必要

## 設立経緯

舞苑学院の起源は、豊葦島の自然環境・火山活動・魔道資源・虹命樹を調査するために設置された研究所にある。

### 発展年表（概略）

| 年代 | 出来事 |
|------|--------|
| 1946年 | 豊葦島発見。神原家主導で緊急調査開始 |
| 1947年 | 豊葦島臨時調査団設置 |
| 1950年頃 | 豊葦島総合調査研究所設置（舞苑学院の前身） |
| 1950〜60年代 | 虹命山・虹命樹・豊葦カルデラ・黄泉内海の本格調査。都市開発・防災研究の中核機関となる |
| 1970〜80年代 | 研究都市・観光都市としての基盤整備。高等教育機関化 |
| 1990年代 | 大学部の前身が成立（自然科学・応用科学・魔道学を中心に） |
| 2000年代 | 附設中等部・高等部が整備され、魔術師教育機関として発展 |
| 2010年代 | 国立魔道学院として再編・拡大 |
| 現在 | 豊葦県の教育・研究・魔道行政・都市防災の中核機関 |

## 神原家との関係

- 制度上は国立機関
- 舞苑学院の成立には神原家の計画都市構想が深く関わっており、土地・施設・予算・研究資源の多くに神原家が関与している
- 豊葦県に置かれているため、現在は神原家の影響力が学院内で最も強い
- 「神原家の所有物ではないが、神原家なしには成立しなかった学院」

---

## 学院の性格

- 元が研究所のため研究所気質が残っている（実験施設が多い・学生が研究補助に参加・立入制限区域が存在）
- 「学校」であると同時に国家級研究機関でもある二面性を持つ
- 豊葦県の都市計画・防災・魔道行政と深く関与している

### 舞苑学院保安局
学院内で発生する魔道事故・生徒間抗争・危険術式・外部侵入に対応する内部治安組織。教員・魔道局出向者・元魔道警察官・上級生補助員で構成される。
