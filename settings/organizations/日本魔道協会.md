# 日本魔道協会（JMA）

## 基本情報

| 項目 | 内容 |
|------|------|
| 正式名称 | 日本魔道協会 |
| 略称 | JMA |
| 設立背景 | 第二次世界大戦後、国際魔道条約への署名に伴い設立。条約第2条が締約国に課す**登録制度の実行機関**として、国内法により置かれた（2026-10-10確定）。占領期に解体された魔法省の機能のうち、登録・測定を引き継いだ（`魔道庁.md`） |
| 法的な位置づけ | **特殊法人**（特別の法律により国が直接設立する法人。現実のNHK＝日本放送協会と同じ型）。2026-10-10確定 |
| 監督官庁（国内） | **魔道庁**（内閣府外局） |
| 上位機関（国際） | 国際魔道協会（IMA）。JMAは国際魔道条約の国内実施機関 |

### 特殊法人であることの意味（2026-10-10）
- 条約上の義務を負うのは国家（締約国）であり、その登録制度を実行する機関として国が特別の法律で設置した。国が深く関わって発足したのはこのためである。
- 国から距離を置いた協会でありながら、魔道庁の監督を受ける。国の枠の外には出ない。
- JMAは測定データを正確に集める立場、魔道庁はIMAへ何を報告するかを決める立場にあり、両者の間に緊張が生じうる（`魔道庁.md`、`国際魔道協会.md` 第4条）。
- 根拠法の名称（仮：日本魔道協会法）と設立年は未定。占領期の解体後、1950年前後が自然（現実のNHKの特殊法人化は1950年）。

**物語上の材料（案）：既得権益**
特殊法人は既得権益の温床になりやすい。たとえば次のような形が考えられる（いずれも未確定）。
- 魔道庁からJMA役員への天下り
- 御三家・名家の出身者がJMAの要職を占める
- 登録・測定・資格にかかわる手数料など、独自の財源
- 地方支部が持つ資格認定の裁量（`命脈` の灯の資格維持もこの裁量による）が、地域の利権になる

## 魔術師管理制度

### 出生からの経過観察
出生時に魔法の兆候が見られる、または魔法を持つ可能性の高い家系の出身の場合、
**潜在的魔術師**として経過観察を行う。

### 12歳での判定
12歳までに経過観察を打ち切り、以下に分類する。

| 分類 | 内容 |
|------|------|
| 顕在的魔術師 | 12歳時点で魔法能力が確認された者 |
| 非魔術師 | 12歳時点で魔法能力が確認されなかった者 |

**12歳という基準の性格（2026-10-10確定）：** 発現年齢に固定された上限はなく、12歳は「統計的にほぼすべての発現が出そろう」ことに基づく手続き上・便宜上の基準である。
12歳以降は経過観察の対象から外れるだけであり、その後に魔法が発現した場合は、通常の手続きで登録する。

**発現の届出義務（2026-10-10確定）：** 12歳判定による「みなし」の経路とは別に、**年齢を問わず、魔法が発現した者には届け出る義務がある。** 届け出なかった場合の扱いは「未登録魔術師の扱い」節を参照。

## 魔道士登録制度

**顕在的魔術師と判定された者は、一定の教育・研修を経て魔道士登録することが国内法により義務付けられている。** 任意加入の制度ではない。

### 登録への道筋
```
顕在的魔術師
    ↓
一定の教育・研修（学園等）
    ↓
魔道士登録（義務）
    ↓
年1回の義務的再測定
```

### 学園との関係
学園は「一定の教育・研修」を担う制度的装置として機能する可能性がある。
→ 卒業 ＝ 登録資格の取得、という構造になりうる。
→ 詳細は `settings/world/世界観概要.md`（学園セクション）を参照。

### 専門職資格への派生
魔道士登録はあくまで基礎資格であり、特定の職務に従事するための上位・専門資格はこれとは別に存在する。
基礎登録＝国が一律に課す義務、専門資格＝登録魔道士が職務ごとに任意で申請・取得するもの、という二階建て構造。

**魔法に関する資格は、基礎登録・専門資格を問わずすべてJMAが認定・管理する。** 地方自治体や民間団体が独自に魔法関連資格を発行することはない。地方自治体が現場の制度（例：救急車への同乗運用）を独自に整備することはあっても、そこで要求される資格自体はJMA認定のものを援用する。
例：JMAが認定する専門資格「魔道救急救命士」（`AI_Novel/命脈/構想.md` 参照）。

審査では総合ランクのみを足切りにせず、申請職務に必要な魔法系統、実用出力、精度、制御、状況判断などを個別に確認する。Cランクの登録魔道士でも、必要能力が認められれば専門資格を取得・維持できる。

### 専門資格の審査・維持・処分（2026-10-10確定）

#### 取得時の審査
| 段階 | 内容 |
|------|------|
| 1. 研修課程の修了 | 職務ごとにJMAが定める研修を受ける（例：魔道救急救命士なら救急医療の講習と実習） |
| 2. 実技審査 | 職務に即した課題で、系統・出力・精度を測る（年次再測定の生体材課題と同じ形式） |
| 3. 判断能力の審査 | 事例にもとづく口述試験。いつ使い、いつ使わないかを問う |
| 4. 合議による認定 | 地方支部の複数の審査員が合議で決める（ランク測定と同じ方式） |

#### 維持の確認（有効期限なし・毎年確認）
専門資格に有効期限はない。**年1回の再測定の結果を、地方支部が職務の維持要件と照合する。**

```
年1回の再測定（基礎登録の義務）
  ├ ランクの判定
  └ 専門資格の保有者は、同じ結果を地方支部が職務の維持要件と照合
        ├ 要件を満たす　　　　→ 維持
        ├ 要件ぎりぎり・要注意 → 維持。面談・休養の勧告
        └ 著しい低下　　　　　→ 臨時測定 → 行使範囲の見直し
＋ 年に一定時間の研修義務（未受講は維持要件を欠く）
```

例：『命脈』第三話の雫石灯は、ランクはCだが閉創の技能が維持要件を満たすと支部が判断し、資格を維持した。負荷所見が強いため休職を勧告された。
研修の年間時間数は未定。

#### 資格がなくなる・制限される場合
| 種類 | 内容 | 原因 |
|------|------|------|
| **失効**（自動） | 資格が自動的に消える | 臨界点到達による魔法の喪失／休止期間の上限超過／基礎登録の抹消 |
| **範囲の限定** | 独立行使 → 指示下行使 | 臨時測定で出力が基準を下回った |
| **停止**（懲戒） | 期間を区切って行使を禁じる | 規定違反（同意を得ない施術、記録の虚偽など） |
| **取消**（懲戒） | 資格を剥奪する | 重大な違反、または指示下行使の基準すら下回った場合 |

処分は地方支部が行い、JMA本部へ不服を申し立てられる。失効・取消の後も、取得時と同じ審査を受け直せば再び取得できる。

### 行使範囲と休止（2026-10-10確定）

#### 行使範囲（専門資格の付帯条件）
専門資格には、JMA地方支部が**行使範囲**を付帯条件として記載する。

| 行使範囲 | 内容 | 主な対象 |
|---------|------|---------|
| **独立行使** | 現場の判断で行使できる | 通常の資格者 |
| **指示下行使** | 医師の具体的な指示がある場合に限り行使できる | 新規取得者、休止からの復帰者、出力が独立行使の基準を下回った者 |

指示下行使の枠は以前から存在し、主に新人と復帰者のための段階として運用されてきた。行使範囲の変更は地方支部の**臨時測定**に基づく。出力（範囲・所要時間）が独立行使の基準を下回っても、精度と判断能力が保たれていれば、資格は取り消されず指示下行使に限定される。

- 臨時測定の引き金（大規模行使後の事後報告によるのか、雇用者・本人の申請によるのか）の詳細は未定。

#### 休止（魔法行使停止届）
- **性格（2026-10-10確定）：** 本人が自分の意思で、一時的に職務から離れるための制度。典型は療養（神経の消耗など）、育児・転職、心理的な理由。懲戒としての「停止」とは、本人の意思によるかどうかで区別する。
- **支部の関与：** 地方支部は休止を**勧告できるが、命令はできない。** 強制が必要な場合は、範囲の限定または停止（懲戒）による。
- **提出先：** JMA地方支部。様式はJMAの様式集にある「魔法行使停止届」（記載事項：氏名・登録番号・保有資格・停止理由・停止開始日）。
- **効力：** 記載した停止開始日から、専門資格に基づく行使が止まる。届を出せば実際に止まる書類である。
- **範囲：** 止まるのは専門資格に基づく行使のみ。基礎登録は国の義務であるため残り、**年1回の再測定の義務も続く。**
- **復帰：** 休止は取り消せる。休止期間内に臨時測定を受ければ復帰でき、期限を過ぎると専門資格は失効する。復帰直後は指示下行使から始まる。
- **上限（2026-10-10確定、目安3年）：** 長く現場を離れると技能が衰えるため、上限は「臨時測定だけで戻れる期間」と「取得時の審査を受け直す期間」の境目とする。上限を超えて失効しても、取得時と同じ審査で再び取得できる（年数は問題があれば見直す）。
- 雇用上の休職（雇用主への申請）とは別の手続きである。

#### 資格によらない緊急時の行使（2026-10-10確定）
他人への治癒魔法は、患者の将来に害を及ぼすおそれがあるため、現実の医行為に相当するものとして扱う。

- **業として**（繰り返し行う意思をもって、職務として）行うには専門資格が要る（現実の医師法17条に相当）。
- **緊急時に一度だけ行う行使は許される。** 資格を持たない魔道士、休止中の資格者を問わない。繰り返し行うものではないため業にあたらず、差し迫った危険を避けるためのやむを得ない行為として違法性もない（現実の一般市民によるAED使用、刑法37条の緊急避難に相当）。善意で行った結果に後遺症が残っても、悪意や重大な過失がなければ損害賠償責任を負わない（民法698条の緊急事務管理に相当）。
- したがって休止中に止まるのは「職務として出動し、治癒すること」であり、目の前の急病人を一度助けることまでは妨げない。

例：『命脈』の灯にとって、停止届に日付を書くことは「人を治せなくなること」ではなく「町から呼ばれる人でなくなること」を意味する。

#### 特別指定魔道士との関係（2026-10-10）
国際魔道条約第4条に基づく特別指定は、**内閣総理大臣**が行う（事務は魔道庁。`魔道庁.md`）。JMAは審査資料（測定データ）と意見を提出するにとどまり、指定権を持たない。正確な申告を求めるJMAと、戦力の秘匿を望みうる政府との間に緊張が生じうる（→ `../world/魔法体系.md` 「特別指定魔道士」）。

#### 自治体による職務指定との関係
自治体は資格を発行できないが、JMA資格の行使範囲を前提に、**職務として指定**することはできる（例：湯坂市の「補助的魔法対応者」。`AI_Novel/命脈/設定/ストーリー由来の未確定事項.md` 決定記録を参照）。

### 本部と地方支部の分業
JMAは本部と、都道府県単位（またはブロック単位）の**地方支部**からなる二層構造を持つ。

| 階層 | 役割 |
|------|------|
| **JMA本部**（東京） | 全国共通の基礎登録制度・専門資格の審査基準（審査項目・合格ライン）を策定。統計局を持ち、全国の登録・測定・施術データを集約する |
| **JMA地方支部** | 本部が定めた基準に基づき、専門資格の個別審査・認定・更新を実際に行う。地域の実情（症例数、現場の人手不足、施術環境）を踏まえた個別判断を行う |

専門資格の**基準は中央が一元的に定めるが、個々の認定は現場に近い地方支部が行う**。これにより、Cランクの登録魔道士でも地方支部の判断で専門資格を取得・維持できる余地が生まれる（例：湯坂市の雫石灯が現Cランクでも「魔道救急救命士」資格を維持している根拠）。

一方で、本部の統計局が集約するデータと、地方支部が個別に把握している現場の実情との間には距離があり、両者の判断が一致しない緊張関係が構造的に生じうる。

## 未登録魔術師の扱い（2026-10-10確定）

### 基本方針
**未登録の本人は保護の対象、隠した者は処罰の対象。**
魔法は危険であるため、未登録の本人は罰して遠ざけるより、判定・登録・教育へ引き込む方が社会にとって安全である。一方、IMAは各国による魔術師の秘匿への恐怖から生まれた組織であり（`国際魔道協会.md`）、**第三者が魔術師を隠すことを最も重い罪**とする。

### 類型と罰則
| 類型 | 内容 | 扱い |
|------|------|------|
| ① 届出の怠り | 発現したのに届け出ない | 過料（行政罰）。強制的に判定し、登録させる。未成年の場合は保護者の責任 |
| ② 登録の拒否 | 判定されたのに教育・登録を拒む | 罰金と強制登録 |
| ③ 未発見 | 本人も周囲も気づいていない | 罰則なし。発見時に通常の手続きへ |
| ④ 隠匿・利用 | **第三者が**未登録の魔術師を匿う、または使役する | **重い刑事罰（懲役）**。組織的に行えば加重 |

### 摘発の仕組み
魔素は3次元で観測できないため、未登録の魔術師は**魔法が目に見える形で起きない限り発見されない**。

| 発見の経路 | 担い手 |
|-----------|--------|
| 魔法の事故・暴発（最も多い） | 都道府県警の魔道課 |
| 医療機関での異常な所見、学校での兆候 | 通報を受けてJMAが判定 |
| 組織的な隠匿、国際的な犯罪 | 警視庁公安部魔道課（公魔） |

管轄は**登録＝JMA、刑事事件＝警察、国家の安全保障＝公安**に分かれる。事案によっては三者の管轄が重なり、主導権をめぐる摩擦が生じうる（例：`../stories/天宮前日譚.md` の凍結事件）。

### 発見から登録までの空白
発見された未登録の魔術師は、登録されるまでIMAへの報告対象にも特別指定の対象にもならない。捜査・保護を理由に登録が先延ばしにされれば、国家がその魔術師をIMAに知られないまま手元に置くこともありうる。制度上の常態ではないが、**物語上そうしたケースがあってよい**（`国際魔道協会.md` 第4条の過少指定の誘因と同じ根）。
