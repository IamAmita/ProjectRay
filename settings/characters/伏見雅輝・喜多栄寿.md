## 伏見雅輝（ふしみ まさき）

### 基本情報

| 項目 | 内容 |
|------|------|
| 氏名 | 伏見雅輝（ふしみ まさき） |
| 所属 | 京都府警魔道課（京都府警察二条警察署） |
| 階級 | 巡査部長 |
| 役割 | 捜査の主導者。喜多の先輩 |

### 人物像

| 特徴 | 描写 |
|------|------|
| 口調 | 淡々とした。感情を表に出さない |
| 所作 | 乱れがない |
| 思考 | ベテランの直感。「きな臭い」を一次情報から即座に読む |
| 感情 | ないわけではない（「いつもよりも明らかに空気が硬い」）が、職業的に制御している |

### 事件への視線

伏見は最初から「失踪児童発見事件」として蓮華を見ている。

> 「死体より先に少年の身体を見る」

普通の刑事が「二人死亡」から語り始めるのに対し、伏見が最初に言うのは「栄養失調、全身の外傷、それに目を引く多数の縫合痕」。この視点の違いが冒頭から際立つ。

「虐待痕のある子供が死体のそばにいた」という事実から、かなり早い段階で「加害者というより被害者ではないか」と疑い始める。ただし最初から確信しているわけではなく、捜査の前提として複数の仮説を並列で持ち続ける。

### 初動捜査の手順

事件発生直後の動きの順番。

**① 現場保全**
最優先。死者が出ているため事件性の有無を確認する。凍結範囲・魔力残留・発動地点・放出方向を調べる。

**② 生存者（蓮華）の保護**
死にかけている子供を事情聴取より先に救急搬送する。この時点では聴取より医療が優先。

**③ 死者の身元確認**
伏見が最初に知りたいのは「蓮華が誰か」ではなく「死んだ2人が何者か」。死者の身元次第で事件の構図が変わる。

**④ 現場周辺の捜索**
死者2名しかいないため、「ここが本当に事件現場なのか」を疑う。車両・所持品・通信機器・血痕・足跡などを捜索。

**⑤ 蓮華の身元確認（病院搬送後）**
指紋・DNA・行方不明者照会 → 鬼灯蓮華と判明。

**⑥ 病院からの情報収集**
医師から「栄養失調・多数の古傷・縫合痕・腎臓移植歴」の報告を受ける。ここで初めて「長期間拘束されていた可能性が高い」という認識に至る。

### 初期仮説（A〜D）

初日の時点では以下の仮説が全て残っている。

| 仮説 | 内容 |
|------|------|
| 仮説A | 少年が魔法で2人を殺した |
| 仮説B | 2人から襲われて反撃した（正当防衛） |
| 仮説C | 魔法事故（制御できない暴発） |
| 仮説D | 第三者がいる |

虐待痕から早期に被害者方向へ傾くが、捜査上はすべての可能性を残す。

### 捜査の主軸

初動捜査の主軸は「蓮華を追及する」ではなく、

**「死んだ2人が何者だったのかを調べる」**

死者の身元が割れることで、事件の構図が一気に見えてくる。

### 思考の流れ（初動から証拠収集後）

```
傷だらけの少年が死体のそばで発見される
↓ 全身の外傷・多数の縫合痕（身体的証拠）
↓ 長期拘束を示す身体痕跡・公的記録なし
↓ 魔法暴発で魔術師2名死亡
↓ 未登録魔術師案件の可能性
↓ 国際犯罪の可能性
→「これは公安案件だろ」
```

### 伏見の立場の特殊性

公安（公魔）への移管を予想しながらも、正式移管まで自分に動ける時間があることを理解している。「まだ事件の全容が分かっていない」「この子は重要参考人だ」という理由で身柄を保持できる。

捜査の建前上は蓮華を重要参考人として扱いつつ、本音では早い段階から「被害者側の人間」として動いている複層的な立場を持つ。

### 主な台詞（本文より）

> 「惨いな。だが、魔道界らしい事例だ」

> 「我々の責務は、一般人を魔法に関するインシデントから守ることだ。いちいち感情的になっていては、民衆どころか自分すら守れんぞ」

> 「厄物のにおいがプンプンするな」

> 「人身売買。人体実験。少なくとも、それらが絡んでいる可能性は十分にある」

## 喜多栄寿（きた えいじゅ）

### 基本情報

| 項目 | 内容 |
|------|------|
| 氏名 | 喜多栄寿（きた えいじゅ） |
| 所属 | 京都府警魔道課 |
| 階級 | 新人 |
| 役割 | 視点人物（一人称「俺」）。伏見の後輩 |

### 人物像

| 特徴 | 描写 |
|------|------|
| 視点 | 感情移入しやすい。蓮華の震えが「胸に引っかかる」 |
| 思考 | 最初は「魔法暴発事件」として見る。伏見の解釈に徐々に引き上げられていく |
| 役割機能 | 読者の目線に近い存在。伏見の言葉を聞いて驚く・血の気が引く場面で読者の感情を代理する |

### 伏見との温度差

| 伏見 | 喜多 |
|------|------|
| 「失踪児童発見事件」として見る | 「魔法暴発事件」として見る |
| 感情を制御し淡々と動く | 感情がそのまま出る |
| 公魔への移管を冷静に予測 | 「公魔ですか？」と驚く |

この温度差が捜査パートの会話に自然な緊張感を生む。

### 物語上の機能

- 読者が世界観・制度・事件を「聞く側」として理解するための存在
- 伏見の台詞に対して適切なリアクションを返すことで、伏見の異常な冷静さを際立たせる
- 蓮華への感情移入を担うことで、読者と蓮華の心理的距離を調整する

---

## 二人の関係性

| 軸 | 内容 |
|----|------|
| 経験差 | ベテラン vs 新人 |
| 視点差 | 事件の本質を即座に読む vs 表面の事実から始まる |
| 感情差 | 制御された感情 vs 生の感情 |

この三軸が一致して、読者には「伏見の視点から得られる情報」と「喜多の感情から得られる体感」の両方が届く構造になっている。

## 京都府警 捜査時系列

### 数年前（未特定）

* 鬼灯家崩壊・両親死亡。
* 蓮華失踪。行方不明児童として処理される。京都府警も足取りを掴めない。

---

### 2024年3月24日

**早朝（凍結事件）**

* 京都市内で大規模凍結事件発生。
* 京都府警魔道課出動。伏見・喜多が担当。
* 凍結空間の中心で魔術師2名の死亡と蓮華を発見。
* 蓮華を保護・救急搬送。

**この時点で確認されていないこと**

* 死者の身元・蓮華の身元
* 非合法施設の有無
* 犯行者と被害者の区別

---

### 2024年3月下旬

* DNA・行方不明者照会 → 鬼灯蓮華と判明。
* 捜査本部設置。
* 医師報告：腎臓移植歴・多数の縫合痕・長期拘束の痕跡。
* 長期監禁・人体実験・人身売買との関連が浮上。

---

### 2024年4月

* 蓮華を京蓮学院大学病院へ移送。集中治療開始。
* 保護責任者：京都府警魔道課のまま。
* 公安・魔道庁が注視開始。

---

### 2024年春〜夏

**捜査側**：施設関係者洗い出し・身元不明死体の特定・資金ルート調査。ただし主犯不明。
**蓮華側**：発話不能・記憶混濁のため証言取得困難。

---

### 2024年秋

* 実行犯の多くが死亡・証拠不足・黒幕不明で捜査停滞。
* 未解決事件として継続捜査へ。

---

### 2024年冬

* 蓮華の回復により日常会話が可能になる。断片的な記憶も戻り始める。
* 再事情聴取 → 施設内部情報・組織構造の一部が判明。

---

### 2025年春

* 蓮華証言と新証拠が結びつく。残党捜索・資金源・黒幕調査が加速。

---

### 2025年4月27日頃

* 蓮華が京蓮学院大学庭園で天宮梓音と出会う。
* 同時期、伏見たちは蓮華の社会復帰・後見人問題・今後の保護体制を検討中。
