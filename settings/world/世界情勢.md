## 日本

### 政権
- 石橋源内閣（モデル：石破茂）
- 内輪もめによる実質少数与党、政治的不安定感
- 未記載金などの裏金問題で信用も欠くか
- 育児・介護休業法などによる働き方改革
- サイバー防衛法の成立（5/16）

### 経済・社会
- 大企業は政策に沿った制度を定める体力がある一方、中小企業は苦しい
- 大企業とその他の格差拡大の懸念が社会不安につながっている
- 少子高齢化による人手不足
- 現役世代の社会保険料負担問題

### 外交
| 相手 | 関係 |
|------|------|
| 対米 | 軍事上は緊密な関係も、通商面で冷えている |
| 対中 | 経済面では緊密も軍事面で緊張感あり。対米関係の冷え込みによっては関係変化もあるか |
| 対露 | 非友好国認定。ウクライナを支援。北方領土問題も先延ばし。戦争終結後の関係改善は見込める |
| インド・太平洋 | 関係の緊密化を図っている。米国の思惑もあるが、対中国考慮もあるか |

## アメリカ

### 政権
- ジョーカー大統領（モデル：トランプ）
- 上院下院両方を共和党が支配するも、不安定
- MAGA派と主流派の対立あり
- 国教政策をめぐり連邦と州の対立あり
- 対外的な報復関税や移民問題など、米国人の雇用と主権を守る意思表明
- ビザ取消などにより、企業や大学の反発
- トランス問題

### 外交
| 相手 | 関係 |
|------|------|
| 対亜 | インドや中国、太平洋地域などへの関税引き上げを一時凍結。対中における台湾抑止姿勢 |
| 対欧 | 欧州諸国に防衛費増額を呼びかけ、共同声明。ウクライナとの安保協定 |
| 対中東 | ガザ停戦に対する働きかけ。イランに対する圧力 |
| 対中米 | 国境・移民問題での対立 |

## ロシア

### 政権
- ジェレズノフ大統領（モデル：プーチン　ロシア語で「鉄」の意、実在の苗字）
- ほぼ独裁政権
- 高インフレと軍事偏重で生活格差拡大
- 輸入品を国産ブランドで代替中
- 西側企業資産の国有化法案を審議中
- 軍事態勢による経済疲弊
- 電子召集令状の導入、徴兵対象年齢の引き上げ
- 退役軍人の優遇

### 外交
| 相手 | 関係 |
|------|------|
| 対中 | 準同盟から実務超密着へ。軍事連携もあり |
| 対印 | 石油輸出で過去最高。経済的親密 |
| 対北 | 弾薬同盟。対米共闘姿勢 |
| 対イラン | 戦略提携条約 |
| 対欧 | ウクライナ戦争継続中。EUとエネルギー輸出で駆け引き。黒海海上での海上安全会談に合意 |
| 対アフリカ | 囲い込みたい |
| BRICS-plus | エジプト・サウジ正式加盟。技術・決済インフラ議論を主導 |

## 中国

### 政権
- 学遠大総書記/国家主席（モデル：習近平）
- 独裁体制。党統制を深化
- 不動産テコ入れ、都市改造推進
- 人口減少中で、高齢化コストが地方を圧迫。少子化対策も実施中
- 若年層の失業問題が深刻

### 外交
| 相手 | 関係 |
|------|------|
| 対露 | 外相がモスクワで大統領と会談。相互補完協議 |
| 対米 | 関税争い、一時凍結 |
| 台湾海峡 | 中国軍が大規模演習。G7外相が共同声明で懸念表明 |
| 対印 | インド産品の輸入拡大を表明 |
| 対アフリカ | 打算的経済協力・援助。衛生、鉄道、農業技術を輸出 |
| 国連安保理 | ロシアと共にガザ停戦案に拒否権を行使 |
| BRICS+ | インド、サウジ加盟。決済基盤 BRICS Pay を主導 |
