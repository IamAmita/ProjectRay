## 理論的基盤（案）

### 世界の物理構造
本作ではM理論を基盤とした世界観を採用する（案）。

- 根源場の揺らぎにより根源粒子（弦に対応）が発生し、その性質によって各場に固定される
- 場と粒子は一対の関係にある
- **バルク次元に影響する粒子**：重力子・ディラトン・モジュライ（世界のテクスチャそのものに作用）
- **3次元ブレーンにのみ影響する粒子**：上記以外の基本粒子

### 魔法場
- 高次元（n+x次元）に存在する場
- 神（別世界の存在）によってもたらされた技術
- 各場との接続技術も神の御業とされる
- 魔法場を通じて、n次元の任意の場を操作できる

> 裏設定（`world_overview.md` 参照）との接続：神＝4次元に移行した存在の系譜。
> 魔法場は次元上昇の際に残された技術の名残。

## 魔素（案）

| 用語 | 定義 |
|------|------|
| **魔素** | ダークマターと同一の存在。ボソン。多重次元に同時に属せる性質を持つ |
| **マナ** | 体内の魔素 |
| **エーテル** | 体外の魔素 |

> **重要**: 魔素＝ダークマター。宇宙に遍在しているが、通常の物質とは直接相互作用しない。
> 魔素を介してのみ、現実の物質・エネルギーと相互作用が起こる。

### 魔素の作用連鎖
```
魔素 ⇒ 魔法場 ⇒ 根源場 ⇒ 任意場 ⇒ 物質・エネルギー
```

### 魔素の持つ荷量

**ベクトル荷**
物質の位置を表す連続的な荷量。
魔法荷の引力・反発の強度は、ベクトル荷の近似度によって決まる。

**魔法荷**
魔法荷を持つ者同士の相互作用を決める荷量。±・0の三種。

| 極性 | 挙動 |
|------|------|
| 同極（++または−−） | 引き合う（電磁力とは逆） |
| 異極（+−） | 反発する |
| 0 | 不干渉 |

根源場の操作が低次元の魔法場に干渉する際、この荷量が媒介として機能する。

### 魔法の発動メカニズム（案）
```
脳 → イメージ → 脳波（波形）→ 魔法場変換 → 魔法行使
```
- 魔法場変換の際に、魔素の魔法荷が自動で付与される（案）
- 魔素はこのプロセスを通じてのみ現実の物質と相互作用する
- ゲージ選択的重ね合わせによる詳細操作の可能性あり（要検討）

### 未解決問題
- 魔素（ダークマター）が体内でどのように蓄積・生成されるか
- 「魔力の生成が可能かどうか」の遺伝的メカニズムの詳細
- ゲージ選択的重ね合わせの具体的な操作理論

## 才能と遺伝（案）

### 魔術師と非魔術師を分けるもの
**魔力（魔素）の生成が可能かどうか**が遺伝によって決まる。これが魔術師と非魔術師の境界。

### DNAへのコード埋め込み
- 魔法の使用手順を記したコードが**関数**として全人類のDNAに保存されている
- 魔術師のイメージに沿って魔法が発現する仕組み
- 使用可能な魔法の種類も遺伝によって決まる

> **重要な含意**：魔力生成が不可能な非魔術師でも、何らかの形で魔力を体内に貯蔵できれば、魔法が使用できる可能性がある。

### 遺伝パターン
- 遺伝的側面が強く、基本的には魔法を持つ家系のみで使用可能
- 突然変異により、魔法を持たない家系から魔術師が生まれることもある

## 魔法の等級分類（案）

### 第0魔法（根源魔法）
- 魔法場に接続し、揺らぎを操作する
- 個人ごとに専用の魔法場が存在する
- 全魔法の土台。行使可否は魔法場制御の可否に依存
- 代表的応用：魔法場直接変換（粒子の存在状態→エネルギー化。物理的媒介不要）

### 第1魔法
- 魔法場を介して、単一の場に個別に干渉
- 同時に複数場への接続も可能
- 魔法場の揺らぎを反映し、仮想粒子を用いて作用する
- 操作可能な場の例：グルーオン場・電磁場・重力場・ヒッグス場 など

### 第2魔法
- 第1魔法の複合系
- 複数の場を同時に制御する

### 第3魔法
- 第2魔法の複合系
- 複数の第2魔法を併用
- **ほとんどの「属性魔法」は第3魔法以上**

## 魔法の観測可能性

### 基本原則：結果は見えるが、本体は見えない
魔法の現象（結果）は3次元科学で観測できる。しかし魔法の本体（高次元での機序）は、原理的に観測不可能。

| 観測状況 | 詳細 |
|---------|------|
| ✓ 観測できる | 火が出た、傷が治った、人が転移した——という現象・結果 |
| ✗ 観測できない | なぜそうなったか。高次元での接続・操作のプロセス |

**なぜ観測できないのか：**
2次元の住人は「上方向」を観測する手段を持たない。紙が動いても「世界が動いた」としか認識できない。同様に、3次元に閉じた科学の測定器は高次元方向への干渉そのものを検出できない。魔法の本体が高次元にある以上、3次元科学がどれだけ発展しても原理的な到達限界がある。

### 科学者と魔法の関係
- 科学者は魔法を「否定できない」——結果として目の前で現象が起きているから
- 科学者は魔法を「説明できない」——なぜそうなるかの機序に到達できないから
- 「魔法は存在する。しかし必ず法則があるはずだ」という信念で研究を続ける科学者が存在しうる——それは狂気にも信念にもなり得る

### 魔力量が科学的に測定できない理由
魔力の本体が高次元にある以上、3次元の測定器でアクセスできない。経験則や感覚では分かるが、理論的・数値的な根拠を示せない。これは魔道士のランク測定が「複数の測定者による合議制」に留まる構造的理由の一つ。

### 魔術師自身も原理を知らない
神々の遺産である魔法を、現代の魔術師は原理を知らないまま使っている。現代人が半導体の量子力学的動作を理解しなくてもスマートフォンを使えるように、魔術師は「経験則として動作すること」を学ぶだけで十分に機能する。本質的な理解は誰も持っていない。

### ブラックホールとの類似
魔法による高次元への局所的な接続は、理論上ブラックホールと同種の現象である可能性がある。

| 比較 | 内容 |
|------|------|
| 魔法 | 魔術師が意図的に局所的な高次元接続を生成する技術 |
| 自然発生ブラックホール | 同種の高次元接続が自然に極端な形で発生した現象 |

実際に作中の科学者が「魔法を研究していたら、ブラックホールと同じ数式が出てきた」という状況がありうる。魔術師は古代から使い、科学者は後から理論を発見した——しかし両者とも本質を理解していない。

## 治癒魔法

治癒魔法には明確に異なる2種類が存在する。

### 下級治癒（細胞分裂加速型）
一般的な回復魔法。広く普及しており、戦場での即応性に優れる。

| 項目 | 内容 |
|------|------|
| 仕組み | 細胞分裂・増殖を魔法で加速させる |
| 効果 | 傷の修復が急速に進む |
| 代償 | 細胞分裂の回数（テロメアの短縮）を消費する |
| リスク | 使用頻度が高いと**寿命が縮まる** |
| 分布 | 一般魔術師・魔道士に広く普及 |

> 一般人の寿命が80歳前後に留まる主因の一つ。頻繁な治癒魔法使用が自らの寿命を削っている可能性がある。

### 上級治癒（DNA修復型）【御三家秘伝】
御三家が保有・継承する秘伝技術。下級治癒とは根本的に異なる。

| 項目 | 内容 |
|------|------|
| 仕組み | DNA・細胞レベルの損傷を直接修復する |
| 効果 | 傷の修復に加え、老化の根本要因にもアプローチ可能 |
| 代償 | ほぼなし（副作用が極めて少ない） |
| リスク | 特になし |
| 分布 | **御三家のみ保有・継承** |

この技術的格差が、一般魔道士（寿命80歳）と御三家（寿命130歳前後）の寿命格差の根本原因となっている。御三家が秘伝として管理し外部に流出させないのは、この格差が権力基盤の一部を構成しているためでもある。

## 精霊と降霊術

### 精霊とは何か
精霊は情報生命体であり、人間とは全く別個の存在。

| 特性 | 詳細 |
|------|------|
| 本質 | 情報の塊。特定の知識・記憶・経験・意識の断片が固着したもの |
| 通常状態 | **思考しない**。CPUのないデータ、または停止した演算機のようなもの |
| 自発性 | 通常状態では自ら動くことも語ることもない |
| 由来 | 人間の死後・強烈な思念の残留・その他（複数の成因がありうる） |

精霊は情報として存在しているが、それを処理する基盤（神経回路に相当するもの）を持たないため、通常は沈黙したままである。「いる」が「動かない」状態。

### 降霊術とは何か
降霊術は、精霊に一時的な思考基盤を与えて「起動」させる技術。

```
ダークマター（魔素）→ 仮想神経回路の構築 → 精霊と接続 → 精霊が思考・発話可能になる
```

| 項目 | 詳細 |
|------|------|
| 使用素材 | ダークマター（魔素）。体内に蓄積される性質を利用 |
| 仕組み | 魔素で精霊のための仮想神経回路を構築し、精霊情報をその回路に乗せる |
| 効果 | 精霊が「思考・会話・知識の共有」できる状態になる |
| 通常魔法との違い | 外部から情報を「呼び出す」技術であり、情報制限の例外に当たる |

降霊術が「情報取得系魔法」の通常制限（感覚拡張のみ・無から知識生成不可）を超える理由：精霊自身が知識を持つ実在であり、降霊術師は無から情報を生成しているのではなく、すでに存在する情報体と対話しているため。
