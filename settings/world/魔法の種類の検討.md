## 属性・魔法分類案

> 以下はブレインストーミング段階の分類。
>
> **2026-10-10確定：属性は魔法的には存在しない。** 真層の仕組みに「属性」に当たる単位はなく、火・水などは便宜上の慣用的な呼び名にすぎない。以下の一覧は、真層で魔法の種類を整理する際の素材、および表層の慣用名の候補として扱う。

### 自然・属性系
| 属性 | 主要な操作原理 |
|------|--------------|
| 火 | 酸化/還元反応、熱操作、プラズマ |
| 水 | 分子間力操作（電磁力）、位相変化 |
| 風 | 物質位置操作（魔法荷）、温度差による気流 |
| 土 | 物理操作、化学変化による生成 |
| 氷 | 化学結合操作、分子運動の沈静化 |
| 雷 | 電磁場・電子場操作、電荷再配置 |
| 光 | 電磁場操作、光子操作、プラズマ生成 |
| 闇 | （未定） |
| 金属 | 核融合/核分裂（錬金術）、化学反応 |
| 木 | 形状操作、代謝効率操作、治癒 |
| 毒 | 化学物質操作、直接的化学変化 |
| 重力 | 時空間操作、質量操作、バルク次元場干渉 |
| 磁力 | 電磁場操作、物性としての磁性操作 |
| 熱 | 物質振動操作、光子励起 |
| 音 | 空気振動操作、感覚器官操作 |
| 霧 | 物質操作、電磁場操作による幻視 |
| 影 | （未定。電磁波の吸収?） |
| 星 | 質量魔法、星エネルギーの魔力転換 |
| 時空間 | 時間速度操作、タイムリープ、空間接合、結界 |

### 生命・精神系
- 回復・治癒（代謝向上、物理処置、必要物質供給）
- 召喚（同次元/低次元/高次元）
- 変身・変化
- 強化・弱体
- 魂操作・霊体干渉
- テレパシー・読心・催眠
- 呪詛・呪術・因果操作

### 物理・エネルギー操作系
- 念動・念力
- 原子・分子レベル操作（錬金術）
- エネルギー生成
- 物質創造・変換
- 結界・封印
