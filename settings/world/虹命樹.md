- 根元直径：
- 樹冠：厚み200m　幅600m

#### 火口深度との相対位置

#### 根の形状
- 主根：直径100m　深さ3km　反転二重螺旋構造（電磁代謝層）
- 側根：山体全体に広がる

#### 幹の内部構造
- 最大幹径：150m

| 部位 | 構造 |
|------|------|
| 髄 | 生育細胞 → CNF伝熱層 |
| 木部 | 道管・緩衝層 |
| 形成層 | 通常 |
| 師部 | 通常 |
| 樹皮 | 硫黄樹皮 |

#### 樹皮の物性
- 外側：石・金属並みに硬い
- 中層：ゴムのように粘る（硫黄架橋）
- 内側：コルクで断熱
- 酸・火・菌に超強い
- 雷も流さない（絶縁性）
- 落雷・風・衝撃に強い複合シェル

#### 葉の構造・色彩・季節変化
- サイズ：1.5〜2m × 1〜1.5m
- 大量蒸散のための空洞化構造
- CNF葉脈　撥水ナノ構造
- 回折・干渉による構造色

#### 生長速度・寿命・更新周期
- 不明

#### 火山ガス吸収後の分配経路

| 部位 | 役割 |
|------|------|
| 主根 | 亜硫酸・硫化水素を利用した電磁代謝 |
| 側根 | ガス吸収 → 硫黄酸化・硫酸還元サイクル |
| 根本 | 余剰硫黄を単体硫黄として排出 |
| 水蒸気 | 側根 → 地上に噴気・蒸散源 |
| 二酸化炭素 | 電磁代謝の炭素源 |
