## 起源に関する裏設定（真層・作者の構想）

> 出どころ：作者の構想（`../../notes/chat_history/2026/06/03/魔法がいつから存在するか、という設定について深掘って考えたい.md`）。2026-11-08に `魔法体系.md` から移した。

この設定は基本的に作中人物が知るものではなく、作中で明示的に言及する予定もない。
完結後の裏設定公開などで初めて明かされる可能性がある、世界の底にある設定として扱う。

魔法は、人類が作った技術ではない。
1次元の世界における知的存在が極致に達して2次元へ移行し、その系譜がさらに3次元へ到達した。
3次元におけるその系譜は、人類から見れば「神」と呼んで差し支えない存在であり、彼らもまた極致に達して4次元へ移行した。

現在の3次元世界に存在する魔法は、神々が4次元へ移行した後に残された、次元上昇技術の名残・残響・低次元側インターフェースである。
魔法とは次元ごとに異なる振る舞いをするが、本質的には同一系統の技術である。

表向きには、魔法は「別の次元・存在から流れ込んでくる力」として理解される（`魔法体系.md`「魔法の本質」）。
裏設定上は、魔術師が高次元技術の残留構造に部分的に接続し、自身の身体・意識・認識を通じて現象化している。
神々は基本的にこの世界を直接管理しておらず、魔法は恩寵というより、残された巨大な技術基盤を人間が限定的に利用しているものに近い。

この裏設定は、魔法描写の一貫性を保つための羅針盤として用いる。
毎場面で厳密に参照するものではなく、魔法の起源・才能・限界・古代神話の手触りに迷ったときの基底設定とする。

## 理論的基盤（案）

> 出どころ：作者メモ（`../../notes/chat_history/2026/06/03/魔法概要.md`）。

### 世界の物理構造
本作ではM理論を基盤とした世界観を採用する（案）。

- 根源場の揺らぎにより根源粒子（弦に対応）が発生し、その性質によって各場に固定される
- 場と粒子は一対の関係にある
- **バルク次元に影響する粒子**：重力子・ディラトン・モジュライ（世界のテクスチャそのものに作用）
- **3次元ブレーンにのみ影響する粒子**：上記以外の基本粒子

### 魔法場
- 高次元（n+x次元）に存在する場
- 神（別世界の存在）によってもたらされた技術
- 各場との接続技術も神の御業とされる
- 魔法場を通じて、n次元の任意の場を操作できる
- 魔法とは、物理的、量子的な場に干渉し、操作する技術である（作者、2026-06-10。`../../notes/chat_history/2026/06/10/魔法の起源について1.md`。2026-11-14、点検 B-7 の対処でここに書き加えた）

> 裏設定（上記「起源に関する裏設定」）との接続：神＝4次元に移行した存在の系譜。
> 魔法場は次元上昇の際に残された技術の名残。

## エネルギー源

> 出どころ：作者（`../../notes/chat_history/2026/06/30/魔法のエネルギー源.md`）。2026-11-08に `魔法体系.md`「発動方法＞エネルギー源」と一本化した。作中の科学が知っているのは、魔法が3次元ではエネルギー保存則を破るという異常までである（`魔法の分類.md`「成立史」）。

3次元におけるエネルギーの源は多次元の場の揺らぎ（エネルギー）。多次元干渉粒子が存在し、次元を超えて場の揺らぎに干渉する。

- 3次元だけで見るとエネルギー保存則は成立しない
- 多次元全体では成立している
- 術者は「発電機」ではなく「変換器・制御器」

「多次元干渉粒子」は便宜上の呼称。実体は多次元場の局所的な励起状態（量子場の励起）。魔素とは別のものであり、等級分類の第1魔法の「仮想粒子」と同じものを指す（2026-11-09、下記「発動の流れ」）。

## 魔素（案）

> 出どころ：作者メモ（`../../notes/chat_history/2026/06/03/魔法概要.md`。荷量は同 `分類案.md` での使われ方）。魔素を作中でどう呼び、どこまで知られているか（表層での扱い）は未定（`../未確定事項一覧.md` 0-14）。
→ 未整理点の検討は [魔素（検討ファイル）](魔素.md) を参照。

| 用語 | 定義 |
|------|------|
| **魔素** | ダークマターと同一の存在。ボソン。多重次元に同時に属せる性質を持つ |
| **マナ** | 体内の魔素 |
| **エーテル** | 体外の魔素 |

> **重要**: 魔素＝ダークマター。宇宙に遍在しているが、通常の物質とは直接相互作用しない。
> 魔素を介してのみ、現実の物質・エネルギーと相互作用が起こる。

### 魔素と魔力（2026-11-09、AIの推奨を作者が採用）

> 点検 C-4（`../../考察/魔法設定の点検・2026-11-08.md`）、`../未確定事項一覧.md` 0-10・0-7 を解消。

| 項目 | 内容 |
|------|------|
| 魔力 | **体内の魔素（マナ）のこと。** 作者メモ（06-03）の「魔力(=魔素)」のとおり |
| 魔力量 | **体内に蓄えた魔素の量。** 2026-10-10の「魔力量は体内の貯蓄量」が何を貯めているかの答え |
| 使うと | **体内の魔素が使われて減る。** 使われた魔素は体の外に出て、エーテル（体外の魔素）に戻る。消えてなくなるのではない（マナとエーテルは同じ粒子の呼び分け） |
| 減った魔素の戻り方 | 魔術師は魔素を生成できる（魔術師と非魔術師の境界。下記「才能と遺伝」）。生成・蓄積の機構の細部は作者の判断で保留（`../未確定事項一覧.md` 0-5） |

**魔素の総量（2026-11-09、AIの推奨案Cを作者が採用）：** **魔素の総量は、多次元全体では一定である。3次元から見ると増減して見える。** 魔素は多重次元に同時に属する（上記の表）ため、魔術師の「生成」は、高次元の側から3次元へ魔素を引き出すことである。3次元だけを見れば、魔素が作られたように見える。
- 上記「エネルギー源」（3次元ではエネルギー保存則が破れて見えるが、多次元全体では成り立つ）と同じ形であり、世界の法則がそろう。
- 作者メモの問い「体内で生成する場合、クォークからの変換になるため非現実的」（`../../notes/chat_history/2026/06/03/魔法概要.md`）は生じない。通常の物質を変換して作るのではない。
- 作中の科学から見れば、魔素は観測できないため、この増減も測れない。測れるようになれば、エネルギー保存則の破れと並ぶ「異常」になる。
- 3次元の魔素（マナとエーテル）は、魔術師の生成の分だけ増える。宇宙の暗黒物質の量全体と比べれば、ごくわずかである。
- 参考にした現実の理論（`../../考察/魔法設定の点検・2026-11-08.md` C-4）：ボソンの粒子数は保存しない（光子）、本当に保存するのはエネルギー（E=mc²）、暗黒物質の凍結（フリーズアウト）、余剰次元の理論（ADD模型・ランドール＝サンドラム模型。高次元へ逃げると4次元では保存則が破れて見える）、細胞の能動輸送（作るのではなく汲み上げて濃度差を保つ）。
- 採らない案：A 総量が厳密に一定（「生成」は実は取り込み。10-10の「生成」を読み替えることになり、魔術師が多い土地でエーテルが減るかという濃淡の問題が出る）。B 増減する（場の揺らぎのエネルギーから作る。作られた魔素がたまり続けるため、消える・戻る仕組みが別に要る）。
- 引き出す仕組みの細部は、0-5 として保留のまま。

**生成の場所と管理（2026-11-09、作者決定。AIの科学的な検討をもとに作者が採用）：** **魔素は骨髄で作られ（引き出され）、延髄が管理する。**

| 項目 | 内容 |
|------|------|
| いつ | **生きている間、意識しなくてもずっと続く。** 呼吸や造血と同じ（作者） |
| どこで作るか | **骨髄**（作者）。魔素を生成できるかは遺伝で決まり（上記「才能と遺伝」）、その力は骨髄の細胞に現れる |
| 誰が管理するか | **延髄**（作者）。延髄が体内のマナの量を感じ取り、骨髄の生成を増やしたり抑えたりする。呼吸中枢が血中の二酸化炭素を感じ取って呼吸を調節するのと同じ形のフィードバックであり、満ちれば生成を抑えるため、体に保てる量に上限（器）が生まれる |
| どこにためるか | **魔素は体の物質の中ではなく、その人の魔法場（高次元の側）に保たれる。** 魔素は多重次元に同時に属するため、3次元では体内にあり（マナ）、高次元ではその人の魔法場につなぎとめられている。骨髄は引き出しの入り口にすぎず、ためる場所も使う場所（専用神経系が魔法場を駆動する。上記「発動の流れ」）も魔法場の側にあるため、血液のように体の中を運ぶ必要がない |
| 脳死のあと | **生成は続く。** 現実の骨髄が脳の指令なしに働き続ける（脳死の状態でも造血は続く）のと同じく、延髄が死んでも骨髄の生成は、調節を失いながら続く |

置き場所の軸：**延髄（管理）→ 脊髄の近くの専用神経系（出力・制御）→ 椎骨の骨髄（生成）** が、脳幹から背骨にかけての一つの軸にそろう。大人の造血骨髄は主に体の中軸の骨（椎骨・骨盤・胸骨・肋骨・頭蓋骨）にあり、椎骨の骨髄は脊髄を取り囲んでいる。専用神経系の位置「脊髄の近く」は、2026-07-10の相談でAIが例に出した「脊髄近傍の特殊な神経叢」（`../../notes/chat_history/2026/07/10/魔法行使の代償とリスク.md`。作者はこのとき専用神経系そのものを採り、位置は記録されていなかった）を、2026-11-09にこの軸として採った。

帰結：
- **骨髄移植で、生成する力が移る。** 魔術師の骨髄を移植された非魔術師は、魔素を作れるようになり、専用神経系が開通すれば魔術師になりうる。現実でも、他人の造血幹細胞の移植を受けると、血液型が提供者のものに変わり、血液のDNAも提供者のものになる（キメラ状態）。使える魔法（関数）は、受けた人のDNA（呼び出し口。上記「発動の流れ」）で決まり、移らない。
- 骨髄以外の臓器（腎臓など）の移植は、中に蓄えられていた魔素を運ぶだけであり、発現しても一時的である（上記「外部からの供給」）。
- **生成する力は歳とともに落ちる。** 造血骨髄は子どもでは全身の骨にあるが、歳とともに脂肪に置き換わって減る。既存の「老いや不調によるランクの低下」「全盛期」（`魔法体系.md`「ランクの変動」）と合う。
- 骨髄を傷つける病気や治療（白血病、再生不良性貧血、抗がん剤、放射線治療）は、生成する力も落とす。
- 乗っ取った精霊は、宿主の体が生きている限り、脳が死んだあとも骨髄から魔素を受け取り続ける。持続を縮めるのは、精霊が魔法を使った分だけである（下記「宿主の魔法」）。事例：天宮前日譚の晴明（`../stories/天宮前日譚.md`「結末：蓮華の死」）。討伐で身体機能を止めれば、骨髄の生成も止まる。
- 作中の医学が、骨髄移植や年齢による変化から、魔素を作る力が骨髄にあることに気づいていても不自然ではない（表層が真層に部分的にたどり着いている例。`../README.md` 運用ルール6）。どこまで知られているか、骨髄バンクやJMAの規制、魔術師の骨髄を狙う犯罪などは未定（`../未確定事項一覧.md` 1-16）。

科学的な評価（中立。AIの検討、2026-11-09）：「末梢で作り、中枢で調節する」形は、ホルモン（甲状腺と視床下部・下垂体）や呼吸（延髄の呼吸中枢）など人体によくある形であり、自然寄りである。骨髄には交感神経が通り、造血幹細胞が血中に出る量を一日のリズムで調節していることが知られている（Méndez-Ferrerら、Nature 2008）。ただし、現実の造血を主に調節しているのは腎臓のエリスロポエチンや肝臓のトロンボポエチンなどのホルモンであり、延髄の管理は「呼吸中枢のような仕組みを魔素に当てはめた設計」である。魔素は通常の物質と直接相互作用しないため、体の中を運ぶ形は採れず、魔法場にためる決まりを置いた。

**二つの限界：** 魔法の限界は二つあり、別のものである。
- **魔素の枯渇：** 体内の魔素が尽きると、魔法場を駆動できなくなり、降霊術の仮想経路も死霊魔術の仮想の質量も保てない（下記「人と精霊の主導権」の「仮想経路の持続」、「死霊魔術の仕組み」の「仮想の質量」）。
- **専用神経系の疲弊：** 確定済みの「魔力切れ」（`魔法体系.md`「魔力切れの理由」「代償・リスク」）。
- **ふつうの魔法では、神経の疲弊が先に来る。** 魔素の量が効いてくるのは、長く続く術（降霊術の仮想経路、死霊の仮想の質量）と、規模の大きい術である。事例：乗っ取った精霊が魔法を使うほど、宿主の体の魔素が減り、仮想経路の持続も短くなる（下記「宿主の魔法」）。

**作中（表層）での見え方：** `魔法体系.md`「魔力切れの理由」。「魔力切れ」は近代医学では神経の疲弊を指すと分かっている。魔素は3次元で観測できないため、量のほうは「魔力量が多い・少ない」という経験則としてしか知られず、測れない（下記「魔力量が科学的に測定できない理由」）。「魔力切れ」という呼び名は、昔の人が量が尽きると考えた名残である（表層の理論が実際とずれている例。`../README.md`）。

**外部からの供給（0-7）：** **体内に魔素があれば、専用神経系は開通しうる。** 魔素を生成できない非魔術師でも、移植などで外から魔素を与えられれば、生成能力を持つ未発現者と同じく、先天的な開通の素地や生命の危機での覚醒によって発現しうる。ただし自分で魔素を作れないため、**蓄えた魔素が尽きれば使えなくなる（一時的な発現）。** 例外は骨髄移植で、生成する力そのものが移るため、発現は一時的ではない（2026-11-09。上記「生成の場所と管理」）。
- 作者メモ（06-03）の「魔力の生成が不可能な体でも、何らかの形で魔力を体内に貯蔵すれば、イメージが勝手に沸いて魔法が使用できる」と、2026-10-10の「発現には専用神経系の開通が要る」を両立させる。
- 帰結（天宮前日譚）：施設の研究者が「魔法は臓器に宿り、移植で移る」と信じ込んだのは、移植で魔素を与えられた非魔術師の被験者に、一時的な発現が見られることがあったため、と読める。骨髄移植で生成する力が移ること（上記「生成の場所と管理」）を研究者が知っていたとしても、誤りは「使える魔法（関数）まで、どの臓器でも移る」と考えた点にある（2026-11-09）。魔法が続いた（自分で魔素を作れた）のは蓮華だけだったので、蓮華は「唯一の成功例」になった（`../stories/天宮前日譚.md`「組織の構造と隠蔽」）。
- 採らない案：外から魔素を与えても使えない（専用神経系が閉じたままで操作できない。作者メモの記述を改めることになる）。

### 魔素の作用連鎖
```
魔素 ⇒ 魔法場 ⇒ 根源場 ⇒ 任意場 ⇒ 物質・エネルギー
```

### 荷量（ベクトル荷・魔法荷）

> 2026-11-09、見出しを「魔素の持つ荷量」から改めた。ベクトル荷は魔素だけでなく、すべての粒子が持つ（下記）。出どころ：作者メモ（`../../notes/chat_history/2026/06/03/分類案.md` での使われ方。定義文の出どころは未確認）。

**ベクトル荷**
物質の位置を表す連続的な荷量。
魔法荷の引力・反発の強度は、ベクトル荷の近似度によって決まる。

**ベクトル荷の意味（2026-11-09、AIの推奨を作者が採用。点検 C-3）：**
- **ベクトル荷は、粒子が高次元（余剰次元）のどこにいるかを表す値（ベクトル）である。** 3次元での位置ではない。
- **同じ種類の粒子は、高次元で近い位置にいる。** そのため「位置」と「種類」は同じことの二つの面であり、上の定義（位置）と作者メモの「同種の粒子/分子同士は魔素を介さずに結合可能（ベクトル荷の近似）」（土）の両方が成り立つ。作者メモの「根源粒子は、その性質によって各場に固定される」（上記「世界の物理構造」）とも自然につながる。
- **すべての粒子が持つ**（通常の物質も、魔素も）。座標のようなものである。
- **魔法での働き：** 関数は、狙う粒子のベクトル荷に合わせて作用を向けるため、選んだ種類の粒子にだけ、魔法荷の引力・反発が強く効く。作者メモの使われ方（水：水の分子だけを動かす、風：空気の分子の位置操作、土：同種の結合、氷：結合の置き換え、金属：原子核の結合）がこれで説明できる。下記「発動の流れ」のうち、関数が魔法場から任意の場へ干渉する段階の中身にあたる。
- 参考にした現実の理論：スプリット・フェルミオン模型（Arkani-Hamed & Schmaltz、2000年。粒子の種類ごとに余剰次元の別々の位置に局在し、その重なりが結合の強さを決める）、カルツァ＝クライン理論（余剰次元の方向の運動が、4次元では電荷として現れる）。
- 採らない案：3次元の位置そのもの（近似度がただの距離になり、「同種は結合する」を説明できない）。種類を表すラベル（「位置操作」の意味が失われる）。

**魔法荷を誰が持つか（2026-11-09、AIの推奨を作者が「一旦」採用。作者が後で整合性を確認する。`../未確定事項一覧.md` 9-26）：**

| 項目 | 内容 |
|------|------|
| 通常の物質 | **ふだんの魔法荷は0。** 魔法を使わなくても力がはたらく「第五の力」は、現実の精密な実験（エトヴェシュ型）で非常に強く制限されている。「魔素は通常の物質と直接相互作用しない」とも合う |
| 魔法荷の出どころ | **関数が、魔法を使っている間だけ一時的に与える。** 魔法が終われば0に戻る。狙う粒子はベクトル荷で選ぶ（上記） |
| 魔素 | **ふだんの魔法荷は0。** 魔素は多重次元に属する性質で魔法場とつながっており（下記「発動の流れ」）、魔法荷を要しない。ふだんから持つと、同じ極どうしが引き合って暗黒物質が固まり、未採用の「場所による魔素の濃淡」（`魔素.md`）が生まれてしまう。魔素を介して結合させるときは、関数がその魔素に一時的に魔法荷を与える |
| 力を運ぶもの | **魔法場の励起（スピン0）。** 下記「発動の流れ」の多次元干渉粒子（仮想粒子）のうち、魔法場そのものの励起にあたる。現実の物理でも、スピン0の粒子（湯川型の力）やスピン2の重力子が運ぶ力は、同符号どうしが引き合い、符号が逆どうしは反発する（スピン1の光子が運ぶ電磁気力とは逆）。魔法荷の「同極は引き合い、異極は反発する」は、これで説明できる |
| 力の届く距離 | 決めない。術者の力量で変わる（湯川型の力なら、運ぶ粒子の質量で届く距離が決まる） |

帰結：
- 念動のような位置の操作は、対象と術者側の基点に同じ極を与えて引き寄せ、違う極を与えて押しのける形になる。
- 作者メモの土「同種の粒子/分子同士は魔素を介さずに結合可能、異なる粒子/分子は魔素を介して結合」：同じ種類の粒子はベクトル荷が近いため、同じ極を与えると強く引き合って結合する。違う種類はベクトル荷が遠く力が弱いため、間をつなぐ魔素が要る。
- 魔法が終わって魔法荷が0に戻っても、その間にできた化学結合や移した物質はそのまま残る。

**観測できるか（2026-11-09、AIの検討。作者の依頼で記録）：** **直接は観測できないが、力のふるまいから間接的に推定できる。**
- 直接観測できない理由：
  - 測るための試験粒子を用意できない。電場なら試験電荷を置けば力の分布を測れるが、魔法荷はふだん0で、術者が狙った粒子にしか与えられないため、科学者が置いた測定用の粒子は狙われていなければ何も感じない。
  - 力を運ぶ魔法場の励起は高次元にあり、検出器にかからない（下記「魔法の観測可能性」）。
  - 魔法荷を与える関数も高次元にあり、いつ・どの粒子に・どちらの極を与えたかという過程は見えない。
- 間接的に推定できる理由：
  - 魔法を使っている間に物体が受ける力の向きと強さは、3次元で測れる（加速度・軌跡・力センサー）。魔術師は人口の約10%おり、JMAの測定制度もあるため、協力者を使った系統的な実験ができる。
  - 実験を重ねれば、「引き寄せられた物どうしは引き合い、押しのけられた物とは押し合う」「狙われた種類の物質にだけ効き、同じ種類ほど強く効く」という力の法則を経験則として取り出せる。電子を知る前に、力のふるまいから正負の電荷とクーロンの法則が導かれたのと同じ道筋である。
  - 押した反作用が高次元側や魔素（見えない）へ行くなら、3次元では運動量の保存が破れて見え、エネルギー保存則の破れと並ぶ「異常」として観測される。
- 現実の前例：クォークの**色荷**は、閉じ込めのため単独では取り出して測れないが、間接的な証拠から実在が受け入れられている。魔法荷は「直接は取り出せないが、間接的な証拠から推定される荷量」として、色荷に近い立場になる。
- 表層との関係：作中の科学が、力の観察から魔法荷に当たる概念を経験則として持っていても不自然ではない（`../README.md` 運用ルール6）。届くのは「狙われた物にだけ一時的に生じる、同じものどうしが引き合う種類の力がある」までであり、真層の中身（関数が一時的に与える、スピン0の励起が運ぶ、ベクトル荷で狙いを選ぶ）には届かない。作中でこの概念をどこまで持ち、何と呼ぶか（作者メモの用語「魔法荷」を表層でも使うか）は未定（`../未確定事項一覧.md` 0-14）。

## 魔法の呼び出し構造（**真層**・2026-10-10確定）

> 作中人物には知られていない。作者が魔法描写の一貫性を保つための基底設定。

### 魔法はAPIである
魔法とは、先史文明（次元を渡った上位存在。上記「起源に関する裏設定」）が作った**モジュール化された機構**であり、術者はその仕組みを知らないまま使っている。たとえるならAPIに近い。

```
術者の「イメージ」（説明はできないが、理解はしている）
  → API（完成品の関数群。中身は誰も知らない）
  → 魔法場（術者が直接制御する唯一の場）
  → 魔法場から任意の場（電磁場・重力場など）へ干渉する
```

> 図の「API → 魔法場」の並びは、関数を流れの一段階として描いたものではない。関数は魔法場から先の処理を決めるプログラムであり、術者は魔素で魔法場を駆動する（2026-11-09、下記「発動の流れ」）。

- **APIの関数は完成品である。** 術者は、用意された関数をイメージによって呼び出しているにすぎない。部品を組み立てて新しい魔法を作ることはない。
- **術者が直接制御するのは魔法場のみ。** 魔法場からどの場へ、どう干渉するかは関数の内部で処理される。
- 術者は「どの場を、いくつ使うか」を意識しない。直感的に使えるのは、場の組み合わせが関数の内部で既に済んでいるからである。
- 呼び出せる関数は遺伝によって決まり、家系ごとに特に遺伝しやすい関数がある（→ 相伝魔術。2026-10-19確定、`../organizations/御三家.md`「相伝魔術とは」）。相伝魔術は家系の外にも現れうる。特定の血統**しか**呼び出せない関数が存在するかは未定（旧記述「一部の関数は、特定の血統しか呼び出せない」を改めた）。名家の強さ（血・型・知識・環境）との関係は下記「発動の流れ」の「名家の強さとの対応」（2026-11-09）。

### 魔法の同一性
真層における「同じ魔法」とは、**同じ関数（原理）を呼び出していること**である。

| 見た目 | 原理 | 真層での扱い |
|--------|------|-------------|
| 同じ | 違う（イメージが違い、別の関数を呼んでいる） | **別の魔法** |
| 違う | 同じ | **同じ魔法** |

作中の人々に観測できるのは結果とイメージの手触りだけであり、呼び出している関数は確かめられない。したがって表層の分類は、別物を同じ種類として扱ったり、同じものを別の種類として扱ったりしうる（→ `../README.md` 運用ルール4）。

### 等級との関係
第0〜3魔法の等級（下記）は、**関数の内部実装がいくつの場を組み合わせているか**を表す。術者からは見えない。
術者側の消耗は「像の保持時間 × 精密さ」で決まり（`魔法体系.md`「消耗の決まり方」）、等級には依存しない。ランクと等級が独立していることの根拠でもある。

### 保留
- **関数は引数（パラメータ）を受け取るか。** 同じ関数で見た目が変わる理由をどう説明するかに関わる。上位存在は「正解」をプログラムできる存在に近いため、関数がイメージから必要な値を受け取り、適切な結果を返す設計の方が好ましい可能性がある。
- 関数の総数・粒度、アクセス権の遺伝の仕組み。

## 魔法の観測可能性

> 層：本体が高次元にあって観測できないという機序は真層。作中の科学者の立場（「否定できないが、説明もできない」）は表層として語ってよい（`魔法の分類.md`「成立史」、`世界観概要.md`「科学と魔法」）。出どころ：作者の発想（`../../notes/chat_history/2026/06/10/魔法と科学の関係.md`「ブラックホールを介して次元渡航」）をもとにした整理。細部は作者の確認記録が未確認（点検 D）。

### 基本原則：結果は見えるが、本体は見えない
魔法の現象（結果）は3次元科学で観測できる。しかし魔法の本体（高次元での機序）は、原理的に観測不可能。

| 観測状況 | 詳細 |
|---------|------|
| ✓ 観測できる | 火が出た、傷が治った、人が転移した——という現象・結果 |
| ✗ 観測できない | なぜそうなったか。高次元での接続・操作のプロセス |

**なぜ観測できないのか：**
2次元の住人は「上方向」を観測する手段を持たない。紙が動いても「世界が動いた」としか認識できない。同様に、3次元に閉じた科学の測定器は高次元方向への干渉そのものを検出できない。魔法の本体が高次元にある以上、3次元科学がどれだけ発展しても原理的な到達限界がある。

### 科学者と魔法の関係
- 科学者は魔法を「否定できない」——結果として目の前で現象が起きているから
- 科学者は魔法を「説明できない」——なぜそうなるかの機序に到達できないから
- 「魔法は存在する。しかし必ず法則があるはずだ」という信念で研究を続ける科学者が存在しうる——それは狂気にも信念にもなり得る

### 魔力量が科学的に測定できない理由
魔力（体内の魔素。上記「魔素と魔力」）は3次元で観測できず、その働きの本体も高次元にある以上、3次元の測定器でアクセスできない。経験則や感覚では分かるが、理論的・数値的な根拠を示せない。これは魔術師のランク測定が「複数の測定者による合議制」に留まる構造的理由の一つ。

### 魔術師自身も原理を知らない
神々の遺産である魔法を、現代の魔術師は原理を知らないまま使っている。現代人が半導体の量子力学的動作を理解しなくてもスマートフォンを使えるように、魔術師は「経験則として動作すること」を学ぶだけで十分に機能する。本質的な理解は誰も持っていない。

### ブラックホールとの類似
魔法による高次元への局所的な接続は、理論上ブラックホールと同種の現象である可能性がある。

| 比較 | 内容 |
|------|------|
| 魔法 | 魔術師が意図的に局所的な高次元接続を生成する技術 |
| 自然発生ブラックホール | 同種の高次元接続が自然に極端な形で発生した現象 |

実際に作中の科学者が「魔法を研究していたら、ブラックホールと同じ数式が出てきた」という状況がありうる。魔術師は古代から使い、科学者は後から理論を発見した——しかし両者とも本質を理解していない。

## 精霊と降霊術

### 精霊とは何か（**真層**）
精霊は情報生命体であり、人間とは全く別個の存在。

**2026-10-19確定（2026-06-10の作者発言を正とする）：**
> 人格情報は精霊にならない。人間と精霊は別個の生命体であり、魔法によって精霊が互換性のある肉体を得た時、我々の知る精霊となる。

| 特性 | 詳細 |
|------|------|
| 本質 | 情報の塊。**何の情報を持っているかは不明**（人間の科学では本来干渉できない生命体であり、作者にも分からないものとして扱う） |
| 通常状態 | **思考しない**。CPUのないデータ、または停止した演算機のようなもの |
| 自発性 | 通常状態では自ら動くことも語ることもない。人間とは本来、互いに干渉しあわない |
| 由来 | 人間とは起源も系統も異なる独立した生命体。**死んだ人間が精霊になるのではない** |
| 「我々の知る精霊」 | 魔法によって、互換性のある肉体（器）を得て起動した状態の精霊 |

精霊は情報として存在しているが、それを処理する基盤（神経回路に相当するもの）を持たないため、通常は沈黙したままである。「いる」が「動かない」状態。

> 旧記述「由来：人間の死後・強烈な思念の残留・その他」は、2026-06-10の相談の途中でAIが出した案が残ったもので、作者の結論（上記）と食い違っていたため改めた（2026-10-19）。

### 降霊術とは何か
降霊術は、精霊に一時的な思考基盤を与えて「起動」させる技術。

```
ダークマター（魔素）→ 仮想神経回路の構築 → 精霊と接続 → 精霊が思考・発話可能になる
```

| 項目 | 詳細 |
|------|------|
| 使用素材 | ダークマター（魔素）。体内に蓄積される性質を利用 |
| 仕組み | 魔素で精霊のための仮想神経回路を構築し、精霊情報をその回路に乗せる |
| 効果 | 精霊が「思考・会話・知識の共有」できる状態になる |
| 通常魔法との違い | 外部から情報を「呼び出す」技術であり、情報制限の例外に当たる |

降霊術が「情報取得系魔法」の通常制限（感覚拡張のみ・無から知識生成不可）を超える理由：精霊自身が知識を持つ実在であり、降霊術師は無から情報を生成しているのではなく、すでに存在する情報体と対話しているため。

**作者による原理（2026-06-10の発言。2026-10-19に正として記録）：**
> 降霊術とは基本的に、ダークマターによって構成される仮想神経回路をニューロンとして情報体を再構築する技術である。降霊時は仮想神経回路を用いるため、擬似的に精霊の記憶や精神状態となる。

### 人と精霊の主導権（2026-10-19確定）
降霊術で術者が精霊と結びつくとき、**精霊に意識を支配されるか、自分が精霊を支配するかは、術者の魔法の練度による。**

- **練度の低い術者は、精霊に精神を奪われる。** 場合によっては、二度と戻れないこともある。
- **術者が術の途中で死亡しても、精霊の活動は停止しない。** 降霊術の脳経路は、術者の脳そのものではなく魔素で組んだ仮想経路であるため。
- **事例（2026-10-19確定）：**
  - **鬼灯蓮華**：降霊術の暴走で精霊（安倍晴明）に乗っ取られ、不可逆の脳神経の損傷で死亡した後も、体が動き続けた（`../characters/鬼灯蓮華.md`）。
  - **安倍晴明**：精霊そのもの。史実の晴明は、この精霊が人の体を乗っ取って活動していた姿である（下記「確定している精霊」）。

**仮想経路の持続（2026-10-19確定）：** 仮想経路は、**必要量の魔力が続く限り保たれる。** 術者の死後も同様である（魔力量は体内の貯蓄量＝体内に蓄えた魔素の量。`魔法体系.md`「素養」、上記「魔素と魔力」）。精霊が仮想経路で体を動かしている間は、死霊魔術の関数もその体を生きているとみなす（2026-11-08「一旦」採用。下記「亡くなったばかりの死者と、呼び出す相手」）。

**精神を奪われた術者（2026-10-19確定）：**
- **精霊が離脱すれば、術者は元に戻る。**
- ただし**精霊は人体の負荷を考慮しない。** 精霊が人体の耐えられない行為をして損傷した場合、術者はその損傷を引き継いで戻る。
- 既存設定との接続：精霊が専用神経系を臨界点まで酷使すれば、術者は魔法を失った状態で戻ることになる（`魔法体系.md`「代償・リスク」。安全装置は存在しない）。

**体そのものの限界（2026-10-19確定、晴明の事例）：** 安倍晴明は、宿主の脳の限界は来なかったが、**人体の老衰の限界で活動を停止した。** 仮想経路は脳・神経の代わりにはなるが、体そのもの（臓器など）の限界は越えられない、という読みになる。
- **事例（2026-10-20確定）：** 天宮前日譚で、梓音は晴明に乗っ取られた鬼灯蓮華の体を両親の死霊で押さえ、腐敗呪術で不可逆の損傷を与えて身体機能を停止させることで、晴明を停止させる。晴明は消滅せず、器を失って沈黙に戻る（`../stories/天宮前日譚.md`「結末：蓮華の死」）。

**宿主の魔法（2026-10-20確定）：** 人の体を乗っ取った精霊は、**その体の魔法（関数）を使える。** 使える関数は体の遺伝で決まり、呼び出すのはイメージである（上記「魔法の呼び出し構造」）。帰結として、精霊が魔法を使うほど宿主の体に蓄えられた魔力が減り、仮想経路の持続も短くなる。事例：晴明は、乗っ取った蓮華の錯視・物理凍結を使える。

**練度（2026-10-19確定）：** 練度とは**イメージの精度**である。たとえば、自分の神経と仮想神経を明確に分離するイメージを保てるかどうか。**はっきりとした基準は設けない。**

**届く精霊（2026-10-20確定）：** 降霊術でどの精霊に届くかは、**距離ではなく、術者との相性（互換性）で決まる。** 精霊が「互換性のある肉体を得て起動する」（上記「精霊とは何か」）ことに沿う。大物主（三輪山）のように特定の土地に結びつく精霊もいるが、それはその精霊の性質であり、精霊一般の決まりではない。距離を問わないため、ランスロットを日本で降ろすことにも支障はない。
- 事例：鬼灯蓮華の降霊術は、国内の施設から逃亡した後に発現し、その時点で相性の合う晴明に届いた（`../characters/鬼灯蓮華.md`「降霊術の発現」）。

### 降霊術・死霊魔術・腐敗呪術の定義（2026-10-20確定）

**作者による定義：**

| 術 | 定義 |
|----|------|
| 降霊術 | **自らの肉体に精霊を宿す魔法** |
| 死霊魔術 | **その土地の過去の死亡者の情報から、仮想の質量を用いて死霊を顕現させる魔法** |
| 腐敗呪術 | **腐敗という概念を付与し適用する呪術** |

既存の確定事項との関係：
- **死霊は精霊ではない。** 精霊は人間と別個の生命体であり、人格情報は精霊にならない（上記「精霊とは何か」）。死霊は、死亡者の情報をもとに顕現させたものである。
- 顕現させられる死霊は、**術を使う土地**で過去に亡くなった者に限られる。

> 以前のメモ（`../../notes/chat_history/2026/06/03/分類案.md`）では、死霊を「同次元召喚」の「情報の再構成」の例として挙げ、「蘇生」の項で「身体の再構成は可能…か？：死霊魔法／内面の再現は困難か」としている。

#### 死霊魔術の仕組み（**真層**・2026-10-20確定）

**作者の案：** 死霊魔術が用いる情報は、土地に残っているものではない。関数が**別次元（高次元）の座標情報を基に「過去の特定領域」を算出し、その領域内の情報から亡者の情報を取得して**、顕現させる。

| 項目 | 内容 |
|------|------|
| 過去への作用 | **見るだけ。** 過去を書き換えることはできない（時間逆行・因果の遡行は不採用のまま。上記の6/3のメモ） |
| 情報の収集 | **関数による自動収集。** 死霊魔術の術者が過去を見ることはない |
| 仮想の質量 | **魔素で組んだ質量。** 触れられ、物を押さえたり戦ったりできる。魔力が続く限り顕現する（降霊術の仮想経路と同じ決まり） |
| 領域の範囲 | **術者の周囲の一定の範囲。** 広さは術者の力量で変わる。地名や町の境界など、人間が引いた区切りには従わない |
| 過去への遡り | **時間とともに薄れる。** 古い死者ほど呼びにくく、形も崩れる |

帰結：
- 対象は、領域の中で亡くなった者だけである。遺体がもう土地になくても、過去の領域には亡くなった時点の本人がいるため呼べる（事例：鬼灯蓮華の両親）。その土地にいても、別の場所で亡くなった者は対象外（事例：凍結事件の男性2名）。
- 「死者の情報が土地に残る」仕組み（情報を残しておく媒体）は設けない。

**亡くなったばかりの死者と、呼び出す相手（2026-11-08、AIの推奨を作者が「一旦」採用）：**

| 項目 | 内容 |
|------|------|
| 亡くなったばかりの死者 | **呼べる。** 古い死者ほど薄れるため、亡くなったばかりの死者がいちばん鮮明である（作者の見方「呼べる方が自然」と同じ） |
| 何をもって「亡くなった」とするか | **体全体の死（身体機能の停止）。** 精霊が仮想経路で体を動かしている間は、脳が損傷していても、関数はその体を生きているとみなす（上記「人と精霊の主導権」） |
| 誰を顕現させるか | **覚醒したばかりの術では、領域の中の亡くなった者を、関数が自動で顕現させる。** 術者は選べない。古い死者は薄れて形が崩れるため、鮮明に現れるのは新しい死者である |

- 人の目には脳の損傷の時点で亡くなっていても、関数の上ではまだ「亡くなった者」ではない、というずれが生じる。事例：天宮前日譚の鬼灯蓮華は、晴明に乗っ取られて脳神経が損傷した時点で人としては死ぬが、関数の上で「亡くなった者」になるのは、梓音が腐敗呪術で身体機能を止めたときである。そのため討伐の最中に顕現するのは、その土地で以前に亡くなった両親であり、蓮華自身ではない（`../stories/天宮前日譚.md`「結末：蓮華の死」）。
- 覚醒したばかりの術者は誰を呼ぶか選べないため、知らない死者も現れる。事例：梓音は、現れた二人が誰かを知らないまま助けられる。
- 採らない案：脳の死をもって「亡くなった」とする（討伐の最中に、いちばん鮮明な死霊として蓮華自身が現れうる。決定済みの討伐の手順が変わり、死霊が内面を持つかという保留中の論点に直接ぶつかる）。

補足（AIが示した説明。作者は未確認）：

#### 過去視の仕組み（真層・2026-11-08）

> 過去視があるか・その制約（表層）は `魔法体系.md`「過去視」（2026-11-08、AIの推奨案Bを作者が採用）。
