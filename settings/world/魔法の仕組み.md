## 理論的基盤（案）

### 世界の物理構造
本作ではM理論を基盤とした世界観を採用する（案）。

- 根源場の揺らぎにより根源粒子（弦に対応）が発生し、その性質によって各場に固定される
- 場と粒子は一対の関係にある
- **バルク次元に影響する粒子**：重力子・ディラトン・モジュライ（世界のテクスチャそのものに作用）
- **3次元ブレーンにのみ影響する粒子**：上記以外の基本粒子

### 魔法場
- 高次元（n+x次元）に存在する場
- 神（別世界の存在）によってもたらされた技術
- 各場との接続技術も神の御業とされる
- 魔法場を通じて、n次元の任意の場を操作できる

> 裏設定（`世界観概要.md` 参照）との接続：神＝4次元に移行した存在の系譜。
> 魔法場は次元上昇の際に残された技術の名残。

## エネルギー源

3次元におけるエネルギーの源は多次元の場の揺らぎ（エネルギー）。多次元干渉粒子が存在し、次元を超えて場の揺らぎに干渉する。

- 3次元だけで見るとエネルギー保存則は成立しない
- 多次元全体では成立している
- 術者は「発電機」ではなく「変換器・制御器」

「多次元干渉粒子」は便宜上の呼称。実体は多次元場の局所的な励起状態（量子場の励起）。

| 用語 | 定義 |
|------|------|
| **魔素** | ダークマターと同一の存在。ボソン。多重次元に同時に属せる性質を持つ |
| **マナ** | 体内の魔素 |
| **エーテル** | 体外の魔素 |

> **重要**: 魔素＝ダークマター。宇宙に遍在しているが、通常の物質とは直接相互作用しない。
> 魔素を介してのみ、現実の物質・エネルギーと相互作用が起こる。

### 魔素の作用連鎖
```
魔素 ⇒ 魔法場 ⇒ 根源場 ⇒ 任意場 ⇒ 物質・エネルギー
```

### 魔素の持つ荷量

**ベクトル荷**
物質の位置を表す連続的な荷量。
魔法荷の引力・反発の強度は、ベクトル荷の近似度によって決まる。

**魔法荷**
魔法荷を持つ者同士の相互作用を決める荷量。±・0の三種。

| 極性 | 挙動 |
|------|------|
| 同極（++または−−） | 引き合う（電磁力とは逆） |
| 異極（+−） | 反発する |
| 0 | 不干渉 |

根源場の操作が低次元の魔法場に干渉する際、この荷量が媒介として機能する。

### 魔法の発動メカニズム

```
人間のイメージ
  → 神の遺産である制御機構に入力
  → 多次元場の波動関数・位相が制御される
  → 多次元干渉粒子（場の励起）が発生・変調する
  → 高次元の揺らぎが3次元現象として出力される
```

- 制御機構の詳細は神の御業の遺産。解明されていない（深く追わない）
- 魔素はこのプロセスを通じてのみ現実の物質と相互作用する
- ゲージ選択的重ね合わせによる詳細操作の可能性あり（要検討）

## 魔法の呼び出し構造（**真層**・2026-10-10確定）

> 作中人物には知られていない。作者が魔法描写の一貫性を保つための基底設定。

### 魔法はAPIである
魔法とは、先史文明（次元を渡った上位存在。`魔法体系.md`「起源に関する裏設定」）が作った**モジュール化された機構**であり、術者はその仕組みを知らないまま使っている。たとえるならAPIに近い。

```
術者の「イメージ」（説明はできないが、理解はしている）
  → API（完成品の関数群。中身は誰も知らない）
  → 魔法場（術者が直接制御する唯一の場）
  → 魔法場から任意の場（電磁場・重力場など）へ干渉する
```

- **APIの関数は完成品である。** 術者は、用意された関数をイメージによって呼び出しているにすぎない。部品を組み立てて新しい魔法を作ることはない。
- **術者が直接制御するのは魔法場のみ。** 魔法場からどの場へ、どう干渉するかは関数の内部で処理される。
- 術者は「どの場を、いくつ使うか」を意識しない。直感的に使えるのは、場の組み合わせが関数の内部で既に済んでいるからである。
- 呼び出せる関数は遺伝によって決まり、家系ごとに特に遺伝しやすい関数がある（→ 相伝魔術。2026-10-19確定、`../organizations/御三家.md`「相伝魔術とは」）。相伝魔術は家系の外にも現れうる。特定の血統**しか**呼び出せない関数が存在するかは未定（旧記述「一部の関数は、特定の血統しか呼び出せない」を改めた）。

### 魔法の同一性
真層における「同じ魔法」とは、**同じ関数（原理）を呼び出していること**である。

| 見た目 | 原理 | 真層での扱い |
|--------|------|-------------|
| 同じ | 違う（イメージが違い、別の関数を呼んでいる） | **別の魔法** |
| 違う | 同じ | **同じ魔法** |

作中の人々に観測できるのは結果とイメージの手触りだけであり、呼び出している関数は確かめられない。したがって表層の分類は、別物を同じ種類として扱ったり、同じものを別の種類として扱ったりしうる（→ `../README.md` 運用ルール4）。

### 等級との関係
第0〜3魔法の等級（下記）は、**関数の内部実装がいくつの場を組み合わせているか**を表す。術者からは見えない。
術者側の消耗は「像の保持時間 × 精密さ」で決まり（`魔法体系.md`「消耗の決まり方」）、等級には依存しない。ランクと等級が独立していることの根拠でもある。

### 保留
- **関数は引数（パラメータ）を受け取るか。** 同じ関数で見た目が変わる理由をどう説明するかに関わる。上位存在は「正解」をプログラムできる存在に近いため、関数がイメージから必要な値を受け取り、適切な結果を返す設計の方が好ましい可能性がある。
- 関数の総数・粒度、アクセス権の遺伝の仕組み。

## 魔法の等級分類（案・**真層**）

> **2026-10-10確定：** 本分類は真層の設定であり、作中人物には知られていない。表層では別の分類が用いられる（`魔法体系.md`「分類の二層」）。ランクとは独立している。

### 第0魔法（根源魔法）
- 魔法場に接続し、揺らぎを操作する
- 個人ごとに専用の魔法場が存在する
- 全魔法の土台。行使可否は魔法場制御の可否に依存
- 代表的応用：魔法場直接変換（粒子の存在状態→エネルギー化。物理的媒介不要）

### 第1魔法
- 魔法場を介して、単一の場に個別に干渉
- 同時に複数場への接続も可能
- 魔法場の揺らぎを反映し、仮想粒子を用いて作用する
- 操作可能な場の例：グルーオン場・電磁場・重力場・ヒッグス場 など

### 第2魔法
- 第1魔法の複合系
- 複数の場を同時に制御する

### 第3魔法
- 第2魔法の複合系
- 複数の第2魔法を併用
- **慣用名でいう「属性魔法」のほとんどは第3魔法以上**（属性は魔法的には存在しない。下記）

## 魔法の観測可能性

### 基本原則：結果は見えるが、本体は見えない
魔法の現象（結果）は3次元科学で観測できる。しかし魔法の本体（高次元での機序）は、原理的に観測不可能。

| 観測状況 | 詳細 |
|---------|------|
| ✓ 観測できる | 火が出た、傷が治った、人が転移した——という現象・結果 |
| ✗ 観測できない | なぜそうなったか。高次元での接続・操作のプロセス |

**なぜ観測できないのか：**
2次元の住人は「上方向」を観測する手段を持たない。紙が動いても「世界が動いた」としか認識できない。同様に、3次元に閉じた科学の測定器は高次元方向への干渉そのものを検出できない。魔法の本体が高次元にある以上、3次元科学がどれだけ発展しても原理的な到達限界がある。

### 科学者と魔法の関係
- 科学者は魔法を「否定できない」——結果として目の前で現象が起きているから
- 科学者は魔法を「説明できない」——なぜそうなるかの機序に到達できないから
- 「魔法は存在する。しかし必ず法則があるはずだ」という信念で研究を続ける科学者が存在しうる——それは狂気にも信念にもなり得る

### 魔力量が科学的に測定できない理由
魔力の本体が高次元にある以上、3次元の測定器でアクセスできない。経験則や感覚では分かるが、理論的・数値的な根拠を示せない。これは魔道士のランク測定が「複数の測定者による合議制」に留まる構造的理由の一つ。

### 魔術師自身も原理を知らない
神々の遺産である魔法を、現代の魔術師は原理を知らないまま使っている。現代人が半導体の量子力学的動作を理解しなくてもスマートフォンを使えるように、魔術師は「経験則として動作すること」を学ぶだけで十分に機能する。本質的な理解は誰も持っていない。

### ブラックホールとの類似
魔法による高次元への局所的な接続は、理論上ブラックホールと同種の現象である可能性がある。

| 比較 | 内容 |
|------|------|
| 魔法 | 魔術師が意図的に局所的な高次元接続を生成する技術 |
| 自然発生ブラックホール | 同種の高次元接続が自然に極端な形で発生した現象 |

実際に作中の科学者が「魔法を研究していたら、ブラックホールと同じ数式が出てきた」という状況がありうる。魔術師は古代から使い、科学者は後から理論を発見した——しかし両者とも本質を理解していない。

## 治癒魔法

治癒魔法には明確に異なる2種類が存在する。

### 下級治癒（細胞分裂加速型）
一般的な回復魔法。広く普及しており、戦場での即応性に優れる。

| 項目 | 内容 |
|------|------|
| 仕組み | 細胞分裂・増殖を魔法で加速させる |
| 効果 | 傷の修復が急速に進む |
| 代償 | **治療対象となった患者の細胞**が、分裂回数（テロメア）を消費する |
| リスク | 同じ患者が頻繁に治療を受けると、治療部位の老化・変異蓄積・発癌等の長期リスクが高まる |
| 分布 | 一般魔術師・魔道士に広く普及 |

> **術者自身のテロメアは消費しない。** 術者側に生じるのは、通常の魔法行使と同じ精神・神経系の疲労である。患者側の負担と、術者側の魔力切れ・臨界点到達リスクは別のものとして扱う。

### 上級治癒（DNA修復型）【存在は未定】
下級治癒とは根本的に異なる機構として構想上は存在するが、**世界内に実在するか、作中に登場させるかどうかは未定。** 「御三家の秘伝」と決め打ちしない。

| 項目 | 内容（案。実在前提の仮置き） |
|------|------|
| 仕組み | DNA・細胞レベルの損傷を直接修復する |
| 効果 | 傷の修復に加え、老化の根本要因にもアプローチ可能 |
| 代償 | ほぼなし（副作用が極めて少ない） |
| リスク | 特になし |
| 分布 | 未定 |

一般魔道士と御三家（あるいは他の長命な存在）の間に寿命格差を設けるかどうか、設けるとして上級治癒を根拠にするかどうかも、この項目とあわせて未定のまま保留する。

### テロメア利用設定の生物学的制約

現実の生物学に基づく基礎事項は `../../notes/research/テロメア.md` を参照。

- テロメアだけを伸ばしても、DNA変異、ミトコンドリア損傷、神経変性などは修復されない。
- 全細胞のテロメラーゼを活性化すると、前がん細胞やがん細胞も増殖しやすくなる。
- 造血幹細胞や皮膚、腸管など、細胞分裂の多い組織ほど効果と副作用が先に現れる。
- 神経や心筋のように分裂頻度の低い細胞では、単純なテロメア延長の恩恵は小さい可能性がある。
- 安全な長寿化には、テロメア延長だけでなく、DNA損傷検査、異常細胞の排除、免疫監視、エピジェネティック状態の修復などが必要になる。
- 長寿能力が遺伝する設定では、長いテロメアそのものよりも、テロメアの損傷を検知し、必要な細胞だけを安全に維持する制御能力を遺伝させる方が説得力を持たせやすい。

## 精霊と降霊術

### 精霊とは何か（**真層**）
精霊は情報生命体であり、人間とは全く別個の存在。

**2026-10-19確定（2026-06-10の作者発言を正とする）：**
> 人格情報は精霊にならない。人間と精霊は別個の生命体であり、魔法によって精霊が互換性のある肉体を得た時、我々の知る精霊となる。

| 特性 | 詳細 |
|------|------|
| 本質 | 情報の塊。**何の情報を持っているかは不明**（人間の科学では本来干渉できない生命体であり、作者にも分からないものとして扱う） |
| 通常状態 | **思考しない**。CPUのないデータ、または停止した演算機のようなもの |
| 自発性 | 通常状態では自ら動くことも語ることもない。人間とは本来、互いに干渉しあわない |
| 由来 | 人間とは起源も系統も異なる独立した生命体。**死んだ人間が精霊になるのではない** |
| 「我々の知る精霊」 | 魔法によって、互換性のある肉体（器）を得て起動した状態の精霊 |

精霊は情報として存在しているが、それを処理する基盤（神経回路に相当するもの）を持たないため、通常は沈黙したままである。「いる」が「動かない」状態。

> 旧記述「由来：人間の死後・強烈な思念の残留・その他」は、2026-06-10の相談の途中でAIが出した案が残ったもので、作者の結論（上記）と食い違っていたため改めた（2026-10-19）。

### 降霊術とは何か
降霊術は、精霊に一時的な思考基盤を与えて「起動」させる技術。

```
ダークマター（魔素）→ 仮想神経回路の構築 → 精霊と接続 → 精霊が思考・発話可能になる
```

| 項目 | 詳細 |
|------|------|
| 使用素材 | ダークマター（魔素）。体内に蓄積される性質を利用 |
| 仕組み | 魔素で精霊のための仮想神経回路を構築し、精霊情報をその回路に乗せる |
| 効果 | 精霊が「思考・会話・知識の共有」できる状態になる |
| 通常魔法との違い | 外部から情報を「呼び出す」技術であり、情報制限の例外に当たる |

降霊術が「情報取得系魔法」の通常制限（感覚拡張のみ・無から知識生成不可）を超える理由：精霊自身が知識を持つ実在であり、降霊術師は無から情報を生成しているのではなく、すでに存在する情報体と対話しているため。

**作者による原理（2026-06-10の発言。2026-10-19に正として記録）：**
> 降霊術とは基本的に、ダークマターによって構成される仮想神経回路をニューロンとして情報体を再構築する技術である。降霊時は仮想神経回路を用いるため、擬似的に精霊の記憶や精神状態となる。

### 人と精霊の主導権（2026-10-19確定）
降霊術で術者が精霊と結びつくとき、**精霊に意識を支配されるか、自分が精霊を支配するかは、術者の魔法の練度による。**

- **練度の低い術者は、精霊に精神を奪われる。** 場合によっては、二度と戻れないこともある。
- **術者が術の途中で死亡しても、精霊の活動は停止しない。** 降霊術の脳経路は、術者の脳そのものではなく魔素で組んだ仮想経路であるため。
- **事例（2026-10-19確定）：**
  - **鬼灯蓮華**：降霊術の暴走で精霊（安倍晴明）に乗っ取られ、不可逆の脳神経の損傷で死亡した後も、体が動き続けた（`../characters/鬼灯蓮華.md`）。
  - **安倍晴明**：精霊そのもの。史実の晴明は、この精霊が人の体を乗っ取って活動していた姿である（下記「確定している精霊」）。

**仮想経路の持続（2026-10-19確定）：** 仮想経路は、**必要量の魔力が続く限り保たれる。** 術者の死後も同様である（魔力量は体内の貯蓄量。`魔法体系.md`「素養」）。

**精神を奪われた術者（2026-10-19確定）：**
- **精霊が離脱すれば、術者は元に戻る。**
- ただし**精霊は人体の負荷を考慮しない。** 精霊が人体の耐えられない行為をして損傷した場合、術者はその損傷を引き継いで戻る。
- 既存設定との接続：精霊が専用神経系を臨界点まで酷使すれば、術者は魔法を失った状態で戻ることになる（`魔法体系.md`「代償・リスク」。安全装置は存在しない）。

**体そのものの限界（2026-10-19確定、晴明の事例）：** 安倍晴明は、宿主の脳の限界は来なかったが、**人体の老衰の限界で活動を停止した。** 仮想経路は脳・神経の代わりにはなるが、体そのもの（臓器など）の限界は越えられない、という読みになる。
- **事例（2026-10-20確定）：** 天宮前日譚で、梓音は晴明に乗っ取られた鬼灯蓮華の体を両親の死霊で押さえ、腐敗呪術で不可逆の損傷を与えて身体機能を停止させることで、晴明を停止させる。晴明は消滅せず、器を失って沈黙に戻る（`../stories/天宮前日譚.md`「結末：蓮華の死」）。

**宿主の魔法（2026-10-20確定）：** 人の体を乗っ取った精霊は、**その体の魔法（関数）を使える。** 使える関数は体の遺伝で決まり、呼び出すのはイメージである（上記「魔法の呼び出し構造」）。帰結として、精霊が魔法を使うほど宿主の体に蓄えられた魔力が減り、仮想経路の持続も短くなる。事例：晴明は、乗っ取った蓮華の錯視・物理凍結を使える。

**練度（2026-10-19確定）：** 練度とは**イメージの精度**である。たとえば、自分の神経と仮想神経を明確に分離するイメージを保てるかどうか。**はっきりとした基準は設けない。**

**届く精霊（2026-10-20確定）：** 降霊術でどの精霊に届くかは、**距離ではなく、術者との相性（互換性）で決まる。** 精霊が「互換性のある肉体を得て起動する」（上記「精霊とは何か」）ことに沿う。大物主（三輪山）のように特定の土地に結びつく精霊もいるが、それはその精霊の性質であり、精霊一般の決まりではない。距離を問わないため、ランスロットを日本で降ろすことにも支障はない。
- 事例：鬼灯蓮華の降霊術は、国内の施設から逃亡した後に発現し、その時点で相性の合う晴明に届いた（`../characters/鬼灯蓮華.md`「降霊術の発現」）。

未定：
- 乗っ取った精霊が、宿主の記憶をどこまで使えるか（晴明は宿主の人生をどう引き継いだか。蓮華の記憶を帯びて梓音の前に現れるか）
- ランスロットも、安倍晴明と同じ型（人の体を乗っ取って活動した精霊）か
- 「二度と戻れない」場合の条件（精霊が離脱しない場合、引き継いだ損傷が回復しない場合など）
- 精霊側からの強制的な乗っ取りが起きる条件（精霊は通常、自ら動かない。魔法の暴走で意図せず仮想経路が組まれる場合など。`../characters/鬼灯蓮華.md`）。事例：晴明は乗っ取りの前から蓮華の降霊術で繰り返し起動しており、降ろされている間に思考して復活を画策し、人目を避けて鬼灯家の旧家（鞍馬本町）で蓮華を乗っ取った（2026-10-20確定）。降霊術で繰り返し起動した精霊は、自ら乗っ取りを企てうる。術者に自覚がないまま起動が重なることもあり、周囲には夢遊病のように見える（事例：蓮華）

### 降霊術・死霊魔術・腐敗呪術の定義（2026-10-20確定）

**作者による定義：**

| 術 | 定義 |
|----|------|
| 降霊術 | **自らの肉体に精霊を宿す魔法** |
| 死霊魔術 | **その土地の過去の死亡者の情報から、仮想の質量を用いて死霊を顕現させる魔法** |
| 腐敗呪術 | **腐敗という概念を付与し適用する呪術** |

既存の確定事項との関係：
- **死霊は精霊ではない。** 精霊は人間と別個の生命体であり、人格情報は精霊にならない（上記「精霊とは何か」）。死霊は、死亡者の情報をもとに顕現させたものである。
- 顕現させられる死霊は、**術を使う土地**で過去に亡くなった者に限られる。

> 以前のメモ（`../../notes/chat_history/2026/06/03/分類案.md`）では、死霊を「同次元召喚」の「情報の再構成」の例として挙げ、「蘇生」の項で「身体の再構成は可能…か？：死霊魔法／内面の再現は困難か」としている。

#### 死霊魔術の仕組み（**真層**・2026-10-20確定）

**作者の案：** 死霊魔術が用いる情報は、土地に残っているものではない。関数が**別次元（高次元）の座標情報を基に「過去の特定領域」を算出し、その領域内の情報から亡者の情報を取得して**、顕現させる。

| 項目 | 内容 |
|------|------|
| 過去への作用 | **見るだけ。** 過去を書き換えることはできない（時間逆行・因果の遡行は不採用のまま。上記の6/3のメモ） |
| 情報の収集 | **関数による自動収集。** 死霊魔術の術者が過去を見ることはない |
| 仮想の質量 | **魔素で組んだ質量。** 触れられ、物を押さえたり戦ったりできる。魔力が続く限り顕現する（降霊術の仮想経路と同じ決まり） |
| 領域の範囲 | **術者の周囲の一定の範囲。** 広さは術者の力量で変わる。地名や町の境界など、人間が引いた区切りには従わない |
| 過去への遡り | **時間とともに薄れる。** 古い死者ほど呼びにくく、形も崩れる |

帰結：
- 対象は、領域の中で亡くなった者だけである。遺体がもう土地になくても、過去の領域には亡くなった時点の本人がいるため呼べる（事例：鬼灯蓮華の両親）。その土地にいても、別の場所で亡くなった者は対象外（事例：凍結事件の男性2名）。
- 「死者の情報が土地に残る」仕組み（情報を残しておく媒体）は設けない。

補足（AIが示した説明。作者は未確認）：
- 地球は自転・公転し、太陽系も銀河の中を動いているため、「この土地の過去」は今と同じ空間座標にはない。高次元の座標から割り出す必要があるのは、このためと説明できる。
- 古い死者ほど薄れるのは、遠い過去ほど座標の割り出しの誤差が大きくなり、領域がぶれて情報が粗くなるため、と説明できる。
