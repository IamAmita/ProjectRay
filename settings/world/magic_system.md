# 魔法体系

## 魔法の本質

魔法とは「別の次元・存在」から流れ込んでくる力であり、特定の才能を持つ人間だけが受け取れる。

### 起源に関する裏設定
この設定は基本的に作中人物が知るものではなく、作中で明示的に言及する予定もない。
完結後の裏設定公開などで初めて明かされる可能性がある、世界の底にある設定として扱う。

魔法は、人類が作った技術ではない。
1次元の世界における知的存在が極致に達して2次元へ移行し、その系譜がさらに3次元へ到達した。
3次元におけるその系譜は、人類から見れば「神」と呼んで差し支えない存在であり、彼らもまた極致に達して4次元へ移行した。

現在の3次元世界に存在する魔法は、神々が4次元へ移行した後に残された、次元上昇技術の名残・残響・低次元側インターフェースである。
魔法とは次元ごとに異なる振る舞いをするが、本質的には同一系統の技術である。

表向きには、魔法は「別の次元・存在から流れ込んでくる力」として理解される。
裏設定上は、魔術師が高次元技術の残留構造に部分的に接続し、自身の身体・意識・認識を通じて現象化している。
神々は基本的にこの世界を直接管理しておらず、魔法は恩寵というより、残された巨大な技術基盤を人間が限定的に利用しているものに近い。

この裏設定は、魔法描写の一貫性を保つための羅針盤として用いる。
毎場面で厳密に参照するものではなく、魔法の起源・才能・限界・古代神話の手触りに迷ったときの基底設定とする。

## 使用者

### 魔術師と魔道士の区別
国際魔道条約の定義による重要な区別。

| 用語 | 定義 |
|------|------|
| **魔術師** | 魔法能力を有する者（自然的存在） |
| **魔道士** | 締約国の登録制度に基づき登録された魔術師（社会的存在） |

魔術師として生まれ、教育・登録を経て初めて魔道士になる。
登録しない者は魔術師のまま——制度の外側に留まる存在として扱われる。

### 人口比率
全人口の約10%。「珍しいが例外的ではない」ライン。制度化・管理が進みやすい比率。

## ランク制度

### ランクの定義
使用できる魔法の規模・精度・強度により測定される。種類による区別はなく、量的・質的な上達の差として捉える（ピアノの習熟に近い感覚）。

### ランクの変動
訓練・経験によって上昇・下降どちらもある。維持にも継続的な努力が必要。老いや不調によるランク低下もありうる。「全盛期」という概念が生じる。

### 二重構造
現在のランクと過去の履歴が両方記録される。
例：「現Bランク（過去A）」のような表記が公的書類に存在する。
社会は魔法使いを「現在の能力」と「人生の軌跡」の両面で評価する。

## 測定制度

### 測定頻度
年1回、義務的な再測定がある。逃げられない頻度であり、魔法使いに継続的な緊張感を与える。

### 測定方法
複数の測定者による合議制で属人性の排除を試みている。ただし完全な客観化は達成されておらず、制度を信頼する者と疑う者が共存する。

### 測定機関
日本国内では日本魔道協会（JMA）が担う。
JMAは国際魔道協会（IMA）の国際魔道条約に基づく国内実施機関。
→ 詳細は `settings/organizations/JMA.md` を参照。

### 国・地域との関係
1947年設立の国際魔道協会（IMA）が国際的な管理の枠組みを提供する。
日本はIMAの締約国であり、登録魔道士の情報をIMAに報告する義務を負う。
締約国間でのランク認定の相互承認については未定。
→ 詳細は `settings/organizations/IMA.md` を参照。

## 魔道士の実力決定要因

### 実力の基本公式
```
実力 = 素養 × 教育 × 経験 × 資源
```

| 要素 | 内容 |
|------|------|
| 素養（先天要因） | 魔力量・魔法適性・固有能力の質・学習速度 |
| 教育 | 家伝魔法・師匠・理論教育・秘術 |
| 経験 | 実戦・研究・失敗・人生経験 |
| 資源 | 魔道具・財産・人脈・組織力 |

素養がスタートラインと天井を決め、鍛錬はその範囲内での到達点を決める。努力は確実に意味を持つが、素養の壁は越えられない。「人は生まれながらに不平等」というテーマに直結する構造。

### 実力分布
生まれつきの素養は**対数正規分布**に近い（多数の遺伝的・環境的要因の積から生じる）。そこに教育・経験・秘術による増幅が加わることで、最終的な実力は**べき分布**に近づく。強い者ほど良い師匠・魔道具・情報へのアクセスが増し、さらに成長するという正のフィードバックが働く。

結果として：
- 一般魔道士同士の差は数倍程度
- 御三家クラスになると一般魔道士の数十〜数百倍の実力差が生じうる

### 魔道名家の優位性
御三家の強さは「遺伝のみ」でも「環境のみ」でも説明できない。複合要因で成立している（推定値）。

| 要因 | 貢献度 |
|------|--------|
| 遺伝 | 20% |
| 教育 | 30% |
| 秘術の継承 | 20% |
| 人脈 | 20% |
| 資産 | 10% |

「御三家の子だから強い」のではなく、「御三家だけが超高位の才能を十分に開花させる環境を持っている」構造。才能自体は社会全体に散らばっているが、それを最後まで育てられる者が少ない。

### 一般家庭から高位魔術師が出にくい理由

| パターン | 詳細 |
|----------|------|
| 発現条件の無知 | 呼吸法・瞑想等を幼少期に習得しないと才能が発現しない可能性 |
| 暴走・消失 | 管理なしの発現 → 事故死または能力抑圧による消失 |
| 協会の囲い込み | 才能発覚後に保護され名家へ養子縁組 → 統計上「名家出身者」になる |
| 社会的選別 | 魔導書・師匠・実験設備の壁で伸びしろが制限される |

| 出自 | A級到達率（推定） |
|------|-----------------|
| 御三家 | 40% |
| 名家 | 10% |
| 一般魔術師家系 | 1% |
| 非魔術師家系 | 0.01% |

## 情報取得系魔法

### 基本原則
魔法は**感覚の拡張**は可能だが、**情報を無から生成**することはできない。

| 可否 | 内容 |
|------|------|
| ○ | 千里眼・遠見など知覚範囲の拡張 |
| ○ | 非魔術師には知覚不能な現象（魔力場等）の感知 |
| ✗ | 突如として新たな知識が内側に生まれる類のもの |

例外：降霊術のみ通常のルールとは異なる挙動をする。
→ 詳細は `magic_mechanics.md` の「精霊と降霊術」を参照。
