# 虹命山

## その他

### 火口
- 直径：800m
- 深度：100m
- 濃硫黄泉

### 山体
- 標高：900m
- 中心はカルデラ中央から南に4km
- 平均斜度：20°（丘陵的）

### 岩質
- 主組成：玄武岩質安山岩（BA　SiO₂ 53–57%）、安山岩（And　57–63%）
- 副組成：デイサイト（Dac　63–69%）が浅部で時折出現
- ガス特性：SO₂・H₂Sを多く含む島弧型

### マグマ溜り
- 位置・規模：地下約7km、楕円形の上部マグマ溜りが南側へ偏在
- 内部構成：マグマ液体・結晶（斜長石・輝石など）・火山ガス（二酸化硫黄（亜硫酸）多め、硫化水素少なめ）の混相

### 火山ガス
| 成分 | 排出量 |
|------|--------|
| 全体 | 15,000〜60,000 t/日 |
| CO₂ | 1,000〜7,000 t/日 |
| SO₂ | 500〜2,000 t/日 |
| H₂S | 15〜200 t/日 |

- 導線：火道の主導線のみ

### 熱水系
- 虹命樹の吸収
- 温泉

### 地質層

| 層 | 名称 | 詳細 |
|----|------|------|
| 1 | 表土・風化灰土（黒ボク化） | |
| 2 | 新期スコリア層（8000年前） | 最後の噴火の黒〜赤スコリア。厚さ1〜3m。層理が明瞭に残る。 |
| 3 | 新期溶岩層（8000年前） | 山頂・斜面を構成する安山岩溶岩。成層火山の骨格。 |
| 4 | 火砕流・軽石層（不透水帯） | 古噴火の火砕流堆積物。温泉帯（段状湧出）の原因。 |
| 5 | 古期溶岩（安山岩〜デイサイト） | 山体の中心を成す強固な層。外輪山の基盤。 |
| 6 | 熱水変質帯（粘土化） | 南斜面を中心に形成。崩落・谷形成の主要因。 |
| 7 | 火道周縁ガス帯（SO₂/H₂S豊富） | 火山の中心火道を取り巻く高温帯。虹命樹が利用するガス源。 |
| 8 | 基盤岩（海成層＋火山性基盤） | 島全体の土台を構成。 |
