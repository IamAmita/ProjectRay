# 魔法の分類（表層）

> **本ファイルの位置づけ:**
> **これは表層の設定である。** 作中世界で用いられている魔法の分類を管理する。作中人物・教科書・登録書類の記述として本文に登場してよい。
> 真層（実際の機構）は `魔法の仕組み.md`「魔法の呼び出し構造」。真層では、魔法の同一性は呼び出している関数（原理）で決まり、見た目では決まらない。表層の分類はそれを確かめられないため、部分的に誤っている。
> 二層構造の原則は `../README.md` を参照。
>
> **作成日：** 2026-10-10

---

## 1. 基本方針（確定）

- 表層の正式な分類は、**近代の科学的分類（系統分類）**である。観測される物理的な作用によって魔法を分ける。
- **属性（火・水・雷など）は魔法的には存在しない。** 一般社会・報道・伝承で使われる慣用的な呼び名にすぎない。
- 個別の能力をどの系統に置くかは、検討のたびに修正し、その都度この方針を明確化していく。

### 補足（案）：公式の分類以外の「分け方」

| 分け方 | 使う人 | 基準 |
|--------|--------|------|
| 属性（慣用名） | 一般社会・報道・伝承 | 結果の見た目を神話・古典の語彙で呼ぶ。文化圏ごとに異なる |
| 家伝の「型」 | 名家・師弟の間 | イメージの作り方。言語化できないため公の体系にならず、口伝・秘伝として継承される |

真層では関数を選ぶのはイメージであるため、家伝の「型」は公式分類より真層に近いことがある（`魔法体系.md`「魔道名家の優位性」の秘術の継承と接続）。

## 2. 系統分類（叩き台）

| 系統 | 観測される作用 | 例 |
|------|---------------|----|
| 熱系 | 温度の上昇・低下 | 炎、物理凍結 |
| 電磁系 | 電気・光・磁気 | 紫電 |
| 力学系 | 物体の運動・力・変形 | 棘の操作、念動 |
| 物質変成系 | 化学的な変化（酸化・分解・合成） | 腐敗呪術、酸化呪術 |
| 生体系 | 生体の機能・組織の変化 | 治癒（九系統は下位分類。`治癒魔法の系統.md`）、身体強化、痛覚麻痺、**千里眼（目の強化）** |
| 感覚系 | 他者の知覚への作用 | 錯視、音響による攪乱 |
| 精霊系 | 精霊・霊的存在に関わる作用 | 降霊術、死霊魔術、シャーマン関連の魔法 |
| 特殊系（分類保留） | 物理的に説明できない作用 | 召喚、結界、魔法の阻害（鎮静呪術） |

### 修正履歴
- 2026-10-10：千里眼を「情報取得系」から生体系へ移した（目の強化であるため）。精霊系を新設した。

### 分類が誤りうる典型
- **見た目が同じで中身が別。** 物理凍結は熱系（冷却）に分類されるが、真層では熱を奪う関数ではなく、分子運動を止める別の関数かもしれない。
- **見た目が別で中身が同じ。** 腐敗・酸化・浄化の各呪術は物質変成系の別々の魔法として登録されるが、真層では同じ関数の現れ方の違いかもしれない。
- **特殊系は、科学が説明を保留した種類の寄せ集め。** 真層での中身はばらばらであり、特別指定魔道士（`魔法体系.md`）が集まりやすい。

## 3. 成立史（2026-10-10確定）

魔法を自然科学の観点から究明する勢力は、**19世紀半ば**に決定的に強くなった。転換点は、産業革命・エネルギー革命による魔法の価値の低下と、エネルギー保存則の確立が重なったことである。

| 時期 | 現実の出来事 | 魔法学で起きたこと |
|------|-------------|-------------------|
| 17世紀 | 科学革命（ベーコンの経験主義、ニュートン、1660年王立協会） | 非魔術師の学者による観測・分類が始まる。枠組みはまだ四元素で、魔法は自然哲学の一分野 |
| 18世紀末 | 化学革命（1789年、ラヴォアジエ）。四元素説が崩れる | **属性が科学の座を失い、慣用名に転落する。** 「火・水・風・土」は、物質の分類としても魔法の分類としても学問から退場する |
| 19世紀前半 | 産業革命・エネルギー革命 | 魔法の経済的価値が下がる。魔術師は社会の権威から研究の対象へと立場が逆転し、非魔術師の科学者が主導権を握る |
| 1840年代 | エネルギー保存則の確立（ジュール、ヘルムホルツ） | 魔法が3次元ではエネルギー保存則を破ることが、科学最大の異常として浮上する。科学者が魔法を「否定できないが、説明もできない」立場に置かれるのはここからである |
| 19世紀後半 | 熱力学・電磁気学・生理学が学問として独立。1882年英国心霊研究協会 | 魔道学の学会が成立する。**系統分類の原型**が、このとき確立した物理学の分野の境界を借りて作られる（熱系＝熱力学、電磁系＝電磁気学、生体系＝生理学…） |
| 20世紀前半 | 二度の世界大戦 | 軍事的必要から、各国で魔術師の登録と分類が標準化される |
| 1950年代（仮） | IMA設立（1947年）後 | IMAが各国の分類を統一し、**国際標準の系統分類**を定める。JMAの登録に記載される「系統」はこれに従う |
| 2003年〜（仮） | 分子生物学の発展 | 生体系の下位分類として、治癒魔法の九系統が提唱される（`治癒魔法の系統.md`） |

### この経緯から導かれること
- **産業革命は、魔法と科学の力関係を逆転させた。** 魔術師が権威でなくなったからこそ、魔法は外から観察し分類する対象になった。
- **系統分類が「作用」で魔法を分けるのは、19世紀の物理学の分野の境界を借りたからである。** 分類の軸は人間の学問の都合で決まっており、真層の関数とは無関係である。これが表層の分類がずれる根本の理由である。
