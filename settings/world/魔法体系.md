## 魔法の本質

魔法とは「別の次元・存在」から流れ込んでくる力であり、特定の才能を持つ人間だけが受け取れる。

これが作中で一般に理解されている魔法の姿である。作中の科学は、魔法の結果は観測できるが、その本体と機序には到達できず、魔法が3次元ではエネルギー保存則を破るという異常を説明できない（「否定できないが、説明もできない」。`魔法の分類.md`「成立史」、`世界観概要.md`「科学と魔法」）。

> 真層（起源・エネルギー源・発動の機序）は `魔法の仕組み.md`「起源に関する裏設定」「エネルギー源」「魔法の発動メカニズム」「魔法の呼び出し構造」。

### 分類の二層

**分類の二層（2026-10-10確定）：**
- 第0〜3魔法の等級分類は**真層**の設定であり、作中では知られていない。
- 作中（表層）では、魔法の歴史的・経験的な経緯と近代の科学的分析による**別の分類**が用いられる。正式な分類は近代の系統分類（→ `魔法の分類.md`）。
- **ランクと等級は独立している。** ランクは人の技量（規模・精度・強度）、等級は魔法の種類の複雑さであり、互いに対応しない。人物の力量は「使える系統 × ランク ×（該当すれば）特別指定」で表す。
- **属性は魔法的には存在しない。** 火・水などの属性は、便宜上の慣用的な呼び名にすぎない（表層の分類と併せて整理する）。

## 使用者

### 魔術師と魔道士の区別
国際魔道条約の定義による重要な区別。

| 用語 | 定義 |
|------|------|
| **魔術師** | 魔法能力を有する者（自然的存在）。魔法が使える人間全般を指す |
| **魔道士** | 締約国の制度に基づき、登録された魔術師（社会的存在）。日本では、教育・研修中の**見習い魔道士**と、教育・研修を終えた**公認魔道士**に分かれる |

**呼び名（2026-11-11、作者決定）：**

| 呼び名 | 誰を指すか | 日本の登録 |
|---|---|---|
| **魔術師** | 魔法が使える人間全般（見習い魔道士・公認魔道士・未登録魔術師のすべてを含む） | — |
| **見習い魔道士** | 登録済みで、教育・研修中の魔道士（学院の生徒など） | 魔術師登録の後 |
| **公認魔道士** | 教育・研修を終えた魔道士 | 魔道士登録の後 |
| 未登録魔術師 | 魔術師登録のない魔術師 | なし |

魔術師として生まれ、登録されて魔道士（見習い）になり、教育・研修を経て公認魔道士になる。見習いと公認の区分は日本の国内法によるもので、条約の上ではどちらも「魔道士」である。
**日本国内では、登録は二つに分かれ、どちらも国内法による義務である**（2026-11-07作者決定。→ `organizations/日本魔道協会.md`「魔術師登録」「魔道士登録制度」）。
- **魔術師登録**：顕在的魔術師と判定されたすぐ後に行う。魔法を使える人間であることを国が把握するための登録で、IMAへの報告の対象になる。これにより**見習い魔道士**になる。
- **魔道士登録**：一定の教育・研修を受けた後に行う。社会の中で魔法を使うための基礎資格である。これにより**公認魔道士**になる。

> **書き分けの方針（2026-11-11、AIの推奨案Aを作者が採用）：** 能力・人口・ランク・実力・才能の話は「魔術師／非魔術師」。登録・資格・職務・制度上の身分の話は「魔道士」とし、区別が要る所では「見習い魔道士／公認魔道士」と書く。1947年より前の「魔道士」は、国家や制度に属する魔術師の呼び名とする（近世に原型が現れ、近代に呼び名として定まり、1947年に条約で定義された。`世界史と魔法.md` の作者のメモ）。作中人物の台詞は人物の語彙に任せる（口語で混ぜてよい）。
> 経緯：11-07の時点では、魔道士＝魔道士登録を済ませた者だけで、学院の生徒は魔道士ではなかった。11-11、作者が三つの呼び名を決め、登録された時点で魔道士（見習い）になる形に改めた。登録の名前（魔術師登録・魔道士登録）は、作者メモの言葉を残すため変えていない（AIの推奨を作者が採用。採らなかった案：二つ目を「公認登録」に改める）。

また、判定の経路や年齢を問わず、**魔法が発現した者には届出の義務がある**（2026-10-10確定。→ `organizations/日本魔道協会.md`）。
魔術師登録のない者（未登録魔術師）は制度の建前上ほとんど存在しないはずの**例外的存在**であり、法を逃れている・見つかっていない・何らかの特殊事情を抱えているといった、それ自体が物語上の異常事態を示すシグナルとして扱う。罰則・摘発の仕組みは `organizations/日本魔道協会.md`「未登録魔術師の扱い」（2026-10-10確定）。

登録（魔道士としての基礎資格）とは別に、特定の職務に従事するための専門資格が派生することがある（例：`AI_Novel/命脈/構想.md` の「魔道救急救命士」）。基礎登録は国が一律に課す義務、専門資格は職務ごとに任意で申請・取得するもの、という二階建て構造になる。
**魔法に関する資格はすべてJMA（日本魔道協会）が一元的に認定・管理する。** 地方自治体や民間が独自に魔法関連資格を発行することはない（→ `organizations/日本魔道協会.md`）。

専門資格の審査では、総合ランクだけでなく、その職務に必要な系統・出力・精度・判断能力が個別に確認される。したがってCランクであっても、申請した職務について必要能力を認められれば資格を取得・維持できる。具体的な審査項目や更新条件は未定。

専門資格には**行使範囲**（独立行使／指示下行使）の付帯条件があり、資格の休止制度もある（2026-10-10確定）。詳細は `organizations/日本魔道協会.md` の「行使範囲と休止」を参照。

## ランク制度

### ランクの定義
使用できる魔法の規模・精度・強度により測定される。種類による区別はなく、量的・質的な上達の差として捉える（ピアノの習熟に近い感覚）。

### ランクの変動
訓練・経験によって上昇・下降どちらもある。維持にも継続的な努力が必要。老いや不調によるランク低下もありうる。「全盛期」という概念が生じる。

### 二重構造
現在のランクと過去の履歴が両方記録される。
例：「現Bランク（過去A）」のような表記が公的書類に存在する。
社会は魔法使いを「現在の能力」と「人生の軌跡」の両面で評価する。

### ランク外の区分：特別指定魔道士（2026-10-10確定）

ランクとは別に、国際魔道条約第4条に基づく**特別指定魔道士**の区分がある（→ `organizations/国際魔道協会.md`）。

| | ランク（C/B/A） | 特別指定魔道士 |
|---|---|---|
| 表すもの | 技量の測定結果 | 国家・社会にとっての影響の大きさ |
| 決める者 | JMA（年1回の測定） | **国家**（IMAの規則が定める基準に基づく） |
| 本人の意思 | 測定は義務 | **本人の同意を要しない**（国家的管理区分であるため） |
| 規模 | Aは国内約12万人 | **国内に数十人程度**（目安） |

**ランクとの関係（確定）：** 特別指定はランクと重複する。指定された魔道士も通常どおりランクを持ち、年1回の再測定を受ける（例：「現A・特別指定」）。

**指定の対象（確定）：** 実力はべき分布に従う（→「実力分布」）。指定されるのは次の二種である。

1. **べき分布の最上位層。** 分布の上では連続していても、現実には通常の管理の枠を超える例外的な存在になる。
2. **分布から外れた例外。** べき分布の中に時折現れる、通常の序列では捉えられない魔道士。

**指定の基準（確定）：** 魔道世界における一般的な基準から**著しく逸脱した特性・規模・効能**を持つこと。
「強さ」の序列ではなく、一般的な基準からの逸脱の度合いで判断する。上の二種はいずれも、この逸脱の現れ方の違いである。

- 基準はランクから独立している。**Cランクでありながら特別指定を受けることもありうる**（例：規模は小さいが、効能や特性が一般的な基準から著しく逸脱している場合）。ランクは規模・精度・強度を共通の物差しで測るが、指定はその物差しに乗らない逸脱も対象にするためである。
- 指定は**個別具体的に**行う。家柄・地位（当主であること等）を理由に指定されることはない。
- ただし、指定は国家の政治判断であるため、**政治的な意図によって指定・不指定が左右される余地**がある（→ 下記「指定機関」、`organizations/国際魔道協会.md` 第4条の過少指定の誘因）。どこまで歪むかは要検討。

**指定の効果（確定）**

| 種類 | 内容 |
|------|------|
| 届出 | 住所と長期の移動を所管機関へ届け出る |
| 出国 | 事前の許可を要する。IMAへ通知される |
| 行使の制限 | 他国や私的な組織のための行使を禁じる |
| 協力 | 有事・大規模災害時、国の要請に応じる**努力義務**。拒否への罰則はない |
| 秘匿 | 誰が指定されているかは非公開。知るのは本人・所管機関・IMAのみ |

協力を努力義務にとどめるのは、責務を法が名指しするだけで、応じるかどうかを各人のノブレス・オブリージュに委ねるためである（→ `themes/ノブレスオブリージュ観.md`）。

**指定機関（2026-10-10採用。見直しの余地あり）：** 日本国内では**内閣総理大臣**が指定する。JMAは審査資料（測定データ）と意見を提出するにとどまる。
測定を担う技術機関（JMA）は正確な申告を求め、政府は戦力の秘匿を望みうる。指定を政治判断に置くことで、この緊張が組織間に生じる。JMAの所管省庁が未定でも成立する。

**指定の解除（確定）**

- 解除は国家の判断のみによる。本人は申請できない。
- 能力の低下・死亡に応じ、国家の見直しにより解除される。
- **臨界点到達により魔法を失った場合は解除される。** 指定から確実に外れる方法は、魔法を失うことしかない。

**未定：**
- 年齢を問わず指定しうるか（案：国家的管理区分である以上、12歳の判定以後なら年齢を問わない）。2026-11-07に登録を魔術師登録（判定のすぐ後）と魔道士登録（教育・研修の後）に分けたため、指定の対象を公認魔道士に限ると、教育・研修中の見習い魔道士（子ども）は指定されない。対象をどちらにするかは作者が後で考える（未確定事項一覧 1-9⑤）。2026-11-11に見習いも魔道士と決まったため、広げても名前は「特別指定魔道士」のままでよい
- 政治的な意図が指定に及ぼす影響の範囲（御三家との関係を含む）
- 誰が指定されているか（御三家の当主・次期当主を含め、個別に検討）。神原嶺については「安曇野事件後に指定された」案があるが、`characters/神原嶺.md` の「現在の魔法能力」（未確定事項一覧 5-1）と併せて判断する

## 測定制度

### 測定頻度
年1回、義務的な再測定がある。逃げられない頻度であり、魔法使いに継続的な緊張感を与える。

これとは別に、専門資格の行使範囲を見直す必要が生じた場合や、休止からの復帰時には**臨時測定**が行われる（2026-10-10確定。実施の引き金の詳細は `organizations/日本魔道協会.md` 参照）。

### 測定方法
複数の測定者による合議制で属人性の排除を試みている。ただし完全な客観化は達成されておらず、制度を信頼する者と疑う者が共存する。

### 測定機関
日本国内では日本魔道協会（JMA）が担う。
JMAは国際魔道協会（IMA）の国際魔道条約に基づく国内実施機関であり、条約第2条の登録制度の実行機関として国内法により置かれた特殊法人（→ `organizations/日本魔道協会.md`）。
→ 詳細は `settings/organizations/日本魔道協会.md` を参照。

### 国・地域との関係
1947年設立の国際魔道協会（IMA）が国際的な管理の枠組みを提供する。
日本はIMAの締約国であり、魔術師登録をした魔術師の情報をIMAに報告する義務を負う（2026-11-07作者決定。旧記述は「登録魔道士の情報」）。
締約国間でのランク認定の相互承認については未定。
→ 詳細は `settings/organizations/国際魔道協会.md` を参照。

## 魔法の運用

### 発動方法

> エネルギー源と発動の機序は真層（`魔法の仕組み.md`「エネルギー源」「魔法の発動メカニズム」「魔法の呼び出し構造」。三つを一本につないだものは同「発動の流れ」、2026-11-09）。2026-11-08に同ファイルへ一本化した。表層では、術者がイメージによって魔法を発動させ、専用神経系がその出力と制御を担うことまでが知られている。

#### 発動を担う器官の分業
魔法発動は脳と専用神経系（魔法系神経系）の二段階分業で成立する。

| 器官 | 役割 |
|------|------|
| 脳（大脳皮質） | イメージの生成・維持 |
| 専用神経系（魔法系神経系） | イメージを受け取り、魔法の出力・制御を担う（その先の機序は真層。`魔法の仕組み.md`「魔法の発動メカニズム」） |

> 出どころ：作者（`../../notes/chat_history/2026/07/10/魔法行使の代償とリスク.md`「イメージは脳だけど、魔力の出力や制御は専用の神経系な気がする」）。

専用神経系は**脊髄の近く**にある（2026-11-09。延髄・脊髄・椎骨の骨髄が一つの軸にそろう設計の一部。真層は `魔法の仕組み.md`「生成の場所と管理」）。全人類が先天的に共通して持つ器官だが、通常は閉じており機能しない。発現経路は二つ。
1. **先天的発現**：遺伝的要因により生まれつき開通している（血統・才能と直結）。
2. **後天的発現（覚醒）**：生命の危機に瀕した際の強烈な情動の揺れにより、後天的に開通するケースがある。

#### 発現（表層）
作中で観察できるのは、専用神経系の開通による**発現**だけである。JMAは兆候や家系にもとづいて「潜在的魔術師」として経過観察し、12歳で「顕在的魔術師」「非魔術師」に判定する（`../organizations/日本魔道協会.md`「魔術師管理制度」）。表層の判定は「発現したかどうか」でしか行えないため、12歳で「非魔術師」と判定された者の中から、後に覚醒する者が出ることがある（例：鬼灯蓮華）。

> 真層（魔術師と非魔術師の境界は魔素を生成できるかどうか、発現には魔素の生成と操作の両方が要る）は `魔法の仕組み.md`「才能と遺伝」「発現の条件」。2026-11-08に同ファイルへ移した。

**発現の時期（2026-10-10確定）：** 発現の年齢に固定された上限はない。統計的には、12歳頃までにほぼすべての発現が出そろうとみなしてよい。JMAの12歳判定はこの統計に基づく手続き上・便宜上の基準である（→ `organizations/日本魔道協会.md`）。

#### 魔力切れの理由
エネルギーが尽きるのではなく、専用神経系が疲弊することで制御能力を失う。精神疲労・筋疲労に近い現象で、休息により回復する。

**呼び名と量（2026-11-09、AIの推奨を作者が採用）：** 「魔力切れ」という呼び名は、昔の人が体の中の何かの量が尽きると考えた名残であり、近代医学によって専用神経系の疲弊だと分かった。一方で、「魔力量が多い・少ない」という違いは経験則として知られている。歳とともに落ちること、骨髄移植を受けた非魔術師が魔法を使えるようになる例があることなどから、作中の医学が魔素を作る力の在りかに気づいていても不自然ではない（表層が真層に部分的にたどり着いている例。`../README.md` 運用ルール6。どこまで知られているかは `../未確定事項一覧.md` 1-16）。魔力量は測れないが、ふつうの魔法では神経の疲弊が先に来るため、量の違いが表に出るのは、長く続く術や規模の大きい術を使うときである。
> 真層（魔力＝体内の魔素、魔力量＝体内に蓄えた魔素の量、使うと減る）は `魔法の仕組み.md`「魔素と魔力」。

#### 代償・リスク
魔法行使の代償は脳側・専用神経系側で性質が異なる二層構造になっている。

| 層 | 通常時の代償 | 臨界点到達時の代償 |
|---|---|---|
| 脳（イメージ生成） | 精神的疲労（集中力低下） | ― |
| 専用神経系（出力・制御） | 神経疲労＝「魔力切れ」（一時的な不発を含む。休息で回復可能） | 臨界点到達：出力系統が不可逆に機能を失い、魔法が完全に発動しなくなる |

専用神経系の損耗には**臨界点**が存在する。臨界点未満では、出力低下・遅延・痛み・一時的な不発が生じても休息による回復余地がある。しかし臨界点へ達した瞬間に出力系統は急激かつ完全に機能を失い、その後ふたたび魔法が使えるようになることはない。部分的な永久低下や、臨界点到達後に弱い出力だけが戻る状態は生じない。

臨界点までの残量を直接・正確に測る方法は確立していない。疲労所見から危険を推定することはできるが、「次の一回」が戻れる範囲かどうかは本人にも医療者にも断定できない。

**安全装置は存在しない。** 気絶は疲弊の結果として起きるものであり、臨界点直前で作動する強制停止装置ではない。気合・薬物・精神力・切迫した状況などで意識を保ったまま使い続け、臨界点へ達することは可能である。

**暴発・不発**：制御失敗時には魔法の暴発・不発が起こりうる。

**生命の危機との関係**：専用神経系の消耗・損傷そのものは生命に直結しない（＝魔力切れによる死はない方針）。ただし、魔法の**効果**自体による死のリスク（暴発・制御失敗による自傷・他害等）は別枠で存在する。

##### 測れるもの／測れないもの（2026-10-10確定）

| 対象 | 内容 | 測定 |
|------|------|------|
| 出力 | 現在どれだけ、どれだけ正確に発現させられるか（範囲・所要時間） | **測れる**（再測定・臨時測定） |
| 負荷 | 専用神経系の消耗の程度（負荷所見・炎症所見） | **測れる** |
| 臨界点 | その人の臨界点がどこにあるか | **測れない**。個人差が大きく、事前に特定する方法がない |

測れるのは「現在の消耗」であって「限界の位置」ではない。したがって医学的助言は常に「危険域に入っている」までしか言えず、「あと何回で終わる」とは誰にも言えない。**予報はあるが警報はない。**

臨界点到達は完全喪失であり部分的な残存がないため、**行使後にごく弱い反応でも戻れば、臨界点には達していなかったと事後に判明する。** 到達したかどうかは事後にしか分からず、事前には誰にも分からない。

疲弊後に戻った弱い出力は永久的な低下ではなく、**回復の途上**である。十分な休息を取れば回復の余地があるが、休まずに行使を続ければ低出力のまま留まる。

##### 消耗の決まり方（2026-10-10確定）

専用神経系の消耗は、主として **「像を保持している時間 × 制御の精密さ」** で決まる。発現させる面積・規模は副次的な要因にとどまる。広く雑に発現させるより、狭く正確に留める方が重い。

加えて、**対象が変わるたびに像を組み直す立ち上げの負荷**が生じる。一つの対象に長く行使するより、複数の対象へ少量ずつ行使する方が、合計の消耗は大きくなりうる。

消耗量を直接表す単位はない。現場で目安になるのは、行使回数と保持時間の記録のみである。

#### 詠唱・魔法陣等の役割（2026-11-09、AIの推奨を作者が採用）
本質ではなく補助手段。どれも**像（イメージ）を作り、保つことを助けるだけ**で、それ自体では魔法を起こさない。

| 補助手段 | 役割 |
|---------|------|
| 詠唱 | 言葉で像を固定する |
| 魔法陣 | 図形で像を外に描き、保つための足場にする |
| 触媒 | 手触り・匂い・色などで、像を呼び起こす手がかりにする |
| 修行 | イメージの明瞭さと制御の精度を高め、型を身につける（下記「素養の内訳」「魔道名家の優位性」） |

無詠唱発動：イメージの明瞭さと制御の精度が十分なら、補助なしで発動できる。天才ほど言語化・魔法陣なしで安定した制御ができる。

> 真層での位置づけ：補助手段が助けるのは発動の流れの【体】の段階（脳のイメージ、専用神経系の制御）だけで、関数の側には働かない（`魔法の仕組み.md`「発動の流れ」の「素養との対応」）。
> 魔道具がどういう物か（補助手段と同じく像の手がかりにすぎないのか、実際の作用を持つのか）は未定（`../未確定事項一覧.md` 0-15）。
> 経緯：旧表は2026-06-30の相談でAIが整理したもので、作者の確認記録はなかった（点検 D）。魔法陣を「位相・境界条件を安定させる補助回路」、触媒を「特定の場の励起を誘導する共鳴物質」、血統を「神の遺産との接続適性を受け継ぐ系統」としていた。魔法陣と触媒は、術者の及ばない段階（場の干渉と励起は呼ばれた関数の側）に働く前提で、「発動の流れ」（2026-11-09）と食い違っていた。血統は補助手段ではなく素養の「使える魔法」に当たるため、表から外した。2026-11-09に書き直し、旧記述「無詠唱発動：イメージの精度・位相安定性が十分なら補助なしで発動可能」も改めた。

### 実力分布
生まれつきの素養は**対数正規分布**に近い（多数の遺伝的・環境的要因の積から生じる）。そこに教育（家伝の型・知識）・経験・資源による増幅が加わることで、最終的な実力は**べき分布**に近づく（2026-11-09、旧記述「教育・経験・秘術による増幅」を改めた）。強い者ほど良い師匠・魔道具・情報へのアクセスが増し、さらに成長するという正のフィードバックが働く。

結果として：
- 一般の魔術師同士の差は数倍程度
- 御三家クラスになると一般の魔術師の数十〜数百倍の実力差が生じうる

ランク分布（C 60%／B 39%／A 約1%）は、このべき分布に測定上の区切りを入れたものである。最上位区分のAには上限がないため、分布の裾に当たる極端な層もAに含まれる。その中で一般的な基準から著しく逸脱する者は、ランクとは別に**特別指定魔道士**として扱われる。ただし指定はランクから独立しており、分布の裾にいなくても、特性・効能の逸脱によって指定されることがある（→「ランク制度」）。

### 魔道名家の優位性（2026-11-09、AIの推奨を作者が採用）

| 要素 | 中身 |
|------|------|
| 血 | 魔法の素養と、家系の中で特に遺伝しやすい魔法（相伝魔術。`../organizations/御三家.md`「相伝魔術とは」） |

## 情報取得系魔法

> 本節の「情報取得系」は、魔法で情報を得ることの**原則**をまとめた便宜上の呼び名であり、近代の系統分類（`魔法の分類.md`）の系統ではない。系統分類では、たとえば千里眼は目の強化として生体系に置かれる。

### 基本原則
魔法は**感覚の拡張**は可能だが、**情報を無から生成**することはできない。

| 可否 | 内容 |
|------|------|
| ○ | 千里眼・遠見など知覚範囲の拡張 |
| ○ | 非魔術師には知覚不能な現象（魔力場等）の感知 |
| ✗ | 突如として新たな知識が内側に生まれる類のもの |

例外：降霊術のみ通常のルールとは異なる挙動をする。
→ 詳細は `魔法の仕組み.md` の「精霊と降霊術」を参照。

### 過去視（2026-11-08、AIの推奨案Bを作者が採用）
術者が過去を見る魔法。**存在するが、使える者がごく少なく、制約が強い。** 「知覚範囲の拡張」（上表の○）を時間の方向に広げたものにあたり、情報を無から生成するものではない。死霊魔術とは別の魔法である（`魔法の仕組み.md`「死霊魔術の仕組み」）。

| 項目 | 内容 |
|------|------|
| 仕組み | 作中では解明されていない（真層は `魔法の仕組み.md`「過去視の仕組み」） |
| 範囲 | 術者の周囲だけ |
| 見えるもの | **3次元の光景だけ。** 精霊は見えない（真層の理由は `魔法の仕組み.md`「過去視の仕組み」）。錯視は他者の知覚に作用する魔法（感覚系。`魔法の分類.md`）なので過去視には効かず、その場の光景がそのまま見える |
| さかのぼれる長さ | **数日〜数週間まで。** 一瞬の一人を取り出す死霊魔術と違い、時間の流れごと追うため、薄れるのが早い |
| 共有 | **見えるのは術者一人だけで、記録も共有もできない。** 法廷では証拠にならず、捜査の手がかりにとどまる |
| 使える者 | 国内にごくわずか。都道府県警の魔道課には置かれず、呼ぶなら公魔などを通す |

- 捜査への影響：過去視は捜査を決め手にしない。口封じの実行者がすぐ割れるような使い方はできず、天宮前日譚で捜査が委員に届かない仕組み（`../stories/天宮前日譚.md`「捜査が委員に届かない仕組み」）は保たれる。
- 事例：凍結事件の現場で過去視を使っても晴明は見えず、「少年の魔法が二人を止めた」光景になる。表向きの「暴発」と食い違わない。
- 採らない案：過去視は存在しない（作者の見方「死霊魔術とは別の魔法としてなら、あってよい」〈2026-10-20〉を使わない）。捜査で普通に使われる（委員に届かない仕組みが崩れる）。
