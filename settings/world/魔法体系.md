# 魔法体系

## 魔法の本質

魔法とは「別の次元・存在」から流れ込んでくる力であり、特定の才能を持つ人間だけが受け取れる。

### 起源に関する裏設定
この設定は基本的に作中人物が知るものではなく、作中で明示的に言及する予定もない。
完結後の裏設定公開などで初めて明かされる可能性がある、世界の底にある設定として扱う。

魔法は、人類が作った技術ではない。
1次元の世界における知的存在が極致に達して2次元へ移行し、その系譜がさらに3次元へ到達した。
3次元におけるその系譜は、人類から見れば「神」と呼んで差し支えない存在であり、彼らもまた極致に達して4次元へ移行した。

現在の3次元世界に存在する魔法は、神々が4次元へ移行した後に残された、次元上昇技術の名残・残響・低次元側インターフェースである。
魔法とは次元ごとに異なる振る舞いをするが、本質的には同一系統の技術である。

表向きには、魔法は「別の次元・存在から流れ込んでくる力」として理解される。
裏設定上は、魔術師が高次元技術の残留構造に部分的に接続し、自身の身体・意識・認識を通じて現象化している。
神々は基本的にこの世界を直接管理しておらず、魔法は恩寵というより、残された巨大な技術基盤を人間が限定的に利用しているものに近い。

この裏設定は、魔法描写の一貫性を保つための羅針盤として用いる。
毎場面で厳密に参照するものではなく、魔法の起源・才能・限界・古代神話の手触りに迷ったときの基底設定とする。

### 理論的基盤・等級分類（設計案）と分類の二層
M理論を基盤とした魔法の仕組み・第0〜3魔法の等級分類は考察途中。
→ `魔法の仕組み.md` を参照。

**分類の二層（2026-10-10確定）：**
- 第0〜3魔法の等級分類は**真層**の設定であり、作中では知られていない。
- 作中（表層）では、魔法の歴史的・経験的な経緯と近代の科学的分析による**別の分類**が用いられる。正式な分類は近代の系統分類（→ `魔法の分類.md`）。
- **ランクと等級は独立している。** ランクは人の技量（規模・精度・強度）、等級は魔法の種類の複雑さであり、互いに対応しない。人物の力量は「使える系統 × ランク ×（該当すれば）特別指定」で表す。
- **属性は魔法的には存在しない。** 火・水などの属性は、便宜上の慣用的な呼び名にすぎない（表層の分類と併せて整理する）。

## 使用者

### 魔術師と魔道士の区別
国際魔道条約の定義による重要な区別。

| 用語 | 定義 |
|------|------|
| **魔術師** | 魔法能力を有する者（自然的存在） |
| **魔道士** | 締約国の登録制度に基づき登録された魔術師（社会的存在） |

魔術師として生まれ、教育・登録を経て初めて魔道士になる。
**日本国内では、顕在的魔術師と判定された者の魔道士登録は国内法により義務化されている。**
また、判定の経路や年齢を問わず、**魔法が発現した者には届出の義務がある**（2026-10-10確定。→ `organizations/日本魔道協会.md`）。
登録しない者（未登録魔術師）は制度の建前上ほとんど存在しないはずの**例外的存在**であり、法を逃れている・見つかっていない・何らかの特殊事情を抱えているといった、それ自体が物語上の異常事態を示すシグナルとして扱う。

登録（魔道士としての基礎資格）とは別に、特定の職務に従事するための専門資格が派生することがある（例：`AI_Novel/命脈/構想.md` の「魔道救急救命士」）。基礎登録は国が一律に課す義務、専門資格は職務ごとに任意で申請・取得するもの、という二階建て構造になる。
**魔法に関する資格はすべてJMA（日本魔道協会）が一元的に認定・管理する。** 地方自治体や民間が独自に魔法関連資格を発行することはない（→ `organizations/日本魔道協会.md`）。

専門資格の審査では、総合ランクだけでなく、その職務に必要な系統・出力・精度・判断能力が個別に確認される。したがってCランクであっても、申請した職務について必要能力を認められれば資格を取得・維持できる。具体的な審査項目や更新条件は未定。

専門資格には**行使範囲**（独立行使／指示下行使）の付帯条件があり、資格の休止制度もある（2026-10-10確定）。詳細は `organizations/日本魔道協会.md` の「行使範囲と休止」を参照。

## ランク制度

### ランクの定義
使用できる魔法の規模・精度・強度により測定される。種類による区別はなく、量的・質的な上達の差として捉える（ピアノの習熟に近い感覚）。

### ランクの変動
訓練・経験によって上昇・下降どちらもある。維持にも継続的な努力が必要。老いや不調によるランク低下もありうる。「全盛期」という概念が生じる。

### 二重構造
現在のランクと過去の履歴が両方記録される。
例：「現Bランク（過去A）」のような表記が公的書類に存在する。
社会は魔法使いを「現在の能力」と「人生の軌跡」の両面で評価する。

### ランク外の区分：特別指定魔道士（2026-10-10確定）

ランクとは別に、国際魔道条約第4条に基づく**特別指定魔道士**の区分がある（→ `organizations/国際魔道協会.md`）。

| | ランク（C/B/A） | 特別指定魔道士 |
|---|---|---|
| 表すもの | 技量の測定結果 | 国家・社会にとっての影響の大きさ |
| 決める者 | JMA（年1回の測定） | **国家**（IMAの規則が定める基準に基づく） |
| 本人の意思 | 測定は義務 | **本人の同意を要しない**（国家的管理区分であるため） |
| 規模 | Aは国内約12万人 | **国内に数十人程度**（目安） |

**ランクとの関係（確定）：** 特別指定はランクと重複する。指定された魔道士も通常どおりランクを持ち、年1回の再測定を受ける（例：「現A・特別指定」）。

**指定の対象（確定）：** 実力はべき分布に従う（→「実力分布」）。指定されるのは次の二種である。

1. **べき分布の最上位層。** 分布の上では連続していても、現実には通常の管理の枠を超える例外的な存在になる。
2. **分布から外れた例外。** べき分布の中に時折現れる、通常の序列では捉えられない魔道士。

**指定の基準（確定）：** 魔道世界における一般的な基準から**著しく逸脱した特性・規模・効能**を持つこと。
「強さ」の序列ではなく、一般的な基準からの逸脱の度合いで判断する。上の二種はいずれも、この逸脱の現れ方の違いである。

- 基準はランクから独立している。**Cランクでありながら特別指定を受けることもありうる**（例：規模は小さいが、効能や特性が一般的な基準から著しく逸脱している場合）。ランクは規模・精度・強度を共通の物差しで測るが、指定はその物差しに乗らない逸脱も対象にするためである。
- 指定は**個別具体的に**行う。家柄・地位（当主であること等）を理由に指定されることはない。
- ただし、指定は国家の政治判断であるため、**政治的な意図によって指定・不指定が左右される余地**がある（→ 下記「指定機関」、`organizations/国際魔道協会.md` 第4条の過少指定の誘因）。どこまで歪むかは要検討。

**指定の効果（確定）**

| 種類 | 内容 |
|------|------|
| 届出 | 住所と長期の移動を所管機関へ届け出る |
| 出国 | 事前の許可を要する。IMAへ通知される |
| 行使の制限 | 他国や私的な組織のための行使を禁じる |
| 協力 | 有事・大規模災害時、国の要請に応じる**努力義務**。拒否への罰則はない |
| 秘匿 | 誰が指定されているかは非公開。知るのは本人・所管機関・IMAのみ |

協力を努力義務にとどめるのは、責務を法が名指しするだけで、応じるかどうかを各人のノブレス・オブリージュに委ねるためである（→ `themes/ノブレスオブリージュ観.md`）。

**指定機関（2026-10-10採用。見直しの余地あり）：** 日本国内では**内閣総理大臣**が指定する。JMAは審査資料（測定データ）と意見を提出するにとどまる。
測定を担う技術機関（JMA）は正確な申告を求め、政府は戦力の秘匿を望みうる。指定を政治判断に置くことで、この緊張が組織間に生じる。JMAの所管省庁が未定でも成立する。

**指定の解除（確定）**

- 解除は国家の判断のみによる。本人は申請できない。
- 能力の低下・死亡に応じ、国家の見直しにより解除される。
- **臨界点到達により魔法を失った場合は解除される。** 指定から確実に外れる方法は、魔法を失うことしかない。

**未定：**
- 年齢を問わず指定しうるか（案：国家的管理区分である以上、12歳の判定以後なら年齢を問わない）
- 政治的な意図が指定に及ぼす影響の範囲（御三家との関係を含む）
- 誰が指定されているか（御三家の当主・次期当主を含め、個別に検討）。神原嶺については「安曇野事件後に指定された」案があるが、`characters/神原嶺.md` の「現在の魔法能力」（未確定事項一覧 5-1）と併せて判断する
- 未登録魔術師は条約上「魔道士」ではないため、指定の対象外になる。前日譚（未登録魔術師の国家的隠蔽）との関係

## 測定制度

### 測定頻度
年1回、義務的な再測定がある。逃げられない頻度であり、魔法使いに継続的な緊張感を与える。

これとは別に、専門資格の行使範囲を見直す必要が生じた場合や、休止からの復帰時には**臨時測定**が行われる（2026-10-10確定。実施の引き金の詳細は `organizations/日本魔道協会.md` 参照）。

### 測定方法
複数の測定者による合議制で属人性の排除を試みている。ただし完全な客観化は達成されておらず、制度を信頼する者と疑う者が共存する。

### 測定機関
日本国内では日本魔道協会（JMA）が担う。
JMAは国際魔道協会（IMA）の国際魔道条約に基づく国内実施機関。
→ 詳細は `settings/organizations/日本魔道協会.md` を参照。

### 国・地域との関係
1947年設立の国際魔道協会（IMA）が国際的な管理の枠組みを提供する。
日本はIMAの締約国であり、登録魔道士の情報をIMAに報告する義務を負う。
締約国間でのランク認定の相互承認については未定。
→ 詳細は `settings/organizations/国際魔道協会.md` を参照。

## 魔法の運用

### 発動方法

#### エネルギー源
魔法のエネルギー源は多次元の場の揺らぎ。
3次元だけで見るとエネルギー保存則は成立しないが、多次元全体では成立している。
術者は「エネルギーを生成する発電機」ではなく、「高次元から3次元へエネルギーを受け渡す変換器・制御器」として機能する。

#### 発動メカニズム

```
人間のイメージ
  → 神の遺産である制御機構に入力
  → 多次元場の波動関数・位相が制御される
  → 多次元干渉粒子（場の励起）が発生・変調する
  → 高次元の揺らぎが3次元現象として出力される
```

制御機構の詳細は神の御業の遺産であり、解明されていない（深く追わない）。

#### 発動を担う器官の分業
魔法発動は脳と専用神経系（魔法系神経系）の二段階分業で成立する。

| 器官 | 役割 |
|------|------|
| 脳（大脳皮質） | イメージの生成・維持 |
| 専用神経系（魔法系神経系） | イメージを受け取り、神の遺産である制御機構への出力・位相制御を担う |

専用神経系は全人類が先天的に共通して持つ器官だが、通常は閉じており機能しない。発現経路は二つ。
1. **先天的発現**：遺伝的要因により生まれつき開通している（血統・才能と直結）。
2. **後天的発現（覚醒）**：生命の危機に瀕した際の強烈な情動の揺れにより、後天的に開通するケースがある。

**魔術師と非魔術師の境界（2026-10-10確定）：** 境界は**魔素を生成できるかどうか**であり、これは遺伝によって決まる（→ `魔法の仕組み.md`「才能と遺伝」）。

**発現の条件（2026-10-10確定）：** 魔法が発現するには、**魔素の生成**と**魔素の操作**の二つがそろわなければならない。魔素の操作は専用神経系が担い、上記の開通によって可能になる。

| 状態（真層） | 魔素の生成 | 魔素の操作（開通） | JMAの判定（表層） |
|------|-----------|-------------------|-----------|
| 非魔術師 | できない | （器官はある） | 経過観察中は「潜在的魔術師」でありうる。12歳判定で「非魔術師」 |
| 未発現の魔術師 | できる | まだできない | 経過観察中は「潜在的魔術師」。発現しないまま12歳を迎えれば「非魔術師」 |
| 発現した魔術師 | できる | できる | 顕在的魔術師 |

> JMAの「潜在的魔術師」は、兆候や家系にもとづく**経過観察の区分**であり、真層の状態とは一致しない。生成能力を持たない者も含まれうる。

魔素は3次元では観測できないため、表層の判定は「発現したかどうか」でしか行えない。12歳時点で「非魔術師」と判定された者の中にも、生成能力を持ちながら発現しなかった者が含まれうる。後天的な覚醒は、こうした生成能力を持つ未発現者にのみ起こる（例：鬼灯蓮華）。

**発現の時期（2026-10-10確定）：** 発現の年齢に固定された上限はない。統計的には、12歳頃までにほぼすべての発現が出そろうとみなしてよい。JMAの12歳判定はこの統計に基づく手続き上・便宜上の基準である（→ `organizations/日本魔道協会.md`）。

#### 魔力切れの理由
エネルギーが尽きるのではなく、専用神経系が疲弊することで制御能力を失う。精神疲労・筋疲労に近い現象で、休息により回復する。

#### 代償・リスク
魔法行使の代償は脳側・専用神経系側で性質が異なる二層構造になっている。

| 層 | 通常時の代償 | 臨界点到達時の代償 |
|---|---|---|
| 脳（イメージ生成） | 精神的疲労（集中力低下） | ― |
| 専用神経系（出力・制御） | 神経疲労＝「魔力切れ」（一時的な不発を含む。休息で回復可能） | 臨界点到達：出力系統が不可逆に機能を失い、魔法が完全に発動しなくなる |

専用神経系の損耗には**臨界点**が存在する。臨界点未満では、出力低下・遅延・痛み・一時的な不発が生じても休息による回復余地がある。しかし臨界点へ達した瞬間に出力系統は急激かつ完全に機能を失い、その後ふたたび魔法が使えるようになることはない。部分的な永久低下や、臨界点到達後に弱い出力だけが戻る状態は生じない。

臨界点までの残量を直接・正確に測る方法は確立していない。疲労所見から危険を推定することはできるが、「次の一回」が戻れる範囲かどうかは本人にも医療者にも断定できない。

**安全装置は存在しない。** 気絶は疲弊の結果として起きるものであり、臨界点直前で作動する強制停止装置ではない。気合・薬物・精神力・切迫した状況などで意識を保ったまま使い続け、臨界点へ達することは可能である。

**暴発・不発**：制御失敗時には魔法の暴発・不発が起こりうる。

**生命の危機との関係**：専用神経系の消耗・損傷そのものは生命に直結しない（＝魔力切れによる死はない方針）。ただし、魔法の**効果**自体による死のリスク（暴発・制御失敗による自傷・他害等）は別枠で存在する。

##### 測れるもの／測れないもの（2026-10-10確定）

| 対象 | 内容 | 測定 |
|------|------|------|
| 出力 | 現在どれだけ、どれだけ正確に発現させられるか（範囲・所要時間） | **測れる**（再測定・臨時測定） |
| 負荷 | 専用神経系の消耗の程度（負荷所見・炎症所見） | **測れる** |
| 臨界点 | その人の臨界点がどこにあるか | **測れない**。個人差が大きく、事前に特定する方法がない |

測れるのは「現在の消耗」であって「限界の位置」ではない。したがって医学的助言は常に「危険域に入っている」までしか言えず、「あと何回で終わる」とは誰にも言えない。**予報はあるが警報はない。**

臨界点到達は完全喪失であり部分的な残存がないため、**行使後にごく弱い反応でも戻れば、臨界点には達していなかったと事後に判明する。** 到達したかどうかは事後にしか分からず、事前には誰にも分からない。

疲弊後に戻った弱い出力は永久的な低下ではなく、**回復の途上**である。十分な休息を取れば回復の余地があるが、休まずに行使を続ければ低出力のまま留まる。

##### 消耗の決まり方（2026-10-10確定）

専用神経系の消耗は、主として **「像を保持している時間 × 制御の精密さ」** で決まる。発現させる面積・規模は副次的な要因にとどまる。広く雑に発現させるより、狭く正確に留める方が重い。

加えて、**対象が変わるたびに像を組み直す立ち上げの負荷**が生じる。一つの対象に長く行使するより、複数の対象へ少量ずつ行使する方が、合計の消耗は大きくなりうる。

消耗量を直接表す単位はない。現場で目安になるのは、行使回数と保持時間の記録のみである。

#### 詠唱・魔法陣等の役割
本質ではなく補助装置。

| 補助手段 | 役割 |
|---------|------|
| 詠唱 | イメージを固定するための言語的フレーム |
| 魔法陣 | 位相・境界条件を安定させる補助回路 |
| 触媒 | 特定の場の励起を誘導する共鳴物質 |
| 血統 | 神の遺産との接続適性を受け継ぐ系統 |
| 修行 | イメージの精度と制御安定性を高める訓練 |

無詠唱発動：イメージの精度・位相安定性が十分なら補助なしで発動可能。天才ほど言語化・魔法陣なしで安定した制御ができる。

## 魔道士の実力決定要因

### 実力の基本公式
```
実力 = 素養 × 教育 × 経験 × 資源
```

| 要素 | 内容 |
|------|------|
| 素養（先天要因） | 魔力量・魔法適性・固有能力の質・学習速度（詳細は下記） |

> **魔力量（2026-10-10確定）：** 体内の**貯蓄量**を指す。何を貯蓄しているのかは未定（魔素か、それ以外か）。
| 教育 | 家伝魔法・師匠・理論教育・秘術 |
| 経験 | 実戦・研究・失敗・人生経験 |
| 資源 | 魔道具・財産・人脈・組織力 |

素養の内訳：

| 素養要因 | 内容 |
|---------|------|
| イメージの明瞭さ | 脳内で位相制御の入力となるイメージを鮮明に保てるか |
| 位相制御の精度 | 多次元場の波動関数・位相を細かく制御できるか |
| 精神・神経系の耐久性 | 高出力に耐える制御器官の強さ |
| 多次元場との共鳴適性 | 多次元干渉粒子（場の励起）をどれだけ安定して通過・制御できるか |
| 神の遺産との接続強度 | 制御機構への接続の深さ・安定性 |

素養がスタートラインと天井を決め、鍛錬はその範囲内での到達点を決める。努力は確実に意味を持つが、素養の壁は越えられない。「人は生まれながらに不平等」というテーマに直結する構造。

### 実力分布
生まれつきの素養は**対数正規分布**に近い（多数の遺伝的・環境的要因の積から生じる）。そこに教育・経験・秘術による増幅が加わることで、最終的な実力は**べき分布**に近づく。強い者ほど良い師匠・魔道具・情報へのアクセスが増し、さらに成長するという正のフィードバックが働く。

結果として：
- 一般魔道士同士の差は数倍程度
- 御三家クラスになると一般魔道士の数十〜数百倍の実力差が生じうる

ランク分布（C 60%／B 39%／A 約1%）は、このべき分布に測定上の区切りを入れたものである。最上位区分のAには上限がないため、分布の裾に当たる極端な層もAに含まれる。その中で一般的な基準から著しく逸脱する者は、ランクとは別に**特別指定魔道士**として扱われる。ただし指定はランクから独立しており、分布の裾にいなくても、特性・効能の逸脱によって指定されることがある（→「ランク制度」）。

### 魔道名家の優位性
御三家の強さは「遺伝のみ」でも「環境のみ」でも説明できない。複合要因で成立している（推定値）。

| 要因 | 貢献度 |
|------|--------|
| 遺伝 | 20% |
| 教育 | 30% |
| 秘術の継承 | 20% |
| 人脈 | 20% |
| 資産 | 10% |

「御三家の子だから強い」のではなく、「御三家だけが超高位の才能を十分に開花させる環境を持っている」構造。才能自体は社会全体に散らばっているが、それを最後まで育てられる者が少ない。

### 一般家庭から高位魔術師が出にくい理由

| パターン | 詳細 |
|----------|------|
| 暴走・消失 | 管理なしの発現 → 事故死または能力抑圧による消失 |
| 協会の囲い込み | 才能発覚後に保護され名家へ養子縁組 → 統計上「名家出身者」になる |
| 社会的選別 | 魔導書・師匠・実験設備の壁で伸びしろが制限される |

> 「呼吸法・瞑想等を幼少期に習得しないと才能が発現しない」という言い伝えは、**世俗的な伝統（俗説）**として存在してよいが、正式な設定ではない（2026-10-10）。

| 出自 | Aランク到達率（推定） |
|------|-----------------|
| 御三家 | 40% |
| 名家 | 10% |
| 一般魔術師家系 | 1% |
| 非魔術師家系 | 0.01% |

## 情報取得系魔法

> 本節の「情報取得系」は、魔法で情報を得ることの**原則**をまとめた便宜上の呼び名であり、近代の系統分類（`魔法の分類.md`）の系統ではない。系統分類では、たとえば千里眼は目の強化として生体系に置かれる。

### 基本原則
魔法は**感覚の拡張**は可能だが、**情報を無から生成**することはできない。

| 可否 | 内容 |
|------|------|
| ○ | 千里眼・遠見など知覚範囲の拡張 |
| ○ | 非魔術師には知覚不能な現象（魔力場等）の感知 |
| ✗ | 突如として新たな知識が内側に生まれる類のもの |

例外：降霊術のみ通常のルールとは異なる挙動をする。
→ 詳細は `魔法の仕組み.md` の「精霊と降霊術」を参照。
