# タイムライン

> **本フォルダの位置づけ:**
> 作品全体の時系列を管理するためのマスター年表群。
> 詳細設定は各設定ファイルに残し、このフォルダでは矛盾確認に必要な骨格を扱う。
> 「確定」「仮」「未確定」を明示し、後から変更する場合は関連ファイルも確認する。

---

## 管理方針

- 物語の主舞台は2025年の日本。
- 現実史準拠を基本とするが、魔法の存在により歴史・制度・文化の経路が変化している。
- 大きな歴史は「結末は現実に近いが、そこへ至る経路が違う」形式で扱う。
- 前日譚は2024年の凍結事件と2025年の蓮華・梓音編が重なる構造を持つ。
- 読者に開示する年表と、作者が管理する真相年表は分けて考える。
