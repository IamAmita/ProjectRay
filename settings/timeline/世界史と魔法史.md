# 世界史と魔法史

| 時期 | 状態 | 出来事 | 関連 |
|------|------|--------|------|
| 人類史以前〜古代 | 確定 | 魔法は人類誕生時から存在する。古代文明は魔法を含む世界として発展した。 | `../world/世界史と魔法.md` |
| 古代 | 確定 | 魔法・宗教・科学・政治は未分化。祭司・王・学者・魔術師の役割が重なっていた。 | `../world/世界史と魔法.md` |
| 紀元前3500年頃〜 | 考察 | メソポタミア文明。水・土操作、通信、治癒が国家インフラ化していた可能性。 | `../world/世界史と魔法.md` |
| 紀元前3100年頃〜 | 考察 | 古代エジプト文明。水操作、降霊術、死者の知識継承が重視された可能性。 | `../world/世界史と魔法.md` |
| 紀元前2600年頃〜 | 考察 | インダス文明。都市計画・管理・契約系魔法が発達した可能性。 | `../world/世界史と魔法.md` |
| 紀元前2000年頃〜 | 考察 | 古代中国文明。治水魔術、甲骨占い、天命思想が魔法血統と結びついた可能性。 | `../world/世界史と魔法.md` |
| 古代〜中世 | 確定 | 宗教・魔法・科学が一体化した時代が続く。 | `../world/世界史と魔法.md` |
| 1〜2世紀 | 確定 | 神武東征・即位（史実）。御三家が東征の途中で合流し、朝廷の発足に深く関わる。天宮家は出雲、龍崎家は筑後、神原家は吉野の豪族とされる（龍崎家は筑紫で武力により、神原家は吉野で、天宮家は大和の即位の際に交渉により）。 | `../organizations/御三家.md`、`../world/世界史と魔法.md` |
| 〜2世紀後半 | 確定 | 欠史八代（第2〜9代、史実）。王権が揺らぎ、倭国大乱へ。 | `../world/世界史と魔法.md` |
| 2世紀後半〜248年ごろ | 確定 | 卑弥呼（倭迹迹日百襲姫命。母方は天宮家）を共立。邪馬台国は畿内のヤマト。男弟（崇神）が統治を助ける。龍崎家は朝廷の側で武力を担い、神原家は魏との交渉・貿易を担う。239年、魏へ使い。 | `../world/世界史と魔法.md`、`../organizations/御三家.md` |
| 248年ごろ | 確定 | 卑弥呼が死に、箸墓に葬られる。台与（豊鍬入姫命）が継ぐ。 | `../world/世界史と魔法.md` |
| 258年 | 確定 | 崇神が没する。 | `../world/世界史と魔法.md` |
| 266年 | 確定 | 台与が西晋へ使い。 | `../world/世界史と魔法.md` |
| 近世〜近代 | 確定 | 魔法学と自然科学の分離が進む。非魔術師による魔法現象の観測・分類が始まる（17世紀・科学革命）。 | `../world/世界史と魔法.md` |
| 江戸時代 | 確定 | 日本では幕府・藩・寺社・名家が、それぞれ魔術師を抱える。 | `../organizations/魔法省.md` |
| 18世紀末 | 確定 | 化学革命（1789年）で四元素説が崩れ、属性は科学の座を失って慣用名に転落する。 | `../world/魔法の分類.md` |
| 19世紀半ば | 確定 | 産業革命・エネルギー革命による魔法の価値の低下と、エネルギー保存則の確立（1840年代）が重なり、魔法を自然科学として究明する勢力が決定的に強くなる。 | `../world/魔法の分類.md` |
| 19世紀後半 | 確定 | 魔道学の学会が成立し、物理学の分野の境界を借りた系統分類の原型が作られる。 | `../world/魔法の分類.md` |
| 1870年 | 確定 | 史実どおり陰陽寮が廃止される。天文・暦は史実どおり大学へ移り、魔道の業務は翌年の魔法省へ吸収される。 | `../organizations/魔法省.md` |
| 1871年 | 確定 | 廃藩置県の直後、魔法省が置かれる。目的は魔術師の把握・管理。古い魔道の組織を吸収し、地方の管轄局に組み直した。管轄局ごとに養成機関を置く（舞苑を除く国立魔道学院6校の前身）。 | `../organizations/魔法省.md` |
| 第一次世界大戦 | 確定 | 魔道士が強力な兵器として機能した最初の大規模戦争。各国が魔道士を恐れつつ秘匿。以後、日本の魔法省に動員の性格が加わる。 | `../organizations/国際魔道協会.md`、`../organizations/魔法省.md` |
| 第二次世界大戦 | 確定 | 未知の魔術師が戦局を変え、終戦後に各国の秘匿魔術師が問題化する。日本では魔法省が名簿から陸海軍へ魔術師を送り出す一方、陸海軍も魔法省を通さずに魔術師を抱えた（名簿の外の魔術師）。 | `../organizations/国際魔道協会.md`、`../organizations/魔法省.md` |
| 1947年 | 確定 | 国際魔道協会（IMA）設立。国際魔道条約により魔術師登録・国際報告・特別指定魔道士（第4条）の枠組みが成立。占領下の日本は加盟していない。 | `../organizations/国際魔道協会.md` |
| 1947年12月31日 | 確定 | 現実の内務省と同じ日に、魔法省が廃止される。機能は魔道庁（政策・監督）・JMA（登録・測定。設立までは魔道庁が暫定）・警察の魔道部門（治安）・文部省（教育・研究）に分割される。 | `../organizations/魔法省.md`、`../organizations/魔道庁.md` |
| 1948年1月 | 確定 | 魔道庁が総理庁の外局として発足し、登録・測定を暫定的に直接行う。 | `../organizations/魔道庁.md` |
| 1948年3月 | 確定 | 旧警察法の施行。治安維持部の後身は国家地方警察・自治体警察に分かれる。 | `../organizations/魔法省.md` |
| 1949年 | 確定 | 魔道庁が総理府の外局となる。新制大学の発足とともに、養成機関が中等部・高等部・大学に再編されていく。 | `../organizations/魔道庁.md`、`../organizations/国立魔道学院.md` |
| 1951年ごろ | 確定 | 日本が占領当局の了承を得て国際魔道条約に加盟し、JMAが設立される。登録・測定がJMAへ移る。 | `../organizations/国際魔道協会.md`、`../organizations/日本魔道協会.md` |
| 1950年代（仮） | 確定（年は仮） | IMAが各国の分類を統一し、国際標準の系統分類を定める。 | `../world/魔法の分類.md` |
| 1954年 | 確定 | 新警察法により、治安の魔道部門は都道府県警察の魔道部門となる。 | `../organizations/京都府警.md` |
| 2001年 | 確定 | 中央省庁の再編により、魔道庁が内閣府の外局となる。 | `../organizations/魔道庁.md` |
| 現代 | 確定 | 魔法は社会に公知され、政府・法律・教育制度に組み込まれている。 | `../world/世界観概要.md` |
