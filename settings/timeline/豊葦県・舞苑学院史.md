| 1950年代 | 確定寄り | 主権回復後、神原系の企業が集まり直し、神原グループの原型ができる。神原家が豊葦に金を出せるようになる（2026-10-30採用）。 | `../locations/豊葦の歴史.md` |
| 1950〜60年代 | 確定 | 虹命山・虹命樹・豊葦カルデラ・黄泉内海の本格調査。都市開発・防災研究の中核化。重要な調査対象として研究者が集まる。 | `../organizations/舞苑学院.md`、`../locations/豊葦の歴史.md` |
| 1960年代 | 確定寄り | 神原家が、重要な土地を中心部を除いて保護ではなく開発に持っていくよう押し切る。国有地の払い下げで神原系の開発会社が土地を得て、港（藤港）を築く。天宮家への手当てとして、虹命山の一帯を国立公園として開発から外す。神原家は、総合調査の報告で保護範囲を中心部に絞って示し、研究者を資金で割り、「住まなければ守れない」と主張し、港と宿舎を先に造り、人脈で特別保護地区を虹命山の中心部に絞らせる（2026-10-30採用。国立公園の指定年は未定）。 | `../locations/豊葦の歴史.md` |
| 1960年代前半 | 確定寄り | 家族で住む人が増え、豊葦村が置かれる（2026-10-30採用）。 | `../locations/豊葦の歴史.md` |
| 1960年代後半 | 確定寄り | 港の整備と合わせて、藤港の沖の浅い棚と宜本川の河口の浅瀬・小島を核に埋め立てた小さな飛行場が開港する。神原系の企業が港と一体で造り、管理は東京都（2026-11-01採用。原稿の「人工島上の空港を有する国際港」に合わせた）。 | `../locations/豊葦の歴史.md` |
| 1960年代半ば | 確定寄り | 虹命山国立公園の指定。特別保護地区は虹命山の中心部に絞られる（2026-10-30採用。例：1965年、正確な年は未定）。 | `../locations/豊葦の歴史.md` |

| 1970年代 | 確定寄り | 漁業の集落として堅洲島に堅洲村、高天島に高天村が置かれる（2026-10-30採用。正確な年は未定）。 | `../locations/豊葦県成立史.md` |

| 1987〜89年 | 確定寄り | 神原家が、国政の人脈で県を設ける法律を通させる一方、豊葦市の議会と住民に東京都からの分離を求めさせ、上と下から挟んで東京都の反対を押し切る（2026-10-30採用）。 | `../locations/豊葦の歴史.md` |
